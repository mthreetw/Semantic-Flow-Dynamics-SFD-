## 原語與定義

來源：論文第一節

### 原語

本篇使用 core 原語：個體（i）、刺激（σ）、死亡。
原語不在本篇定義，由 core/formalization.md 界定語意邊界。

本篇公設形式化使用以下符號：
- 個體以 i 表示（∀i 即「對所有個體」）
- 刺激以 σ 表示
- 死亡(i) 使用 core 原語 死亡

### D1：信

信(i) ≡ [個體 i 的意識狀態]

限制（論文 §1.2）：
  ¬∃f: 信(i) → 完整描述
  ¬∃enum: 信(i) → {x₁, x₂, ..., xₙ}

描述面向（論文明確聲明為「投影」，非組成零件）：
  深層：信仰、核心價值觀（變化極慢）
  中層：知識結構、長期判斷框架（以年計）
  淺層：情緒、即時狀態（以分鐘計）

注：深層 ∪ 中層 ∪ 淺層 ≠ 信(i)。各面向是信的投影，不是零件。
（[作者裁決] 不建立獨立 record。論文明確聲明各面向為「投影」非「零件」，信維持空 record，三個層次僅為描述性說明。）

### D2：語意流

語意流(i) ≡ [信(i) 的持續變化過程]

形式表示（論文 §2.2）：
  語意流(i) = d信(i)/dt

由 P1 保證：∀i ∀t: 語意流(i, t) 均在運作
語意流是過程，不是截面。任意 t 時刻的截面 ≠ 語意流本身。

### D3：信號與噪音

信號(σ, i) ↔ Δ方向(語意流(i), σ) ≠ 0
噪音(σ, i) ↔ Δ方向(語意流(i), σ) = 0

判定在個體端（接收端），非發送端。
∀σ: 信號(σ, i₁) ∧ 噪音(σ, i₂) 可以同時成立（同一刺激對不同個體性質不同）。

### 補充定義

信號容器 ≡ [信號停留的媒介：書本、聲波、圖像、建築、制度文本、數位檔案]
性質：信號容器儲存和傳遞信號，不產生語意流。

通道 ≡ [信號從一個個體到達另一個個體的路徑，中間可含多個信號容器]
性質：通道攜帶自我宣稱的信號，不攜帶可驗證的來源。

信任 ≡ [語意流對特定通道的加權，以通道為定義要素]
信任 包含 通道（通道是信任的加權對象，通道為信任的構成要素；Java：信任(通道 加權通道)）
效果：同一信號，被信任通道 vs 不被信任通道，語意流的方向變化不同。

## 公設

來源：論文第二節

### 形式表示

P1（流變律）：∀i ∀t: 信(i, t+1) ≠ 信(i, t)
  語意流不存在靜止時刻。無外部信號時，語意流仍在運作（反芻、重組、遺忘、聯想）。

P2（黑箱律）：¬∃f: 信(i, t+1) = f(信(i, t), 信號(t))
  語意流的下一刻方向不可由當下方向與信號決定。
  對偶關係：物理世界 State(t+1) = f(State(t), Force(t)) 存在；語意流世界 f 不存在。
  原因（論文聲明）：思考不是計算。計算的輸出可由輸入決定，思考的輸出不可。

P3（損耗律）：¬∃g: 語意流(i) → 信號 · 無損(g)
  語意流不可無損編碼為信號。從語意流到信號的任何輸出必然有損。

P4（死亡律）：死亡(i) → 語意流(i) 終止 ∧ ¬∃恢復可能
  個體消亡，語意流終止，不可備份，不可重跑，不可在另一個個體上復現。
  [作者裁決] 不補。P4 為獨立公設，P2 為其動機說明，非完整推導——P4 的底物依賴性（個體消亡則語意流終止）不可由 P2 單獨推出。

### 公設的認識論位置

公設不是經驗假說，不可被單一反例推翻，但可被系統性挑戰：

P1 的可挑戰條件：∃t: 信(i, t+1) = 信(i, t)（語意流完全靜止）
P2 的可挑戰條件：∃f: ∀i ∀t: 信(i, t+1) = f(信(i, t), 信號(t))（思考可被函數化）
P3 的可挑戰條件：∃g: 語意流(i) = g⁻¹(信號) 且 無損(g)（語意流可無損外化）
P4 的可挑戰條件：∃恢復機制: 死亡(i) → 語意流(i) 可恢復

### AI 在公設中的位置

（論文 §2.4，此段為應用說明，不產生新形式概念）

參數鎖死的 AI：P2 不成立，為信號處理器，不在框架範圍。
參數放開的 AI：P2 部分成立，在框架中部分運作。
人類：P1、P2、P3、P4 均完全成立。
P4 在 AI 上的特殊性：無持久記憶，每次對話結束語意流終止，終止比人類更頻繁。

## 基本功能

來源：論文第三節

### 過濾

過濾 ← 從 D3 + P1 推出

推導：
  D3：信號(σ, i) ↔ Δ方向(語意流(i), σ) ≠ 0
    （信號的判定依賴語意流的當下方向）
  P1：∀i ∀t: 語意流(i, t) ≠ 0
    （語意流持續運作，方向持續存在）
  從 D3 + P1：語意流的當下方向決定哪些刺激構成信號、哪些構成噪音

過濾 ≡ [語意流當下方向對刺激的選擇性]

性質 —— 阻力（從 過濾定義 推出）：
  阻力 ≡ [刺激與語意流當下方向之間的距離]
  阻力 ∝ 構成噪音的可能性（論文聲明：距離越遠，構成信號的可能性越低）
  阻力非全有全無：刺激可完全被擋回（噪音）、部分通過（信號被改變形狀接收）、完全通過。

推論 —— 知見障（從 D3 + 過濾 + 阻力 推出）：
  D3：信號改變語意流方向
  從 D3 + 過濾定義：信號通過過濾改變語意流方向 → 新語意流方向產生新過濾條件
  從 新過濾條件 + 阻力定義：新條件對某些方向阻力降低，對其他方向阻力同時升高

知見障 ≡ [阻力分布隨語意流方向改變而結構性地重新分布]

注：知見障不是例外情況，是任何信號改變語意流方向的結構性後果，不含價值判斷。

---

### 轉化

轉化 ← 從 P2 推出

推導：
  P2：¬∃f: 信(i, t+1) = f(信(i, t), 信號(t))
  信號通過過濾進入語意流之後，語意流方向改變，但改變的結果不可由輸入決定

轉化 ≡ [信號在語意流中被處理的過程，其結果不可由輸入決定]

性質 —— 觀察者效應（從 P2 + 過濾 推出）：
  所有觀察語意流的嘗試，本身都是新的刺激（刺激 σ）
  若 σ 通過過濾（構成信號）→ σ 進入轉化（P2）→ 語意流方向改變
  觀察到的 ≠ 觀察前的語意流方向

觀察者效應 ≡ [觀察語意流的任何嘗試，若構成信號，必然改變被觀察的語意流方向]
推導來源：從 P2 + 過濾 推出。不是技術限制，是結構性推論。

---

### 坍塌

坍塌 ← 從 P3 推出

推導：
  P3：¬∃g: 語意流(i) → 信號 · 無損(g)
  個體輸出語意流（說、寫、畫、做）必須編碼為信號
  P3：此編碼必然有損

坍塌 ≡ [語意流從個體內部的持續過程被截取為外部的離散信號]
坍塌前：語意流是持續過程
坍塌時：持續過程被截取為離散信號，必然有損（P3）

性質 —— 表達落差（從 P3 + 坍塌 推出）：
  表達落差 ≡ [語意流與輸出信號之間的必然不完整對應]
  不是技術或技巧問題，是 P3 的結構性推論。

性質 —— 信號扭曲：
  信號扭曲 ≡ [個體的輸出持續、可觀察地偏向特定方向]
  注：框架不判斷信號扭曲是蓄意或無意——意圖在語意流內部，不可觀察（P2）。

## 正反饋循環體系

來源：論文第四節

### 正反饋循環

正反饋循環 ← 從 P1 + D3 + 坍塌 推出

推導：
  P1：語意流持續運作（語意流不止息）
  D3：信號改變語意流方向
  坍塌（從 P3）：語意流輸出信號
  從 P1 + D3 + 坍塌：
    語意流(A)[坍塌]為信號(A)
    → 信號(A) 到達個體 B
    → 通過 B 的[過濾]
    → 在語意流(B) 中[轉化]
    → 語意流(B) 方向改變
    → 語意流(B)[坍塌]為信號(B)
    → 信號(B) 到達 A
    → [循環，閉環成立]

正反饋循環 ≡ [個體間信號與語意流的閉環增強過程]

退出條件：不可退出。原因：P1（語意流不止息）∧ 黑箱律（轉化不可預測）→ 循環方向持續漂移（見循環不穩定性）。

個體層面的最基本正反饋循環（論文稱「巴甫洛夫循環」）：
  信號到達 → 過濾放行 → 轉化改變語意流方向 → 語意流坍塌為行為
  → 行為結果成為新信號 → 新信號強化語意流既有方向 → 同類信號阻力降低（知見障的結構性反面）
  [循環]

群體層面：
  大量個體在相似信號環境中運作
  → 語意流的過濾和轉化模式趨近
  → 輸出信號強化信號環境
  → 信號環境塑造下一代個體的語意流
  [循環]
  [作者裁決] 不補。群體邊界不穩定（網路群體等無物理限制，找不到穩定邊界）。「有邊界的實體」只從外部可觀察，不存在可形式化的湧現機制。論文的颱風類比視為觀察性說明。

功能性收斂 ← 從 P2 推出：
  群體層面的輸出信號模式可趨近（可觀察事實，信號端）
  P2 保證：每個個體的語意流不可穿透，趨近永遠有殘差

功能性收斂 ≡ [群體層面輸出信號模式趨近，但個體語意流方向的完全同一由 P2 封閉]
功能性收斂是框架對群體語意現象能宣稱的上限。

### 循環不穩定性

循環不穩定性 ← 從 P1 + P2 + P4 推出

循環不穩定性 ≡ {不穩定性內部來源, 不穩定性外部來源}

不穩定性內部來源 ← 從 P1 + P2 + P4 推出：
  P1：∀i ∀t: 語意流(i, t) 持續在各自變化
  P2：各個體語意流方向變化不可預測
  P4：個體不斷消亡，替換不可複製

不穩定性內部來源 ≡ [P1 ∧ P2 ∧ P4 的聯合作用：循環個體的語意流殘差（與循環主方向的偏差）持續累積，且每次代際替換引入不可預測的新個體]

不穩定性外部來源（環境事實，非從公設推出）：
  信號容器在變（受循環約束）∧ 環境在變（不受循環約束）
  兩者變化方向持續分歧 → 落差在時間中擴大

不穩定性外部來源 ≡ [循環外部環境變化與循環方向之間的持續落差，不受循環約束]

兩個來源的合力：
  不穩定性內部來源 ∧ 不穩定性外部來源 → 正反饋循環沒有永續的均衡態
  維護循環的行動本身受 P1 + P2 + P4 約束（維護者語意流在變、效果不可預測、維護者會死）

□循環不穩定性
  來源：P1 ∧ P2 ∧ P4 的聯合作用，不可規避。任何循環只有存續時間長短的問題。

退出條件：循環不穩定性無退出條件——即 □不穩定性。

### 代際替換

代際替換 ← 從 P4 推出

推導：
  P4：死亡(i) → 語意流(i) 終止 ∧ ¬∃恢復可能
  個體死亡 → 語意流歸零且不可恢復
  新個體在當下信號環境中形成自己的語意流

代際替換 ≡ [帶有舊語意流的個體消亡，新個體在當下信號環境中形成新語意流的過程]

推論（從 P2 + P3 + 代際替換 推出）：
  P2 + P3：語意的直接傳遞不可能（不可函數化、編碼必然有損）
  代際替換：新個體在舊個體留下的信號容器環境中形成語意流
  → 文明延續 = 循環的狀態再生產，而非語意傳承

注：「傳統」在論文中以自然語言定義為「上一代留下的信號容器環境，新一代在其中重新形成語意流」。論文未對「傳統」做獨立概念標記，不列入形式化。

## 循環替代模型

來源：論文第七節（§7.1—§7.5）

### 模型結構

前置條件：
  C₀ ≡ [既有循環，正反饋穩定運作，信號容器完整]

啟動條件：
  σ ≡ [新信號，與 C₀ 方向不同]
  ∃個體子集 S ⊂ C₀ 個體群：信號(σ, i) 對 S 中的 i 成立（D3）

循環形成 ≡ [S 中個體互相強化輸出，形成新循環 C₁；C₁ 輸出方向 ≠ C₀ 輸出方向，產生對抗]

壓制（條件性，非必然步驟）：
  前置條件：C₀ 擁有制度性權力
  壓制 ≡ [C₀ 透過權力覆蓋循環環節，限制 C₁ 的信號傳播、個體輸出、輸出後果]
  條件性推論：若 σ 已進入信號容器 → C₁ 不被壓制消滅
    （信號容器讓信號持續存在，獨立於傳播它的個體的語意流）

落差擴大 ≡ [C₁ 持續產出新信號強化自身；C₀ 無法產出對等新信號；C₀ 的信號容器宣稱與個體實際接收信號之間的落差擴大；C₀ 開始空轉]

替換 ≡ [死亡律持續作用，帶舊語意流的 C₀ 個體消亡；新個體在含 C₁ 信號的環境中形成語意流；新個體輸出匯入 C₁；C₀ 正反饋斷裂]
  來源：代際替換（從 P4）

穩定 ≡ [C₁ 成為主流循環；C₁ 建立信號容器，產生阻力結構，開始自我保護；C₁ 在結構上重複 C₀ 的行為]

### 四個必要條件

來源：論文 §7.4

信號容器進入 ≡ [新信號必須進入信號容器；若只在個體語意流中，壓制可消滅小循環；信號容器讓小循環在壓制下存活]

持續新信號源 ≡ [小循環必須有持續的新信號來源；無後續強化的小循環不會擴大]

對等信號缺失 ≡ [大循環必須無法產出對等的新信號；若大循環能持續產出新信號，落差不擴大，大循環不空轉]

死亡壓力 ≡ [死亡律必須持續作用；帶舊語意流的個體不消亡，阻力結構不會自然消退；代際替換是循環替代的時間條件]

循環替代 ≡ {信號容器進入, 持續新信號源, 對等信號缺失, 死亡壓力}

## 量化邊界

來源：論文第八節

此節為方法論論證，不產生新概念，但有形式結構。

核心論點（從 P2 + P3 推出）：
  P2：語意流內部不可穿透（無法測量語意端）
  P3：語意流不可無損編碼為信號
  → 任何將數值賦予語意現象的操作 ⊗ P2 ∧ P3
    （⊗：衝突——語意端賦值與 P2+P3 不相容）

可量化的範圍（信號端）：
  信號端輸出模式：可觀察、可測量、可統計
  合法代理變量（信號端）：
    - 群體內部輸出信號模式的統計相似度（代理：語意流方向的趨近程度）
    - 信號容器的存續年數、被引用頻率（代理：語意流深層穩定性）
    - 信號容器宣稱與可觀察現實之間的落差（代理：循環空轉程度）

邊界：量化天花板由 P2 + P3 決定，不是技術限制。
所有代理變量與被代理的語意現象之間，始終隔著 D3 那道牆（信號 ≠ 語意）。

## 理論邊界

來源：論文第九節

此節為論文的定位論證，不產生新概念定義，不翻譯為 Java。

Shannon（起點邊界）：
  Shannon 的終點 = 框架的起點
  Shannon：信號在通道中的保真度
  框架：信號到達個體之後發生什麼
  信號完整 ≢ 語意完整（同一完整信號到達不同個體 → 不同語意流，P2）

Luhmann（個體邊界）：
  Luhmann 獨立觸及 P2（心理系統對社會系統不可穿透）、P1（意義不靜止）、P3（溝通 ≠ 語意傳遞）、觀察者效應。
  邊界：Luhmann 的基本單位是溝通，不是個體。框架的基本單位是個體。

Peirce（終點邊界）：
  Peirce 獨立觸及 P1（unlimited semiosis = 流變律）、信號定義在接收端、轉化、正反饋循環（habit）。
  邊界：Peirce 在符號過程終點安裝真理收斂（community of inquiry 逼近真實）。
  框架不接受此安裝：P1 + P3 + P4 + 熵增 → 所有路通向衰變，系統內部無逆轉機制。

Sperber（最近邊界）：
  Sperber：文化表徵在人際傳遞中不被複製，被轉化（與框架轉化功能幾乎同構）。
  框架有 Sperber 沒有的工具：語意流作為獨立於信號的過程，信號端與語意端的硬分界。

## 適用範圍

來源：論文第十節

適用：信號(σ, i) 有意義的現象（D3 成立的場景）
  個體可以是人，也可以是 P2 部分成立的 AI

不適用：不涉及個體接收和處理信號的純信號層問題
  判準：核心是「信號到達個體之後發生了什麼」→ 適用；否則不適用

限制（框架自身聲明）：
  ¬處理真偽（哲學的範疇）
  ¬處理價值（倫理學的範疇）
  ¬提供減少轉化的方法
  ¬預測時間（黑箱律封閉）
  ¬追蹤個體內心（P2 封閉）
  框架自身受 P1—P4 約束（框架的表述也是信號，讀者的信不同，讀出的語意不同）
