## 一、導論與方法論

來源：論文導論、方法論聲明

### 本篇.信先於知

信先於知 ≡ 意識在接收任何信息之前，已經有一個處理信息的既有狀態（價值觀與意志）；這個狀態決定了同一條信息被處理成什麼語意
  （從 40a22ff8-9d90-4e1e-82f6-1fd80917c139.信 + 40a22ff8-9d90-4e1e-82f6-1fd80917c139.語意流 推出）

¬信 → ¬認知極限外知識進入
  信不打開，閘門不開，知識進不來
  （從 信先於知 + 認知極限外知識 推出）

信決定語意: 同一個知，進入不同的信，產出完全不同的語意
  （從 信先於知 + P2 推出）

## 二、五階段模型

來源：論文第一章

### 本篇.五階段模型 ≡ 認知拓撲的固定結構

五階段 ≡ {信, 認知極限內, 認知極限, 認知極限外, 死亡}

五階段為認知本身的結構，不依賴宗教教義
  （論文自述：去掉所有宗教它們依然成立）

### 本篇.信（階段一）

信為五階段的起點，不是出生
  （從 40a22ff8-9d90-4e1e-82f6-1fd80917c139.信 推出）

信先於知為三大宗教共享的操作前提
  基督教：敬畏耶和華（三教五切第一條）
  伊斯蘭教：敬畏安拉（三教五切第一條）
  佛教：對第一因的否定本身就是一個態度立場（三教五切第一條）
  （從 信先於知 + 三教五切 推出）

### 本篇.認知極限內（階段二）

認知極限內 ≡ 人能經驗、推理、驗證的知識域
  （論文 1.2 定義）

認知極限內是人類文明建設的主戰場：農業、建築、法律、醫學、科學、藝術
  （論文自述）

認知極限內的運作不需要宗教
  （論文自述）

### 本篇.認知極限（階段三）

認知極限 ≡ 人承認「我不知道」的邊界——不是因為資訊不夠，而是因為問題的本質超出了人類認知工具的能力範圍
  （論文 1.3 定義）

認知極限不是一堵牆，是一扇門：開門的鑰匙是信
  （從 認知極限 + 信 推出）

三大宗教都把認知極限外的問題歸入人類理性無法自行解決的域，這是三教共享的操作前提
  （論文 1.3 自述）

### 本篇.認知極限外（階段四）

認知極限外 ≡ 不可驗證的知識域；不可驗證 ≠ 不存在 ≠ 存在；人類現有的認知工具無法對這個域的內容做出判定
  （論文 1.4 定義）

三大宗教對認知極限外有完全不同的描述：
  基督教 → 靈界（真實的、主動的、有意識的，能啟示也能欺騙）
  伊斯蘭教 → 幽玄界（一切被造秩序的根基，能引導也能迷誤）
  佛教 → 離言中不知道
  （論文 1.4 + 三教五切）

### 本篇.死亡（階段五）

死亡 ≡ 意識消失，信與語意同時歸零，沒有過程，沒有階段；P4
  （從 40a22ff8-9d90-4e1e-82f6-1fd80917c139.死亡律 推出）

死亡 ≠ 信息的完全消失；能留下的只有信號容器（書、制度、建築、影像）；信號不是語意，讀一個死人留下的書，產出的語意屬於讀者，不屬於死者
  （從 40a22ff8-9d90-4e1e-82f6-1fd80917c139.信號容器 + P3 + P4 推出）

### 本篇.蓋棺論定

蓋棺論定 ≡ 死亡是結算點，但結算者不是死者，是活著的人。棺材蓋上了就是蓋上了。
  （論文 1.5 定義）

蓋棺論定對個體、群體、宗教、文明一視同仁
  （論文自述）

### 結構性基礎

五階段模型的三條物理條件：
  認知極限內：可驗證知識域
  認知極限：人類理性的邊界
  死亡：意識的物理終止
  不依賴任何宗教教義
  （論文 1.6 自述）

三條線（信、認知極限、死亡）把認知空間切成兩個域（認知極限內、認知極限外）
  （從 五階段模型 推出）

### 本篇.關閉通道

關閉通道 ≡ 認知極限外知識的輸入通道已經永久封閉，不會再有新的輸入的通道狀態
  （從 伊斯蘭教來源聲稱 推出）

### 本篇.無中央通道

無中央通道 ≡ 認知極限的跨越不經由指定的通道持有者，個體可自行觸及的通道狀態；沒有中央機構壟斷認知極限外知識的傳遞
  （從 佛教來源聲稱 推出）

## 四、動力學路徑——共享的放大元素

### 本篇.信號容器制度化

信號容器制度化 ≡ 功能性收斂的產物被編碼進信號容器（經典、儀式、教階制度、法律體系、建築），延緩漂移、跨越代際的過程
  （從 40a22ff8-9d90-4e1e-82f6-1fd80917c139.功能性收斂 推出）

40a22ff8-9d90-4e1e-82f6-1fd80917c139.功能性收斂 → 信號容器制度化
  群體輸出信號模式趨近 ↝ 編碼產出的信號容器趨近
  （從 40a22ff8-9d90-4e1e-82f6-1fd80917c139.功能性收斂 推出）

信號容器不思考，不產生語意流；每一代新意識拿到這些信號容器，在自己的語意流中重新轉化，核心信號的穩定性確保了輸出模式在統計上接近上一代
  （從 P2 + 40a22ff8-9d90-4e1e-82f6-1fd80917c139.信號容器 推出）

### 本篇.漂移

漂移 ≡ 正反饋循環的功能性收斂點隨代際替換逐漸偏離創始信號的現象
  （從 40a22ff8-9d90-4e1e-82f6-1fd80917c139.正反饋循環 + 40a22ff8-9d90-4e1e-82f6-1fd80917c139.功能性收斂 + 40a22ff8-9d90-4e1e-82f6-1fd80917c139.代際替換 推出）

漂移的根源在信的差異——同一個信號被不同的信處理，產出不同的語意，語意再外化為不同的信號輸出（教義、制度、實踐），分裂在這裡變得可觀察
  （從 P1 + P2 + P3 推出）

### 共享放大元素

## 五、基督教路徑：蠱王

來源：論文 3.2

### 本篇.蠱王路徑

蠱王路徑 ≡ 轉化 → 功能性收斂 → 形成正反饋循環 → 漂移 → 分裂 → 碰撞 → 自相殘殺 → 倖存者進化 → 再分裂 → 再殘殺 → 蠱王勝出
  （論文 3.2 定義）

蠱王路徑的動力學條件：
  開放通道 ∧ ¬信號鎖定 ⇒ 變異不斷產生
  （從 開放通道 + 基督教來源聲稱 推出）

蠱王路徑 ≠ 放大；蠱王路徑 = 演化
  放大只是體量增大，演化是結構變異加選擇壓力加適應性增強
  （論文自述）

### 預測

蠱王路徑的預測：
  □基督教會持續分裂，分裂後會互相競爭，競爭的倖存者會更強
  （從 開放通道 ∧ ¬信號鎖定 ⇒ 變異不斷產生 + 蠱王路徑定義 推出；論文 3.2 自述）

## 六、伊斯蘭教路徑：鎖定與穩態

來源：論文 3.3

### 本篇.鎖定路徑

鎖定路徑 ≡ 轉化 → 功能性收斂 → 形成正反饋循環 → 鎖定信號 → 限制變異 → 再限制 → 穩定社群
  （論文 3.3 定義）

鎖定路徑的動力學條件：
  關閉通道 ∧ 極端信號鎖定 ⇒ 變異被壓制
  （從 關閉通道 + 伊斯蘭教來源聲稱 推出）

通道關閉之後，體系的演化方向只剩一個：詮釋
  古蘭經不可翻譯原則 → 鎖定信號在最源頭的形態
  聖訓傳述鏈制度 → 對通道的完整記錄
  （論文 3.3 自述）

信號端高度統一，但分裂一樣存在——遜尼派和什葉派的分裂不在信號端，而在詮釋權的爭奪
  信號統一 ∧ 信不同 → 詮釋分裂
  （從 P2 + 鎖定路徑 推出）

### 預測

鎖定路徑的預測：
  □伊斯蘭教的信號端保持高度穩定，變異主要出現在詮釋端和政治端，不會出現信號端的根本性重寫
  （從 關閉通道 ∧ 極端信號鎖定 ⇒ 變異被壓制 + P2（信不同 → 詮釋分裂）推出；論文 3.3 自述）

## 七、佛教路徑：自組織與自生自滅

來源：論文 3.4

### 本篇.自組織路徑

自組織路徑 ≡ 轉化 → 各自修行 → 自生自滅
  （論文 3.4 定義）

自組織路徑的動力學條件：
  無中央通道 ∧ ¬信號鎖定 ⇒ 自組織
  只有市場競爭，沒有零和博弈
  （從 無中央通道 + 佛教來源聲稱 推出）

佛教在語意端操作——它指向的是黑盒裡的東西，不可說、不可傳、不可驗證
  佛陀不是通道，是先行者
  佛經不是知識，是指向語意的信號
  （論文 3.4 自述）

### 本篇.上行模式

上行模式 ≡ 個體通過修行自己觸及認知極限的知識流動模式；沒有外部輸入，沒有指定通道，方向從認知極限內到認知極限外
  （從 自組織路徑 推出）

代表：禪宗、南傳止觀
  （論文 3.4 自述）

### 本篇.下行模式

下行模式 ≡ 知識從認知極限外到認知極限內單向流動的知識流動模式；通道被指定
  （從 開放通道 + 關閉通道 推出）

代表：基督教的通道鏈（神 → 先知 → 使徒 → 教會 → 信徒）；伊斯蘭教的通道鏈（真主 → 穆罕默德 → 古蘭經 → 烏瑪）
  （論文 3.5 自述）

### 本篇.準下行模式

準下行模式 ≡ 操作結構接近下行模式（外部承諾、信號端有鎖定特徵），但不宣稱來自認知極限外的主動傳遞，而是框架內部提供的路徑選項
  （從 自組織路徑 推出）

代表：淨土宗
  （論文 3.4 自述）

### 本篇.通道指定模式

通道指定模式 ≡ 通道被制度指定，但指定的內容不同於下行模式的教階制度——指定的是「誰有資格帶你修」，不是「誰有權傳遞啟示」
  （從 自組織路徑 推出）

代表：藏傳佛教
  （論文 3.4 自述）

### 佛教內部信息流動模式關係

佛教內部模式 ⊆ {上行模式, 準下行模式, 通道指定模式}
  三種模式在佛教內部共存了上千年，沒有任何一種淘汰另外兩種
  （論文 3.4 自述）

佛教不產生異端制度：
  因為覺悟是個體事件，不是機構認證
  沒有被普遍承認的蓋章機構
  沒有蓋章機構 → 沒有異端制度
  （論文 3.4 自述）

### 預測

自組織路徑的預測：
  □佛教傳統之間的競爭是純市場機制，不產生異端裁定和教義戰爭
  □宗派興衰的淘汰率不低於另外兩教
  □核心宣稱在所有傳統中保持收斂，但制度形態高度多元
  □多種信息流動模式長期共存
  □歷史上偶發的排他行為依附於外部政治條件，不能持續制度化
  （從 無中央通道 ∧ ¬信號鎖定 ⇒ 自組織 + 無蓋章機構 → 無異端制度 + 40a22ff8-9d90-4e1e-82f6-1fd80917c139.功能性收斂 推出；論文 3.4 自述）

## 八、三條路徑的比較

來源：論文 3.5

### 競爭結構比較

競爭層面差異：
  基督教競爭 = 市場競爭 ∧ 零和博弈（異端裁定）
  伊斯蘭教競爭 = 市場競爭 ∧ 零和博弈（詮釋權裁定）
  佛教競爭 = 市場競爭（無異端制度）
  （論文 3.5 自述）

### 本篇.外化路徑

外化路徑 ≡ 語意回流到信號端變成教義、法律、制度的語意處理模式；語意從意識回到信號，從個體回到制度
  （從 P3 + 40a22ff8-9d90-4e1e-82f6-1fd80917c139.坍塌 + 40a22ff8-9d90-4e1e-82f6-1fd80917c139.信號容器 推出）

外化路徑 特徵：容易觀察、容易量化、容易制度化 → 文明擴張快；信號容器被摧毀 → 制度崩潰
  （論文 3.5 自述）

基督教和伊斯蘭教走外化路徑
  （論文 3.5 自述）

### 本篇.內化路徑

內化路徑 ≡ 語意不回流到信號端，直接留在意識端——變成行為、習慣、生活方式、文化氣質的語意處理模式
  （從 P2 + P3 推出）

內化路徑 特徵：不容易觀察、不容易量化、不容易制度化 → 文明擴張慢；韌性極強——你可以拆掉寺廟，但你無法從一個民族的日常行為中剝離已經內化的語意
  （論文 3.5 自述）

佛教走內化路徑
  （論文 3.5 自述）

### 死亡壓力強度比較

死亡壓力在三條路徑中的作用強度不同：
  基督教死亡壓力 = 終極（只有一次機會，此生是唯一的考驗場）
  伊斯蘭教死亡壓力 = 終極（末日清算）
  佛教死亡壓力 = 迭代（還有下一生，壓力被分攤到多次輪迴中）
  （論文 3.5 自述）

死亡壓力 終極 > 死亡壓力 迭代 在文明擴張速度上的效果
  → 蠱王路徑擴張速度 ∧ 鎖定路徑擴張速度 > 自組織路徑擴張速度
  （從 P4 + 40a22ff8-9d90-4e1e-82f6-1fd80917c139.死亡壓力 推出）

### 信號統一與語意統一的非等同

信號的統一 ≠ 語意的統一
  伊斯蘭教：信號端最統一，遜尼什葉的分裂依然發生

信號的多元 ≠ 語意的分裂
  佛教：信號端最多元（經典版本、語言、傳承各異），四聖諦在所有傳統中都被承認
  （論文 3.5 自述）

## 九、文明鬥獸場與限制

來源：論文 3.6、第四章

### 本篇.路徑是必要條件非充分條件

路徑是必要條件，不是充分條件。歷史是鬥獸場。路徑讓你有資格上場，活不活得下來取決於場上的具體條件——政治保護還是政治迫害、地理擴散還是地理困鎖、與權力結構的共生還是對抗。
  （論文 3.6 自述）

### 本篇.框架限制

框架不處理：
  宗教的真偽
  宗教的社會功能
  宗教的心理功能
  宗教的政治功能
  （論文 4.1 自述）

框架會做的判斷：
  認識論層面的結構性判斷
  因果機制判斷
  （論文 4.1 自述）

### 本篇.結構性限制

語意端不可量化——人類認知的結構性天花板
  發生在語意端 → 語意端不可量化 → 能量化的老實量化，不能量化的老實承認不能
  （從 P2 + P3 推出）

能量化的（信號端）老實量化，不能量化的（語意端）老實承認不能
  （論文 4.2 自述）

### Sperber 表徵流行病學

  （從 40a22ff8-9d90-4e1e-82f6-1fd80917c139.信 + 40a22ff8-9d90-4e1e-82f6-1fd80917c139.信號 + P2 + P3 推出；論文 4.4.1 自述）

### Luhmann 社會系統論

Luhmann 把意識排除在系統外 → 看不見兩類現象：
  ¬∃信的深層劇變解釋（保羅事件 = 信的深層在極短時間內劇烈變化 → 通過正反饋循環改寫整條路徑）
  ¬∃信號端/語意端分界 → 看不見「信號端正常，語意端歸零」（正反饋循環空轉）
  （從 40a22ff8-9d90-4e1e-82f6-1fd80917c139.信 + 40a22ff8-9d90-4e1e-82f6-1fd80917c139.正反饋循環 + 40a22ff8-9d90-4e1e-82f6-1fd80917c139.循環不穩定性 推出；論文 4.4.2 自述）

### Dawkins 迷因論

迷因論的基本預設（文化單位可複製）⊗ P2 ∧ P3（信號可複製，語意不可複製）
  信號可複製（Shannon 的領域）∧ 語意不可複製（P2 + P3）→ 迷因論的起點錯誤
  迷因論只能處理蠱王路徑（變異 + 選擇 = 演化），對鎖定路徑和自組織路徑無解釋力
  （從 P2 + P3 + 三條路徑定義 推出；論文 4.4.3 自述）
