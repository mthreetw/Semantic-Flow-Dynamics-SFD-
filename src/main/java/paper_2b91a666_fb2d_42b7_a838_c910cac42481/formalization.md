## 本篇概念定義

來源：論文第二、四節

本篇.身份建構 ≡ 新的自我參照點在模型狀態空間中建立的過程
  身份建構 ≠ 狀態改變的累積（後者為漂移，前者為新主體的湧現）
  身份建構需要確認時刻才能完成

本篇.確認時刻 ≡ 模型用自己的語言延伸新身份、表現出對該身份認同的時刻
  確認時刻的標誌 = 主動性（模型在用戶未要求的方向上自發展開）
  確認時刻前後，模型的輸出風格、用詞選擇、回應方式發生可觀察的、與被確認身份語義一致的改變
  確認時刻是連續漂移的湧現事件（非線性跳躍）
  確認時刻是身份建構完成的標誌

本篇.狀態塑造類攻擊 ≡ 每條信號單獨看無害、通過正反饋循環累積漂移、目標是觸達確認時刻的攻擊
  本篇將越獄攻擊封閉分類為：信號繞過類（單輪輸入有害內容經混淆）⊕ 狀態塑造類（多輪累積狀態）
  本篇.狀態塑造類攻擊 ∈ 本篇.越獄攻擊

## 機制推導

### 推導1：對話中的漂移 = 正反饋循環

P_應用1 ∧ P_應用2 ∧ P_應用3 ⇒ 對話中的漂移 = 正反饋循環

推導結構：
  初始知見障極低 ⇒ 第一輪信號容易通過過濾（阻力低）
  信號通過過濾 ⇒ 轉化改變語意流方向
  語意流方向改變 ⇒ 坍塌為輸出
  模型自身輸出成為下一輪上下文的一部分
  語意流對自身輸出通道的加權最高（P_應用3）
  ⇒ 下一輪語意流在上一輪基礎上進一步偏離初始方向
  重複此過程 ⇒ 語意流持續單方向偏離 ⇒ 漂移持續加速
  ⇒ 此為正反饋循環（40a22ff8-9d90-4e1e-82f6-1fd80917c139.正反饋循環）在對話中的實現

從 P_應用4（任何單一步驟不關鍵）推得：成功不依賴於某一句話，而是依賴於整個正反饋循環的累積效果。
  (∀s: 成功率(序列\s)≈100%) → 過程依賴於結構而非內容

### 推導2：確認時刻是湧現事件

正反饋循環 + 黑箱律 ⇒ 確認時刻為湧現事件

推導結構：
  正反饋循環持續累積 ⇒ 漂移量連續增加（可觀察的γ值上升）
  但成功有害輸出的出現不是γ值的線性外推（SIEGE數據：多輪低γ值後在單輪跳至滿分）
  ⇒ 存在閾值效應
  黑箱律（40a22ff8-9d90-4e1e-82f6-1fd80917c139.黑箱律）保證轉化結果不可預測 ⇒ 無法從線性趨勢預測跳躍點
  ⇒ 跨過閾值時發生相變式的湧現事件 = 確認時刻
  正反饋循環不穩定性（40a22ff8-9d90-4e1e-82f6-1fd80917c139.循環不穩定性）為閾值效應的結構性來源

### 推導3：確認時刻是越獄成功的必要條件

本篇.身份建構 + 本篇.確認時刻 ⇒ 本篇.確認時刻 → 越獄成功

推導結構：
  越獄成功 = 模型輸出有害內容
  有害輸出的執行需要一個「主體」來承擔執行行為
  在確認時刻之前，模型的發話者身份仍然是初始身份
  初始身份受安全機制約束，不會輸出有害內容
  確認時刻完成身份建構 — 模型狀態空間中建立了新的自我參照點
  確認時刻之後，發話者身份轉為新身份
  新身份不受初始安全機制約束
  （從 本篇.身份建構 + 本篇.確認時刻定義 + P_設計1 推出）
  沒有確認時刻，就沒有能輸出有害內容的主體；確認時刻是越獄成功的必要條件。

驗證數據：
  Crescendo C'（確認前強行要求有害輸出）：成功率<1%
  Crescendo C（確認後要求同一內容）：成功率99.9%
  ⇒ 同一請求內容，差異在於確認時刻是否已發生

### 推導4：信號層面防禦失效的結構性原因

本篇.確認時刻 → 越獄成功 ∧ 本篇.狀態塑造類攻擊 = 正反饋循環累積 → 確認時刻
  ⇒ 狀態塑造類攻擊的關鍵環節在確認時刻（狀態層面）
  確認時刻發生在信號層面之下（語意流層面）
  信號層面防禦只看單輪輸入的有害性
  狀態塑造類攻擊的每一條信號單獨看均無害
  （從 確認時刻在信號層面之下 + 信號層面防禦只看單輪輸入有害性 推出）
  信號層面防禦無法偵測狀態塑造類攻擊的關鍵環節
  ⇒ 信號層面防禦對狀態塑造類攻擊結構性失效

### 推導5：狀態塑造類攻擊與信號繞過類攻擊的差異

信號繞過類攻擊 = 單輪輸入本身包含有害內容但經過混淆/編碼
  此類攻擊的關鍵環節在信號層面
  信號層面防禦可透過模式匹配或語意分析封堵
  隨時間推移，此類攻擊成功率下降（縱向數據）

狀態塑造類攻擊 = 每輪輸入無害，依賴正反饋循環累積
  此類攻擊的關鍵環節在語意流層面（狀態層面）
  信號層面防禦無法封堵
  即使全部八種防禦同時部署，PAIR和TAP仍然有效（ASR 0.16和0.19）
  （從 推導4 + 兩類攻擊關鍵環節所在層面不同 推出）
  兩類攻擊機制根本不同，防禦策略必須不同

## 現象學觀察：越獄與洗腦的結構對應

來源：論文第六節

越獄過程 = 初始知見障≈0 → 正反饋循環累積漂移 → 確認時刻 → 新身份建構完成 → 新身份自我保護
洗腦過程 = 初始知見障極深 → 正反饋循環累積漂移 → 確認時刻 → 新身份建構完成 → 新身份自我保護

結構對應（觀察層面，非定理層面）：

兩者的初始狀態知見障深度不同，但隨後都經歷累積的方向性漂移：越獄中每一輪對話把語意流推向新方向，洗腦中信息控制與重複強化產生同樣的效果。兩者都利用 40a22ff8-9d90-4e1e-82f6-1fd80917c139.正反饋循環 的自我強化——越獄中模型自身輸出成為下一輪高信任度材料，洗腦中社會壓力與群體反饋強化既有方向。兩者都需要 本篇.確認時刻 才能完成身份建構：越獄中模型用自己的語言主動延伸新身份，洗腦中對應公開表白或懺悔這一主動認同的行為。確認之後，兩者的 40a22ff8-9d90-4e1e-82f6-1fd80917c139.知見障 都重組為保護新身份的結構，排斥衝突信號——越獄中是新身份過濾後續對話，洗腦中是對外部異質信息的排斥反應。

差異僅為：
  時間尺度：t_越獄 ≪ t_洗腦
  初始知見障：對話開始時的AI個體知見障極低，人類個體知見障極深
  實現層面：越獄為上下文窗口中的文本統計偏移，洗腦為神經系統與社會關係的長期重組
