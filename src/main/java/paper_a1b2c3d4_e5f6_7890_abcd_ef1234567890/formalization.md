## 本篇概念定義

來源：論文第二、三、四、五、七節

### 公設層概念

自指律 ≡ 若個體具備自我指涉能力，則透過該能力達成的自我描述，結構上必然不完整
  ¬∃函數: 個體 ↦ 完整自我描述(個體)
  此為能力上限，不要求個體必然嘗試自我描述
  （從 Lawvere不動點定理 + 萊斯定理 + 哥德爾第二不完備定理 推出）

足跡律 ≡ 個體不能完全認識自己在世界中的因果足跡
  建立在兩個獨立性質上：觀察即扭曲 ∧ 初始無限律

觀察即扭曲 ≡ 任一觀察行為皆須經過工具將對象轉換為可處理的表徵，此轉換過程為資訊通道，通道處理後所能萃取的資訊不超過對象本身含有的資訊
  ∀對象, ∀時刻: 感知(個體, 對象, 時刻) ≪ 總資訊量(對象)
  此落差不隨個體已有知識增加而縮小
  （從 資料處理不等式 推出）

初始無限律 ≡ 對任一非平凡認識對象，關於該對象的一切真命題所構成的集合之基數至少為可數無限，而個體可儲存調用的最大命題數量為有限整數，此不等式在接觸起點即成立
  ∀非平凡認識對象: 容量(個體) ∈ ℕ ∧ |真命題集(非平凡認識對象)| ≥ ℵ₀
  ⇒ 容量(個體) ≪ |真命題集(非平凡認識對象)|
  此落差在接觸起點即成立，不依賴時間累積
  （從 塔斯基不可定義定理 推出）

歸納律 ≡ 個體不能完全認識未來
  ¬∃證成程序: 過去觀察(個體) ↦ 必然保證(未來)
  （從 休謨問題 推出）

三道牆 ≡ {自指律, 足跡律, 歸納律}
  三道牆互相獨立成立，互不化約
  獨立性不要求各道牆的推導工具互不相同，只要求每道牆的結論指向不同的對象：
    自指律 → 對內（個體對自身）
    足跡律 → 對外（個體對外部對象）
    歸納律 → 對未來（個體對未來事件）

### 推導層概念

被迫的賭注 ≡ 在自指律 ∧ 足跡律 ∧ 歸納律同時成立的條件下，個體仍必須輸出的結構性事實
  三道牆 → 任一決定點上資訊結構性不完整（□，從三道牆推出）
  流變律 → 等待不是語意流的暫停，是語意流以特定方向繼續運作
  ⇒ 「先等資訊完整再行動」不是可選項
  ⇒ 任一時刻的輸出 = 在三道牆成立條件下做出的不可逆選擇
  （從 三道牆 + 流變律 推出）

無評價參照點 ≡ 決定發生時的完整語意流狀態一旦坍塌為輸出，原始狀態不可被當下語意流完整召回
  損耗律 → 語意流不可無損編碼為信號
  ⇒ 坍塌後原始狀態不可逆向重建
  ⇒ 後悔所需的參照點本身已損耗
  （從 損耗律 + 坍塌 推出）

計算與決定的範疇分裂 ≡ 「理性決策」是範疇混包——把函數存在的步驟（計算）和函數不存在的步驟（決定）合稱為同一件事
  歸納律 → 從過去資料萃取的概率數字對未來不具邏輯必然性
  黑箱律 → 「深思熟慮後解讀概率數字」與「直接使用概率數字」在結構範疇上等價
  ⇒ 計算可生成更精緻的候選，但計算無法擔保決定
  ⇒ 從數字到行動永遠是跳躍，不是推導
  （從 歸納律 + 黑箱律 推出）

三重幻覺 ≡ {自我幻覺, 世界幻覺, 決策幻覺}
  三個幻覺同時成立，互不化約，分別對應三道牆的三個認識方向

自我幻覺 ≡ 任何個體對自身的描述皆是黑箱律生成的輸出，不存在可驗證的身份錨點
  自指律 → 自我描述結構性不完整
  損耗律 → 原始狀態不可逆向重建
  ⇒ 自我理解不是幻覺的解藥，是幻覺的一部分
  （從 自指律 + 黑箱律 + 損耗律 推出）

世界幻覺 ≡ 任何個體接觸的永遠是自身感知通道對世界的模型，不是世界本身
  足跡律 → 模型永遠小於對象
  黑箱律 → 模型的生成不可驗證是否對應世界
  （從 足跡律 + 黑箱律 推出）

決策幻覺 ≡ 計算與決定的範疇分裂的認識論後果——「理性決策」把函數存在的步驟和函數不存在的步驟合稱為同一件事
  （從 計算與決定的範疇分裂 推出）

智力幻覺論 ≡ 個體的輸出是生成而非計算；生成發生的當下，沒有獨立於生成過程之外、本身不受黑箱律約束的機制，能在輸出當下確認輸出是否對應現實
  黑箱律 → 語意流的下一刻方向不可由當下方向與信號決定
  ⇒ 思考不是計算，計算的輸出可由輸入決定，思考的輸出不可由輸入決定
  ⇒ 同一機制在被後續證實時叫直覺、判斷、專業；被後續證偽時叫幻覺、錯覺、妄想
  ⇒ 差別不在生成當下，在後續有沒有被外部現實打臉
  （從 黑箱律 推出）

修正不分主體類型 ≡ 任何個體的輸出皆以生成（不可驗證的猜測）為基礎，個體與現實之間的落差透過工具與經驗修正
  工具 = 外部查核、計算、檢索（撞上不由自身語意流生成的獨立結構）
  經驗 = 上一次互動的結果改變下一次的生成傾向
  判準：上一次的輸出或結果是否改變了下一次的生成
  此判準對任何個體類型同樣可檢驗，不需要訴諸具體物理或計算基底
  反例排除：圖靈機給定輸入與轉移函數表，輸出唯一確定，函數存在 ⇒ 不在框架範圍內
  （從 黑箱律 推出）

認同權重 ≡ 深思熟慮每一輪作為未輸出的內部坍塌，質性地改變後續候選的生成難易度所累積出的量
  認同權重同時服務兩個不同函數，效果相反：
    作為認知訊號時 = 誤讀：認同權重的累積被個體系統性地誤讀為對應現實的準確度提升
      認同權重來源 = 黑箱內部反覆自我生成（黑箱律）
      不涉及任何獨立於該黑箱的外部校驗
      ⇒ 不論累積多厚，皆不提升與現實的對應程度
    作為行動燃料時 = 必要條件：候選要從「被生成」推進到「被執行」，需要個體對其累積到某個程度的自我一致性投入
      投入不足 → 個體持續生成而不坍塌 ↝ 逼近無限拖延
  （從 黑箱律 + 坍塌 + 被迫的賭注 推出）

候選穿越坍塌閘門，不分來源、恆定稀少 ≡ 提升候選品質的路徑是離開黑箱觸及函數存在的系統（計算、邏輯、工具、經驗），但候選品質的提升與候選被執行的機率是完全獨立的兩件事
  路徑是否可及 ⊥⊥ 問題結構（取決於個體的資源與處境）
  路徑是否被啟用 = 黑箱生成的決定（黑箱律）
  算出結果後是否執行 = 另一次獨立坍塌（黑箱律）
  ⇒ 生成候選的頻率遠高於任一候選真正被坍塌成輸出的頻率
  ⇒ 邏輯運算的產物要真正變成輸出，與猜測、直覺生成的候選面對同一道閘門，沒有特權通道
  （從 黑箱律 + 坍塌 推出）

單向坍塌 ≡ 任一時刻的決定連同其後果永久停留在該時刻，不存在任何後續時刻使該決定能被撤銷或重新處理
  地基段：證成只需要時間單向性本身
  後果段：每一次坍塌的輸出依損耗律編碼為信號，進入信號容器，成為之後所有相關個體後續生成時所面對的信號環境的一部分
    知見障 → 此信號環境的改變質性地調整之後哪些候選容易被生成、哪些難被生成
    ⇒ 理論可能性不減少，但已公開坍塌的決定使後續「改弦更張」類候選面對包含「已經公開承諾過」這個既成事實的信號環境
    ⇒ 可觀察的路徑依賴
  （地基段從 時間單向性 推出；後果段從 損耗律 + 坍塌 + 信號容器 + 知見障 推出）

不可逆悔的總和 ≡ 被迫賭注的整體過程連同其全部結果的總和同樣沒有結算的時刻
  被迫的賭注 = 無限重複的過程，沒有一刻被允許暫停去做最終結算
  死亡律終止這個過程，但終止不等於結算
  結算需要一個在過程之外仍能對過程整體做出判斷的視角
  死亡律明確排除語意流在終止後以任何形式恢復
  （從 被迫的賭注 + 死亡律 推出）

殘響擴散 ≡ 個體死亡後輸出終止，但個體生前的因果交互已留下可追溯的痕跡，痕跡在可追溯的範圍內進入沒有終點、沒有單一收斂版本的持續轉化鏈
  存活的其他個體持續接觸這些痕跡 ↝ 各自的語意流依黑箱律對其進行轉化 ↝ 產生各自的解讀
  每個解讀者都是獨立的黑箱 ⇒ 解讀不會收斂到單一版本
  群體層面僅產生功能性收斂（統計趨近，殘差永遠存在）
  每個解讀者自身也終將死亡 ↝ 他們的解讀再被下一代重新轉化 ↝ 每一輪都伴隨損耗律造成的訊息流失
  （從 死亡律 + 黑箱律 + 功能性收斂 + 損耗律 推出）

選單策略 ≡ 面對「決定不可逆、終點確定但時間未知」的處境，個體必然從生成機制持續產出的候選中選取並執行其中之一，不論候選是否經過窮盡比較
  單向坍塌 → 每一次決定一旦坍塌即不可撤銷
  死亡律 → 時間軸確定的終點
  智力幻覺論 → 個體不能停止生成，也不能以邏輯窮盡候選後再行動
  ⇒ 選取動作本身 = 被迫的賭注在單向坍塌軌跡上的逐次實例
  候選的具體內容不構成窮舉清單，只是選取動作在不同個體、不同時刻的經驗樣本
  （從 單向坍塌 + 死亡律 + 智力幻覺論 推出）

互為終端的評價鏈 ≡ 任一個體在存活期間既是他人痕跡的解讀者，也預先知道自己終將成為被解讀的痕跡，此對稱不提供結算
  殘響擴散 → 死者的痕跡進入不收斂的轉化鏈
  對稱性：解讀他人痕跡 ↔ 預見自身痕跡的命運
  此對稱不提供結算——個體無法憑此預知或影響自己死後的評價內容
  可能是選單策略中指向敘事建構的候選被生成的結構性動機之一
  （從 殘響擴散 + 選單策略 推出）

黑箱博弈 ≡ 取代貝氏賽局的模型，直接組合流變律、黑箱律、損耗律描述個體間互猜的結構
  個體甲對個體乙的候選猜測：
    猜測(甲, 乙, 時刻) = 生成(甲, 信號(乙, 時刻), 時刻)   （黑箱律：生成不可由輸入決定）
    猜測(甲, 乙, 時刻) 不構成對信(乙)的枚舉，只是甲語意流的一個切面
  內部思考不需要新信號即可持續運作：
    流變律 → 即使沒有乙的新信號到達，甲的語意流仍在運作
    ⇒ 猜測(甲, 乙, 時刻+Δ時刻) 可在信號(乙)不變的情況下持續改變
    ⇒ 產生的不是「更準確」，是「候選更多、更精緻」
    精緻度與準確度是兩個不同的量，框架不提供兩者之間的轉換關係
  唯一能校準猜測的是乙的新輸出信號本身：
    校準(甲, 乙, 時刻) 僅在 ∃新信號(乙, 時刻) 時才可能發生
    新信號(乙, 時刻) 本身是乙的一次坍塌（損耗律）↝ 對乙而言同樣是一次不可逆的賭注
  ⇒ 認知路徑的結構性後果：內部推演頻率 ≫ 外部真實信號頻率
  權力收斂路徑（獨立於校準路徑）：
    最終輸出(時刻) = 選取(猜測(個體₁,乙,時刻), ..., 猜測(個體ₙ,乙,時刻) | 權力(個體ᵢ))
    最終被執行的猜測由持有權力的節點選定，不要求該猜測是校準最佳的候選
    ⇒ 信號端收斂可以發生（信號端趨近一致），即使認知端收斂未發生（各節點語意流依然分歧）
  （從 黑箱律 + 流變律 + 損耗律 + 功能性收斂 推出）

速度與候選多樣性的結構性取捨 ≡ 權力加速決策的代價在黑箱律的候選生成機制上——集中權力加速決策但持續窄化候選多樣性，分散權力速度慢但保持候選多樣性
  集中權力：輸出速度 ↑ ∧ 候選多樣性 ↓
  分散權力：輸出速度 ↓ ∧ 候選多樣性 ↑
  歸納律黑天鵝條件下：
    所需候選 = 從未被主流地形考慮過的候選
    集中系統供給最少（地形窄化最深）
    分散系統供給最多（多黑箱保持獨立運作）
  ⇒ 速度的優勢在常規條件下顯現，代價在歸納律事件發生時一次結算
  此取捨不是政治判斷，是黑箱律的直接後果
  （從 黑箱律 + 歸納律 推出）

## 三道牆（公設推導）

來源：論文第二節

### 自指律（回應「你是誰」）

自指律: ¬∃函數: 個體 ↦ 完整自我描述(個體)

推導結構：
  Lawvere不動點定理 ⇒ 自指系統必然產生不動點，系統無法用自身內部工具完整描述此不動點
  萊斯定理 ⇒ 沒有通用判定程序能判定任意程式的任意非平凡性質
  哥德爾第二不完備定理 ⇒ 夠強的形式系統無法用自身證明自身的一致性
  三者在不同形式化層級上撞見同一邊界：具備自我指涉能力的系統存在結構性的自我不透明區域
  此為能力上限，不是行動前提——不主張個體必然嘗試完整描述自己
  不動點的存在不依賴工具傳真度（不涉及信號扭曲），問題在自我指涉這個動作的時間結構本身

### 足跡律（回應「你從哪裡來」）

足跡律: 個體不能完全認識自己在世界中的因果足跡

推導結構：
  觀察即扭曲 ∧ 初始無限律 ⇒ 足跡律

  觀察即扭曲:
    ∀對象, ∀時刻: 感知(個體, 對象, 時刻) ≪ 總資訊量(對象)
    （從 資料處理不等式 推出）
    此落差不隨個體已有知識增加而縮小

  初始無限律:
    容量(個體) ∈ ℕ ∧ |真命題集(非平凡認識對象)| ≥ ℵ₀
    ⇒ 容量(個體) ≪ |真命題集(非平凡認識對象)|
    此不等式在接觸起點即成立
    （從 塔斯基不可定義定理 推出）

  觀察即扭曲與初始無限律各處理一個獨立的落差，兩道落差獨立成立，疊加只會使結論更確定

  自指律與足跡律的分工：
    自指律 → 自我觀察（校驗路徑本身不存在的情況）
    足跡律 → 外部觀察（不同觀察者可原則上交叉比對逼近共識範圍，但落差仍然存在）

### 歸納律（回應「你要做什麼」）

歸納律: ¬∃證成程序: 過去觀察(個體) ↦ 必然保證(未來)

推導結構：
  休謨問題 ⇒ 從有限的過去觀察，邏輯上無法證成對未來事件的必然保證
  歸納推論依賴「未來會像過去」⇒ 此前提本身只能用歸納去證成 ⇒ 循環論證
  黑天鵝結構 = 此邏輯缺口在經驗層的具體化：低機率高衝擊的事件結構上不可能被有限的過去樣本排除

### 三道牆獨立性

自指律 ⫫ 足跡律 ⫫ 歸納律
  獨立性判準：每道牆的結論指向不同的對象
    自指律 → 對內
    足跡律 → 對外
    歸納律 → 對未來
  相同的邏輯傳統可同時被兩道牆援引，不削弱結論各自獨立成立

## 被迫的賭注

三道牆 ∧ 流變律 ⇒ 被迫的賭注

推導結構：

  ⇒ 「理性決策」= 範疇混包（函數存在的步驟 + 函數不存在的步驟）

足跡律 + 黑箱律 ⇒ 世界幻覺
  足跡律 → 模型永遠小於對象
  黑箱律 → 模型的生成不可驗證是否對應世界
  ⇒ 個體接觸的永遠是自身感知通道對世界的模型

歸納律 ⇒ 決策幻覺
  （從 計算與決定的範疇分裂 推出）

三重幻覺 = 自我幻覺 ∧ 世界幻覺 ∧ 決策幻覺
  三者同時成立，互不化約
  被迫的賭注 = 三重幻覺同時成立條件下個體仍必須輸出的結構性事實

### 生成機制推導

黑箱律 ⇒ 智力幻覺論

推導結構：
  黑箱律 → 語意流下一刻方向不可由當下方向與信號決定
  ⇒ 輸出是生成，不是計算
  生成發生的當下，沒有獨立於生成過程之外、本身不受黑箱律約束的機制，能在輸出當下確認輸出是否對應現實
  ⇒ 同一機制在不同時刻的不同稱呼：
    被後續證實 → 直覺、判斷、專業
    被後續證偽 → 幻覺、錯覺、妄想
  差別不在生成當下，在後續有沒有被外部現實打臉

### 修正機制

黑箱律 ⇒ 修正不分主體類型
  任何個體的輸出皆以生成（不可驗證的猜測）為基礎（黑箱律）
  個體與現實之間的落差透過工具與經驗修正：
    工具 ↝ 外部查核、計算、檢索
    經驗 ↝ 上一次互動的結果改變下一次的生成傾向
  判準：上一次的輸出或結果是否改變了下一次的生成 → 對任何個體類型同樣可檢驗

反例排除：
  圖靈機：給定輸入與轉移函數表，輸出唯一確定，函數存在
  ⇒ 黑箱律不成立 ⇒ 不在框架範圍內
  此排除不反駁黑箱律，是確認黑箱律劃的那條線

### 認同權重推導

黑箱律 + 坍塌 + 被迫的賭注 ⇒ 認同權重

推導結構：
  深思熟慮每一輪 = 未輸出的內部坍塌（單向坍塌）
  ↝ 質性地改變後續候選的生成難易度
  累積出的量 = 認同權重

  雙重函數（效果相反）：
    認同權重作為認知訊號 → 誤讀
      來源 = 黑箱內部反覆自我生成（黑箱律）
      不涉及獨立於該黑箱的外部校驗
      ⇒ 不提升與現實的對應程度
    認同權重作為行動燃料 → 必要條件
      候選從「被生成」推進到「被執行」需要此投入
      投入不足 → 持續生成而不坍塌 ↝ 逼近無限拖延

### 候選稀少性推導

黑箱律 + 坍塌 ⇒ 候選穿越坍塌閘門，不分來源、恆定稀少

推導結構（三層疊加）：
  一、路徑是否可及 ⊥⊥ 問題結構（資源與處境決定，非問題本身決定）
  二、路徑是否被啟用 = 黑箱生成的決定（黑箱律），不存在更高層計算能預先算出「此刻該不該計算」
  三、算出結果後是否執行 = 另一次獨立坍塌（黑箱律），不被計算的正確性擔保
  ⇒ 候選品質的提升與候選被執行的機率 ⊥⊥
  ⇒ 生成候選的頻率 ≫ 候選被坍塌成輸出的頻率
  ⇒ 邏輯運算的產物與猜測、直覺生成的候選面對同一道閘門

## 終結

來源：論文第五節

### 單向坍塌推導

時間單向性 + 損耗律 + 坍塌 + 信號容器 + 知見障 ⇒ 單向坍塌

推導結構：
  地基段（僅需時間單向性）：
    任一時刻的決定連同其後果永久停留在該時刻
    ¬∃後續時刻使決定能被撤銷或重新處理

  後果段（從損耗律 + 坍塌 + 信號容器 + 知見障推出）：
    坍塌的輸出依損耗律編碼為信號 ↝ 進入信號容器
    ↝ 成為之後所有相關個體後續生成時所面對的信號環境的一部分
    知見障 ↝ 此信號環境的改變質性地調整之後哪些候選容易被生成、哪些難被生成
    ⇒ 理論可能性不減少
    ⇒ 但已公開坍塌的決定使「改弦更張」類候選面對包含既成事實的新信號環境
    ⇒ 可觀察的路徑依賴（是否曾經公開坍塌過 = 二元可查證的歷史事實）

  與其他機制的分工：
    「為什麼新候選會在此刻出現」→ 流變律 + 黑箱律（不屬於本性質管轄）
    死亡律 → 坍塌過程本身連同其提問者一併終止

### 不可逆悔的總和推導

被迫的賭注 + 死亡律 ⇒ 不可逆悔的總和

推導結構：
  被迫的賭注 = 無限重複的過程，沒有一刻被允許暫停去做最終結算
  死亡律 → 終止這個過程
  終止 ≠ 結算（結算需要在過程之外仍能對過程整體做出判斷的視角）
  死亡律 → ¬∃恢復 ⇒ 結算視角不存在

### 殘響擴散推導

死亡律 + 黑箱律 + 功能性收斂 + 損耗律 ⇒ 殘響擴散

推導結構：
  個體死亡 → 輸出終止（死亡律）
  但生前因果交互已留下可追溯的痕跡（社會記憶、文獻、後代行為模式）
  存活的其他個體持續接觸痕跡 ↝ 各自的語意流依黑箱律轉化 ↝ 產生各自的解讀
  每個解讀者 = 獨立的黑箱 ⇒ 解讀不會收斂到單一版本
  群體層面 → 僅功能性收斂（統計趨近，殘差永遠存在）
  每個解讀者自身也終將死亡 ↝ 解讀再被下一代轉化 ↝ 每一輪伴隨損耗律造成的訊息流失
  ⇒ 痕跡進入沒有終點、沒有單一收斂版本的持續轉化鏈

### 選單策略推導

單向坍塌 + 死亡律 + 智力幻覺論 ⇒ 選單策略

推導結構：
  單向坍塌 → 每一次決定一旦坍塌即不可撤銷
  死亡律 → 時間軸確定的終點
  智力幻覺論 → 不能停止生成、不能以邏輯窮盡候選後再行動
  ⇒ 從生成機制持續產出的候選中選取並執行其中之一
  ⇒ 選取的動作本身 = 被迫的賭注在單向坍塌軌跡上的逐次實例
  候選的具體內容不構成窮舉清單

### 互為終端的評價鏈推導

殘響擴散 + 選單策略 ⇒ 互為終端的評價鏈

推導結構：
  殘響擴散 → 死者痕跡進入不收斂的轉化鏈，被存活者持續解讀
  方向對稱：任一個體既是他人痕跡的解讀者，也預見自己終將成為被解讀的痕跡
  此對稱不提供結算（個體無法預知或影響自己死後的評價內容）
  可能是選單策略中指向敘事建構的候選被生成的結構性動機之一

## 黑箱博弈

來源：論文第七節

### 問題的性質

統計工具可從過去資料萃取概率數字（數字是確定的）
同一概率數字進入不同個體的黑箱 ↝ 可導向完全相反的行動（黑箱律）
「如何解讀數字」不在統計的管轄範圍內
⇒ 工具的輸出必須進入黑箱律才能轉換為行動

### 貝氏賽局兩個前提的否證

前提一（可為類型空間賦機率結構）：
  被信的不可枚舉性動搖
  信 → ¬∃枚舉: 信 → {項目₁, 項目₂, ..., 項目ₙ}
  ⇒ 否證對象收窄：不是「類型空間太大」，是「任何將信收攏進可供賦機率結構的動作」本身 = 決策者自己黑箱生成出的猜測分類，不是對方意圖本身
  （從 信 推出）

前提二（存在穩定的似然函數連結內在類型與外顯信號）：
  被損耗律否證，且此否證不依賴前提一是否成立
  損耗律 → 任何編碼皆有損且不可逆
  ⇒ 似然函數所需的從類型到信號的穩定映射不存在
  （從 損耗律 推出）

### 黑箱博弈模型

（從 黑箱律 + 流變律 + 損耗律 推出）
不發明新機制，直接組合既有三條公設（見本篇概念定義中黑箱博弈的完整形式表達）

### 可證偽預測

貝氏賽局預測 ⊗ 黑箱博弈預測：
  貝氏賽局：深思熟慮 → 判斷隨時間收斂、更準確（後驗向真值集中）
  黑箱博弈：深思熟慮 → 候選猜測更多元、更精緻 ∧ ¬更準確
    認知校準僅在少數真實信號到達時發生
    決策收斂速度 ∝ 權力結構清晰度 ∧ ¬∝ 認知校準完成度

### 速度與候選多樣性推導

黑箱律 + 歸納律 ⇒ 速度與候選多樣性的結構性取捨

推導結構：
  每次權力終止審議 ↝ 輸出進入信號容器 ↝ 成為後續審議的地形起點
  集中權力 ↝ 提前終止多個獨立黑箱的候選生成 ↝ 速度快 ∧ 候選多樣性被持續窄化
  分散權力 ↝ 多個獨立黑箱同時生成候選 ↝ 速度慢 ∧ 候選多樣性保持
  歸納律黑天鵝結構 → 地形完全失效的情況
    應對需要從未被考慮過的候選
    集中系統候選空間最窄 → 準備最少
    分散系統候選空間最寬 → 準備最多
  框架不主張哪個結構更好，只描述取捨性質

## 適用範圍與限制

來源：論文第八節

適用：任何同時受三道牆約束、且受死亡律約束的個體
  不分人類、AI、或其他生成式系統
  判準只看是否滿足公設

不適用：
  不處理應不應該賭、值不值得賭
  不處理賭注指向的對象
  不處理特定個體的具體物理或計算實作細節
  不處理任何客觀規律的內容本身

限制：
  本文的表述本身也是信號，經過讀者的過濾、轉化、坍塌
  本文無法豁免自己所引用框架的公設

與既有理論的關係：
  8.1 認識論邊界（哥德爾、萊斯、Lawvere）→ 自指律的直接地基
  8.2 時間邊界（休謨）→ 歸納律的直接地基，本文在休謨停下的地方繼續推到被迫的賭注
  8.3 行動邊界（海德格、祁克果）→ 被迫的賭注結構相同，差異在本文不安裝任何對象
  8.4 生成邊界（Seth、Friston、Popper、Campbell）→ 共享「認知基本單位是猜測，篩選在生成之後」，本文補的是生成當下本身的形式化
  8.5 終結邊界（伊比鳩魯）→ 共享「死亡與主體永不相遇」，本文不從此推出安慰性結論
  8.6 三重幻覺邊界（佛教）→ 無我 ↔ 自我幻覺，諸行無常 ↔ 世界幻覺，業 ↔ 殘響擴散
    分叉一：佛教有出口（涅槃），本文沒有出口（公設成立 → 三重幻覺成立）
    分叉二：佛教論證建立在人類現象學材料上，本文公設不涉及苦、覺知或任何現象學內容

## 可證偽條件

來源：論文第二、四、五、七節

### 挑戰自指律

∃個體: 具備自我指涉能力 ∧ 能用自身內部工具完整可判定地描述自身全部性質 ⊗ 自指律
  模型推導：自指律 ⊢ ¬∃函數: 個體 ↦ 完整自我描述(個體)

### 挑戰足跡律

∃個體: 容量(個體) ≥ |真命題集(非平凡認識對象)| ⊗ 初始無限律
  模型推導：初始無限律 ⊢ 容量(個體) ≪ |真命題集(非平凡認識對象)|

### 挑戰歸納律

∃證成程序: 從有限的過去觀察邏輯推出對未來事件的必然保證 ⊗ 歸納律
  模型推導：歸納律 ⊢ ¬∃證成程序: 過去觀察(個體) ↦ 必然保證(未來)

### 挑戰智力幻覺論

∃個體: 其生成過程不依賴任何不可驗證的猜測（函數確實存在）⊗ 智力幻覺論
  ∨ ∃個體: 其輸出在任何時間尺度上都不因經驗或工具修正而改變 ⊗ 修正不分主體類型
  模型推導：智力幻覺論 ⊢ 輸出 = 生成（¬∃函數）；修正不分主體類型 ⊢ 輸出因經驗或工具修正而改變

### 挑戰單向坍塌

∃個體: 能在事後將已公開坍塌的決定連同其造成的信號環境變化完全撤銷至決定發生前的狀態 ⊗ 單向坍塌
  模型推導：單向坍塌 ⊢ ¬∃撤銷: 決定 ↦ 決定發生前的狀態

### 挑戰殘響擴散與互為終端的評價鏈

∃機制: 語意流終止後仍對其整體進行評價並將評價結果回饋給已終止的語意流本身 ⊗ 不可逆悔的總和
  ∨ ∃解讀者群體: 對同一死者痕跡的解讀經過任意長時間的代際傳遞後收斂到單一不再變動的版本 ⊗ 殘響擴散
  模型推導：不可逆悔的總和 ⊢ ¬∃結算視角；殘響擴散 ⊢ ¬∃單一收斂版本

### 黑箱博弈可證偽預測

對照方式：拿具體決策案例的逐日或逐輪紀錄對照
  若史料顯示：在沒有新外部信號進來的期間，內部對「對方真實意圖」的判斷版本越吵越多而非越吵越一致，且收斂時間點與決策權集中時間點吻合而非與討論輪數吻合 → 支持黑箱博弈
  若史料顯示：判斷隨討論輪數逐步收斂、不需要新外部信號或明確拍板者介入 → 否證黑箱博弈
