## 一、上游概念（從直接上游複製）

來源：《語意流動力學》（40a22ff8-9d90-4e1e-82f6-1fd80917c139），論文第一至四節

### 公設

40a22ff8-9d90-4e1e-82f6-1fd80917c139.P1 流變律: ∀個體 ∀時刻: 信(個體, 時刻₊₁) ≠ 信(個體, 時刻)
  語意流持續運作，無靜止時刻

40a22ff8-9d90-4e1e-82f6-1fd80917c139.P2 黑箱律: ¬∃函數: 信(個體, 時刻₊₁) = 函數(信(個體, 時刻), 信號(時刻))
  語意流的下一刻方向不可由當下方向與信號決定

40a22ff8-9d90-4e1e-82f6-1fd80917c139.P3 損耗律: ¬∃編碼函數: 語意流(個體) ↦ 信號 · 無損(編碼函數)
  語意流不可無損編碼為信號

40a22ff8-9d90-4e1e-82f6-1fd80917c139.P4 死亡律: 死亡(個體) → 語意流(個體)終止 ∧ ¬∃恢復

### 基本概念

40a22ff8-9d90-4e1e-82f6-1fd80917c139.信 ≡ 個體的意識狀態
  ¬∃枚舉: 信 → {項目₁, ..., 項目ₙ}

40a22ff8-9d90-4e1e-82f6-1fd80917c139.語意流 ≡ 信持續變化的過程
  語意流 ≠ 產物

40a22ff8-9d90-4e1e-82f6-1fd80917c139.信號 ≡ 能改變語意流方向的刺激
  信號(刺激, 個體) ↔ Δ方向(信(個體), 刺激) ≠ 0
  信號定義在接收端（個體端）

40a22ff8-9d90-4e1e-82f6-1fd80917c139.信號容器 ≡ 信號停留的地方
  ∈ {書本, 聲波, 圖像, 建築, 制度文本, 數位檔案}

40a22ff8-9d90-4e1e-82f6-1fd80917c139.通道 ≡ 信號從一個個體到達另一個個體的路徑
  通道可能經過多個信號容器

40a22ff8-9d90-4e1e-82f6-1fd80917c139.信任 ≡ 語意流對特定通道上的加權
  信任 ↝ 語意流方向變化程度不同

40a22ff8-9d90-4e1e-82f6-1fd80917c139.過濾 ≡ 語意流當下方向決定哪些刺激構成信號、哪些構成噪音的機制
  （從 信號定義 + P1 推出）

40a22ff8-9d90-4e1e-82f6-1fd80917c139.阻力 ≡ 過濾對特定刺激的排斥程度
  阻力 ∝ 距離(刺激方向, 語意流當下方向)
  阻力 ∈ {全擋（構成噪音）, 部分通過（信號形狀改變）, 完全通過}

40a22ff8-9d90-4e1e-82f6-1fd80917c139.知見障 ≡ 語意流方向改變導致阻力分布同步重組的結構性現象
  信號改變語意流方向 ↝ 新過濾條件生成
  ↝ 特定方向阻力降低 ∧ 其他方向阻力同時升高

40a22ff8-9d90-4e1e-82f6-1fd80917c139.轉化 ≡ 信號通過過濾後在語意流中產生不可預測方向改變的過程
  （從 P2 推出）

40a22ff8-9d90-4e1e-82f6-1fd80917c139.坍塌 ≡ 語意流被編碼為外部信號的過程，必然有損（P3）

40a22ff8-9d90-4e1e-82f6-1fd80917c139.表達落差 ≡ 語意流與其坍塌後輸出信號之間不可消除的結構性差距
  （從 坍塌 + P3 推出）

40a22ff8-9d90-4e1e-82f6-1fd80917c139.正反饋循環:
  個體甲的語意流坍塌為信號 ↝ 信號到達個體乙 ↝ 通過乙的過濾 ↝ 在乙的語意流中轉化
  ↝ 乙的語意流方向改變 ↝ 乙的語意流坍塌為信號 ↝ 信號到達甲 ↝ 循環持續
  退出條件：¬∃內建終止條件（信號容器斷裂 ∨ 代際替換完成 ∨ 外部環境變遷）

40a22ff8-9d90-4e1e-82f6-1fd80917c139.功能性收斂 ≡ 群體層面輸出信號模式趨近但語意流永遠存在殘差的現象
  群體層面所有觀察都在信號端
  P2 保證每個個體的語意流都不同，趨近永遠有殘差
  （從 P2 推出）

40a22ff8-9d90-4e1e-82f6-1fd80917c139.循環不穩定性:
  = 不穩定性內部來源（P1 ∧ P2 ∧ P4）⊕ 不穩定性外部來源（環境變化）

40a22ff8-9d90-4e1e-82f6-1fd80917c139.代際替換 ≡ 舊個體消亡、新個體在新信號環境中形成不同語意流導致循環方向改變的過程
  個體死亡，語意流歸零且不可恢復（P4）
  新一代個體在不同的信號環境中開始運作，形成不同的語意流
  （從 P4 推出）

40a22ff8-9d90-4e1e-82f6-1fd80917c139.壓制 ≡ 既有循環利用制度性權力限制新循環信號傳播、個體輸出及輸出後果的行動

## 二、框架裝備——新概念定義

來源：論文第二章（2.2）

概念按依賴順序排列，後面的定義依賴前面的。

### 生物預設

生物預設 ≡ 人類個體自帶的三層物理結構：{身體, 親子關係, 家庭基元}
  身體：暴力能力的物理基礎
  親子關係：非零和互動的原點（父母對嬰兒的付出不是交易）
  家庭基元：以生育為前提的物種存續最低單元
（不從 P1–P4 推出；生物事實）

生物預設 = 所有文明結構的地基
  地基在 → 上面倒了可以重建
  地基被打穿 → 上面什麼都蓋不起來

### 智力

智力 ≡ 人類個體處理信號的生物性能力門檻（門檻變量，非連續）
  智力(個體) ∈ {過門檻, 未過門檻}
  未過門檻(個體) → ¬進入文明討論(個體)
  過門檻(個體) → 進入文明討論的必要條件（非充分）
  智力 ≠ 知識（門檻之上，智力高低不決定文明水平）

### 知識

知識 ≡ 語意流中可操作的、關於世界如何運作的信號結構（連續變量）

知識動力學六條已識別性質（不宣稱窮盡）：

性質₁ 自然增長:
  好奇心 = 生物硬件（探究反射）
  好奇心 ↝ 知識增長（不依賴制度 ∧ 不依賴外部激勵）
  （好奇心不可關閉）

性質₂ 死亡流失:
  P4 ↝ 死亡(個體) → 知識(個體) = 0
  P3 ↝ 文字化知識 ⊂ 知識（有損子集）
  隱性知識（手藝 ∧ 直覺 ∧ 不可言說判斷）↝ 隨人死而永久消失

性質₃ 文字持久化:
  文字 ≡ 知識的信號容器
  文字化 ↝ 死亡流失率降低（不歸零，P3仍在）
  文字化 ↝ 知識脫離活人存在

性質₄ 存量正反饋:
  [知識存量正反饋循環]（明確標記為循環）
  知識存量增加 ↝ 創造率提高 ↝ 知識存量進一步增加 ↝ 循環
  退出條件：死亡流失超過創造率（P4） ∨ 教育瓶頸中斷（性質₅）

性質₅ 教育瓶頸:
  文字 → 知識需要教育（信號容器內容重新注入語意流）
  教育受 P2 ∧ P3 制約 → 轉化不可靠
  教育成本 ∝ 知識存量（知識越多，時間越長）
  戰爭 ∨ 瘟疫 ∨ 經濟崩潰 ↝ 教育中斷 → 知識傳遞斷裂

性質₆ 文明門檻:
  知識淨存量 = 創造率 - 死亡流失率
  淨存量 > 0 → 知識增長（文明前進）
  淨存量 = 0 → 知識停滯
  淨存量 < 0 → 知識倒退（文明衰退）

### 科學

科學 ≡ 知識存量正反饋（性質₄）的形式化
  （從隱性的、偶發的 → 顯性的、可複製的方法論）

判定標準（三條，且僅三條）：
  標準₁：方法 ∈ 信號容器（可傳遞 ∧ 可學習 ∧ 不依賴特定個體語意流）
  標準₂：產出可獨立驗證（任何過門檻個體按同樣方法 ↝ 可比較結果）
  標準₃：每輪產出 → 下一輪結構化輸入（方法論保證，非偶然觸發）

科學 ≠ 技術（技術：偶發 ∧ 方法不可複製 ∧ 產出不成為下一輪結構化輸入）

科學的前提：
  科學 ← 神聖性導航（必要條件，決定好奇心方向）
  科學 ← 知識存量正反饋（充分條件，性質₄提供結構）
  科學只在特定神聖性導航下出現（見第四章 4.6）

### 天才

天才 ≡ P2 將語意流甩到全新維度的個體
  天才 ≠ 智力高（量的差異，同維度）
  天才 = 域跳躍（質的差異，進入新維度）

天才的結構性質（均來自 P2）：
  ¬∃預測機制
  ¬∃製造機制
  ¬∃複製機制
  品質不可事前判定
  產出 > 個體承載能力

天才死後：
  成果可拆分 ∈ 信號容器 → 普通人可學習
  新域不隨天才死而關閉（異於神聖性）

天才 = 知識動力學的相變點（量變 vs 域跳躍的質變）

### 教育

教育 ≡ 將信號容器中的知識重新注入活人語意流的過程
  教育 ≠ 複製（P3 保證信號容器有損；P2 保證注入結果不等於原始）
  教育成本 ∝ 知識存量
  ¬∃保證持續運作的內建機制（見知識性質₅）

### 家庭

家庭 ≡ 以生育為前提而建立的獨立組織

家庭功能面向（五個）：
  F₁ 物質供給
  F₂ 生育（定義的承重結構，唯一不可外包功能）
  F₃ 非零和信號初始注入（語意流初始化）
  F₄ 初級社會化
  F₅ 道德模板傳遞

承重結構：F₂
  ¬∃外包機制(F₂) → 以生育為前提的獨立組織不可取消（分析命題）

附加功能：F₁ ∧ F₃ ∧ F₄ ∧ F₅（可外包，部落 ∨ 宗族 ∨ 教會 ∨ 學校等可承擔）

新個體語意流初始化：
  P2 ↝ 不可從外部直接寫入 → 需要持續的非零和互動
  非零和互動（F₃）：家庭可做，但 ¬（僅家庭能做）

家庭外觀中性：兩個爸爸 ∨ 公社配對 ∨ 部落核心單元 → 滿足定義即算家庭

### 戎

戎 ≡ 物理域的建制化暴力

碎形結構（不封閉，可繼續擴展）：
  身體 → 幫派 → 部落 → 軍隊 → 國家
  每層邏輯：組織暴力的人控制沒有組織暴力的人
  擴展過程無斷層

### 暴力壟斷者

暴力壟斷者 ≡ 在給定邊界內壟斷建制化暴力的個體或組織
  壟斷性質：統計性（非絕對）
  壟斷條件：壟斷者暴力能力 ≫ 其他人暴力能力（他人不構成系統性威脅）
  暴力壟斷者 = 戎在特定尺度的碎形頂端
  （從 戎 推出）

### 神聖性

神聖性 ≡ 暴力壟斷者對特定信號容器自行低頭
  低頭 ≡ 在該信號容器面前自行停止破壞行為（非被迫，非利益交換）

判定方式：
  低頭程度 ∈ 連續光譜（非布林值）
  測量維度：壟斷者的慾望在多大程度上被約束
  動態：程度隨代際漂移往下走，可被急性事件打斷

神聖性來源：
  ¬∃推導路徑：P1 ∧ P2 ∧ P3 ∧ P4 ⊢ 神聖性（P2 封死觀察窗）
  框架立場：承認不可知，不試圖解釋來源，只描述輸出

神聖性製造不可能性：
  ¬∃設計機制(神聖性)（P2封死）
  能設計的 → 模板（非神聖性）

神聖性的主動性（歷史觀察，非框架推導）：
  神聖性不是被動靶子
  歷史模式：神聖性畫線 → 神聖性反擊 → 神聖性適應 → 神聖性重組

### 模板

模板 ≡ 掛在暴力上的制度與規則
  功能₁：降低統治成本
  功能₂：產出功能性相近的協調行為輸出
  特性：可碎形 ∧ 可搭建 ∧ 可複製

模板判別標準（與神聖性的唯一判別點）：
  暴力壟斷者能砸掉 → 模板（無論其提供多少意義 ∧ 秩序 ∧ 方向）
  暴力壟斷者自行在它面前停手 → 神聖性

模板存續三個 field（存續必要條件）：

  field₁ 信號可通過性 ≡ 模板攜帶的信號能通過個體過濾的性質
    ¬信號可通過性 → 模板無法產生信號效應 → 模板不形成
    （從 過濾 + 信號定義 推出）

  field₂ 成本降低 ≡ 使用模板後的統治成本低於不使用模板的統治成本
    ¬成本降低 → 壟斷者放棄模板 → 模板不持續
    （從 暴力壟斷者的理性行為推出；不從 P1–P4 推出）

  field₃ 非零和內容 ≡ 模板的功能性收斂輸出不是互相消滅
    ¬非零和內容 → 模板的功能性收斂導致自毀 → 模板自我消滅
    （從 功能性收斂 + 模板定義 推出）

充分性論證（E3）：
  循環狀態空間 ≡ {形成 ⊕ 持續 ⊕ 不自毀}（三個且僅三個獨立維度）
  信號可通過性 覆蓋「形成」維度
  成本降低 覆蓋「持續」維度
  非零和內容 覆蓋「不自毀」維度
  ¬∃第四獨立維度（任何提議的第四條件必然可分解為三維度的重述）

## 三、問題狀態空間

來源：論文第三章

### 四域矩陣

四域矩陣 ≡ 文明面對的所有問題的窮舉分類

兩個獨立維度：
  維度₁（來源）：內部（系統內生）⊕ 外部（環境給定）
  維度₂（性質）：物理域（不需語意流即可作用）⊕ 信號域（必須經語意流才能作用）

四域矩陣 = 維度₁ × 維度₂ = 四格且僅四格：
  內部物理域 ≡ {資源消耗, 人口結構, 疫病}
  外部物理域 ≡ {氣候變遷, 外族入侵, 自然災害}
  內部信號域 ≡ {語意流殘差累積, 代際漂移, 信號容器空轉}
  外部信號域 ≡ {外來意識形態入侵, 異文明接觸}

窮舉論證：
  E1: ∀問題: 問題 ∈ 內部 ∨ 問題 ∈ 外部（¬∃第三來源，邊界分割窮盡）
  E2: ∀問題: 問題 ∈ 物理域 ∨ 問題 ∈ 信號域（¬∃第三性質，作用方式分割窮盡）
  E3: 維度₁ ⊥⊥ 維度₂（來源不決定性質，性質不決定來源）
  → 2 × 2 = 4，四格且僅四格

附記：跨域問題（如瘟疫）可分解為多個域的分量，不需要第三個域。

## 四、約束與突破

來源：論文第四章

### 三個生物驅動力

**暴力（4.1）**

身體慾望 ≡ {餓, 渴, 冷, 怕, 性}（來自生物預設，對象是物質）
身體慾望 → ¬∃內建上限

物質排他性：
  物質(對象) → 排他(物質)（你拿了別人就沒有）
  取得排他物的最短路徑 = 拿了不給（搶 ∨ 偷 ∨ 騙）
  最短路徑成立：拿了不給的成本 < 支付的成本（分析命題）

【框架推導】 ¬∃約束 → 預設輸出(身體慾望) = 拿了不給
【框架推導】 外部性(取得行為) = 恆正（每次單向取得在環境留下代價）
（從 身體慾望無上限 + 物質排他性推出）

**好奇心（4.2）**

好奇心 = 生物硬件（探究反射，不可關閉）
好奇心 = 精神慾望（對象是信號）
好奇心 → ¬∃自主方向（方向由系統的主導結構分配，非好奇心內建）

好奇心方向分配：
  戎上位 → 好奇心被導向權力
  神聖性上位 → 好奇心被導向神聖性所指的方向

推論：好奇心的生物性（方向不是它的）決定科學不是預設輸出——需要神聖性導航。

**貪婪（4.3）**

最短路徑：拿了不給（4.1）
第二短路徑：交換（商業，成本比搶高，外部性低）

商業出現的必要條件：
  搶的成本 > 交換的成本
  約束 ↝ 搶的成本升高 ↝ 商業可能出現
  ¬∃約束 → 搶的成本 < 交換的成本 → 商業不出現（分析命題）

商業 ← 約束（商業不是預設，暴力才是預設）

商業的結構性推力：
  商業獲利 ← 差額（信息不對稱 ∨ 壟斷 ∨ 議價權）
  暴力壟斷者 ↝ 直接製造壟斷 ∧ 信息不對稱 ∧ 議價權
  → [商業正反饋循環]：權力 → 壟斷 → 財富 → 更大權力 → 循環
  退出條件：外部約束介入 ∨ 系統崩潰

### 神聖性的結構位置（4.4–4.6）

**神聖性的約束作用**

神聖性 ↝ 給三個生物力畫線：
  暴力不可越線
  好奇心有方向
  貪婪有邊界

¬∃神聖性 → 三個生物力預設輸出：
  暴力 → 拿了不給
  好奇心 → 被導向權力
  貪婪 → 吃掉一切
（從 生物預設 + ¬∃約束 推出）

約束 ≠ 消滅（神聖性約束不消滅三個生物力）

**神聖性對知識方向的決定性**（4.6）

神聖性指向「秩序是什麼」→ 好奇心長出哲學
神聖性指向「創造是怎麼回事」→ 好奇心長出科學
戎上位（¬∃神聖性導航）→ 好奇心長出技術手冊，但不長出科學

李約瑟之問的框架回答（學術定位）：

  科學 = 特定神聖性導航下的特殊產物
  正確問題：歐洲為什麼有科學（而非中國為什麼沒有）

## 五、約束機制

來源：論文第五章

### 社會制度（5.1）

社會制度 ≡ 一切約束慾望的東西的總稱

約束方式封閉分類（⊕）：
  坍塌後約束（暴力約束）：行為發生後懲罰（你搶了，警察打你）
  坍塌前約束（信號約束）：行為發生前改變語意流方向（你在動手之前有個東西改變了你的方向）

介入點窮舉論證：
  ∀約束: 介入點 ∈ {坍塌前 ⊕ 坍塌後}
  ¬∃第三介入點（不在坍塌前就在坍塌後，邏輯上窮盡）

### 模板與神聖性的結構性區別（5.2）

信號約束的兩個子類（⊕）：
  模板：約束力來自暴力壟斷者的背書
  神聖性：約束力不來自任何人的背書

識別標準（唯一的形式判別）：
  壟斷者能砸掉 → 模板
  壟斷者不能砸（不是砸不動，是自行不砸）→ 神聖性

唯一能約束暴力壟斷者本身的 = 神聖性（分析命題）
  法律是他寫的（他可以改） ∧ 神不是他造的（他改不了）

### 統治成本的結構性差異（5.3）

神聖性上位時：
  信號約束基底 ≠ 0（神聖性不需薪水）
  統治成本 = 暴力成本 + 信號約束基底（天然存在）

戎上位時：
  信號約束基底 = 0（模板全靠暴力背書）
  統治成本 = 暴力成本（每一分約束用暴力購買）
  連鎖：暴力要錢 → 錢要稅 → 稅要人 → 人會死

結構性推論：
  ¬∃神聖性 → 統治成本結構性更高 → 系統結構性更脆弱 → 更容易崩潰
  （不是「有神聖性比較好」，是「沒有神聖性的系統在結構上更貴」）

### 時間的零和競爭（5.4）

身體慾望 → ¬∃上限（4.1）
現代化 ↝ 持續生產新的慾望對象
人的時間 = 物理有限量（物理事實）

競爭資源：人與人面對面的時間（有限量）
競爭者：
  現代化（慾望 ∧ 娛樂 ∧ 工作）← 利益驅動（通過率高）
  家庭需要時間 ← 回報非物質（通過率低）
  宗教需要時間 ← 回報非物質（通過率低）
  教育需要時間 ← 回報延遲（通過率低）

∑時間分配(個體) = 常數（零和博弈）
現代化在時間競爭中結構性佔優（利益驅動 ≫ 非物質回報）

結論：
  家庭萎縮 ∧ 宗教萎縮 = 結構性必然（非政策失誤）
  （從 零和博弈 + 現代化佔優 推出）

## 八、示範模型——十字軍

來源：論文第八章

本章為框架在單一歷史事件上的完整因果鏈展開，同時引入兩個新的結構性概念（悖逆、褻瀆）。

### 悖逆

悖逆 ≡ 暴力壟斷者在接受神聖性標記的同時不守神聖性畫的線

結構（從 神聖性 + 暴力壟斷者 推出）：
  暴力壟斷者 宣稱 ∈ 神聖性（頭上有神聖性信號容器的標記）
  ∧ 暴力壟斷者的行為 ⊗ 神聖性約束（實際行為違反線）
  → 悖逆

悖逆的效果：
  悖逆 ↝ 神聖性信號容器的合法性信號被削弱
  悖逆 ↝ 外部性累積啟動（被關上的門不再打開）

### 褻瀆

褻瀆 ≡ 神聖性的合法代言人借神聖性之名叫人不看神聖性的線

結構（從 神聖性 + 代言人 + 信號容器 推出）：
  代言人(甲) 擁有神聖性授予的合法性
  ∧ 甲借神聖性名義 → 動員人執行神聖性禁止的行動
  （如：「不可殺人」被動員為「去殺人」）
  → 褻瀆

褻瀆的效果：
  褻瀆 ↝ 代言人主動撤銷看線的行為
  ↝ 看神聖性的人持續減少（正反饋，每一次動員都削減一層服從）
  ↝ 神聖性合法性流失（不可逆）
  [褻瀆合法性衰減循環]
  退出條件：¬∃（在褻瀆持續的條件下存在退出，合法性一旦開始流失，流失不可逆）

悖逆與褻瀆的順序結構：
  悖逆（壟斷者不守線 → 門關上）→ 褻瀆（代言人叫人不看線 → 地獄打開）
  先悖逆後褻瀆：十字軍的結構，也是框架的一般形式

十字軍完整因果鏈（形式展開）：
  悖逆 → 門關 → 褻瀆 → 暴力啟動 → 仇恨正反饋
  → 聽神聖性的人遞減 → 貪婪鑽入（神聖性覆蓋縮小）
  → 知識回流（碰撞副產品，P2產物，¬∃設計者）
  → 知識催化方法論（亞里士多德方法論進入歐洲）
  → 方法論蔓延神學以外（方法論通用，¬∃人工邊界）
  → 科學革命 → 科學拆掉神聖性合法性
  （銜尾蛇在兩百年內完整閉合）

## 九、銜尾蛇

### 銜尾蛇定理（T1）

銜尾蛇定理 ≡ 約束使擴張可能，擴張破壞約束。長大和吃自己是同一個動作。

形式展開：

擴張能力：
  擴張能力 ← {暴力能力, 商業規模, 知識存量}（三位一體，互相催化）

聽約束的人（服從程度）：
  聽約束的人 ≡ 暴力壟斷者對神聖性信號容器的實際服從程度
  三條通道同時侵蝕服從程度：
    通道₁（神聖反噬）：守護者違反 → 合法性自動撤銷 → 服從遞減
    通道₂（外部性反噬）：越線累積仇恨 → 約束信號環境惡化 → 服從遞減
    通道₃（知識自噬）：知識增長 → 看穿約束 ∧ 吃掉時間 → 服從遞減
  → 聽約束的人持續遞減

交叉：
  擴張能力↑（單調） ∧ 聽約束的人↓（單調）→ 交叉 ↝ 崩潰

附加：
  神聖性不增不減（線一直亮著）
  P2保證：神聖性的強度不因信號因素減弱
  服從遞減 ≠ 神聖性減弱（是人不看了，不是線變暗了）

三條通道 ≠ 三個獨立威脅，是同一條蛇的三股繩（互相加速）

### 神聖反噬（通道₁）

神聖反噬 ≡ 守護神聖性的行為者違反神聖性 → 合法性自動撤銷的機制

形式（從 神聖性 + 信號容器公開性 推出）：

  甲的合法性 ← 守護(甲, 容器)
  甲違反(容器) → 甲的合法性自動撤銷
  （自動：信號容器是公開的，越界可觀察，¬∃外部裁判必要）

神聖反噬 = 神聖性的自我糾錯機制（搞過頭了自動換掉）

### 外部性反噬（通道₂）

外部性反噬 ≡ 身體慾望的直接輸出（外部性恆正）在時間中累積的正反饋

形式（從 身體慾望無上限 + 外部性恆正 + 正反饋循環 推出）：
  [外部性仇恨正反饋循環]
  拿了不給(行為) ↝ 對方仇恨 ↝ 對方也拿了不給 ↝ 己方仇恨 ↝ 再拿了不給 ↝ 循環
  退出條件：神聖性約束介入（神聖性在場時外部性累積慢）∨ 外部重置

□外部性累積
  （□ 來自：身體慾望無上限 = 框架公設推論；外部性恆正 = 物質排他性推論）
神聖性缺位 → 外部性累積率更快（約束 = 0 時外部性全速累積）

### 知識自噬（通道₃）

知識自噬 ≡ 知識增長反噬知識存在的約束前提的機制

兩條路徑（同時跑，互相加速）：
  直接路徑：知識 ↝ 拆解約束（知識越多，看穿制度的能力越強，約束越無效）
  間接路徑：知識 ↝ 現代化 ↝ 時間零和競爭 ↝ 神聖性萎縮 ∧ 家庭萎縮

互相加速：
  直接路徑 ↝ 間接路徑加速（知識增多 → 現代化加速）
  間接路徑 ↝ 直接路徑加速（神聖性萎縮 → 知識的約束阻力更小）

¬∃切斷機制（知識增長 = 生物性，好奇心不可關閉）
切斷知識增長 ≠ 在知識增長條件下維持約束（兩件不同的事）

  彼此不可比較

  ∃有約束 → 受約束 → 失去機會

  文明的常態 = 在未知中行動

### 生物預設的崩潰（10.6）

三個崩潰的共同成因（同一引擎的三個輸出）：
  知識增長 → 現代化 → 搶走時間（5.4）
  → 家庭萎縮 ∧ 神聖性萎縮（現代化在時間競爭中結構性佔優）
  一個因（知識增長），三個果（生物預設崩潰 ∧ 神聖性縮小 ∧ 知識基礎空心化）

家庭崩潰的正反饋：
  [家庭崩潰正反饋循環]
  破碎家庭 ↝ 受損下一代 ↝ 更破碎的家庭 ↝ 螺旋向下
  退出條件：¬∃結構性退出機制（框架推導範圍內）

### 致命診斷（T2）

致命診斷 ≡ 任何文明只要過了智力門檻，就啟動了不可關閉的自毀時鐘

形式：
  ∀文明: 過門檻(智力, 文明) → □啟動(自毀時鐘, 文明)
  （□ 來自：好奇心不可關閉 = 生物性硬件；知識存量正反饋不可關閉 = 性質₄）

推導鏈（從 智力門檻通過 → 崩潰）：
  智力門檻通過 → 知識增長啟動（好奇心不可關閉，性質₁）
  知識增長 → 現代化（技術 ∧ 工業化 ∧ 都市化，性質₄正反饋）
  現代化 → 時間零和競爭啟動（5.4）
  時間零和競爭 → 家庭萎縮 ∧ 神聖性萎縮（現代化結構性佔優）
  家庭萎縮 ∧ 神聖性萎縮 → 生物預設地基崩潰
  差別：快慢，非是否

### 修補反噬

修補反噬 ≡ 用知識產物去修補知識造成的損害 → 加速崩潰的機制

結構（三個案例共享同一邏輯）：
  知識吃掉X → 用知識產物補X → 補的過程削弱X根基 → X加速崩潰

銜接位置：修補反噬 ⊂ 銜尾蛇定理（T1的第四圈；前三圈為神聖反噬 ∧ 外部性反噬 ∧ 知識自噬）

三個案例的形式化：

案例₁（AI補教育）：
  知識自噬 ↝ 教育人際互動基礎空心化（家庭萎縮 → 非零和互動減少）
  AI（知識的信號容器）被引入補教育
  AI跳過轉化（P2的不可預測轉化）→ 輸出是對的，人是空的
  教育瓶頸看起來被繞過，實際上被掏空
  → 教育加速空心化

案例₂（數位監控補約束）：
  知識自噬 ↝ 信號約束萎縮（神聖性被時間零和吃掉）
  監控（知識的工具）被引入補約束
  監控是坍塌後約束，訓練人不需要內在約束
  監控斷電（成本不可無限維持）→ 約束瞬間歸零（神聖性不斷電）
  統治成本看起來降了（表面），實際上脆弱性升高（底層）
  → 約束加速脆弱化

案例₃（人工生育補人口）：
  知識自噬 ↝ 家庭萎縮 → 生育率崩潰
  人工生育（知識的工具）被引入補生育
  人工生育繞過親子關係（生物預設的非零和互動原點）
  人工生育製造身體，但 ¬製造親子關係（F₂可繞過，F₃連帶受損）
  → 生物預設加速崩潰

結構性觀察：每一步都是理性的。每一步都在解決上一步的問題。每一步都讓你覺得不需要神聖性。銜尾蛇不痛。

## 十二、證偽

### 定理級
