## 本篇概念定義

### 原語（不定義，只指認）

來源：論文第一節第一小節

  個體 — 可指認的存在
  刺激 — 到達個體的一切（外部或內部）

### 核心定義

來源：論文第一節第二小節

  信(個體) ≡ 個體的意識狀態
    性質₁：¬∃完整描述函數: 信(個體) → 完整描述
    性質₂：¬∃窮舉: 信(個體) → {面向₁, ..., 面向ₙ}

  語意流(個體) ≡ 信(個體)在時間中持續變化的過程

  信號(刺激, 個體) ≡ {刺激 | Δ語意流(個體)方向 ≠ 0}
  噪音(刺激, 個體) ≡ {刺激 | Δ語意流(個體)方向 = 0}
  信號(刺激, 個體) ⊕ 噪音(刺激, 個體)
    [對同一刺激同一個體，互斥且窮盡；判定在個體端]

### 補充定義

來源：論文第一節第三小節

  信號容器 ≡ 信號停留的媒介
    信號容器儲存信號 ∧ 信號容器傳遞信號
    ∄語意流 ∈ 信號容器

  通道 ≡ 信號從一個個體到達另一個個體的路徑
    通道內部：{信號容器₁, ..., 信號容器ₙ} ⊆ 通道（中間節點，可為∅）
    通道攜帶自我宣稱的來源（不可驗證）

  信任 ≡ 語意流對特定通道之加權
    效果：信任(通道) ↝ Δ語意流(個體)方向
    [同一信號從被信任通道與不被信任通道到達，方向變化不同]

### 基本功能定義

來源：論文第三節

  過濾 ≡ 語意流當下方向決定信號/噪音區分的機制
    [← D3 + P1，見§一]

  阻力 ≡ 刺激與語意流當下方向距離對信號通過可能性的反比關係
    [過濾的性質；非全有全無；通過狀態非封閉分類]
    [作者裁決：方向空間拓撲未定，不能聲稱窮盡通過狀態]

  知見障 ≡ 任何改變語意流方向的信號同時改變阻力分布的結構性性質
    [阻力的結構性後果；非價值判斷]

  轉化 ≡ 信號在語意流中被處理的過程（結果不可由輸入決定）
    [← P2，見§二]

  觀察者效應 ≡ 所有觀察行為本身作為刺激改變被觀察語意流的結構性性質
    [轉化的性質；P2的結構性推論]

  坍塌 ≡ 語意流（持續過程）編碼為信號（離散）的有損過程
    [← P3，見§三]

  表達落差 ≡ 語意流與輸出信號之間的不可消除差距
    [坍塌的結構性性質；P3直接推出]

  信號扭曲 ≡ 個體輸出持續可觀察地偏向特定方向的現象
    [定義在信號端（可觀察）；意圖不可觀察（P2封住）]

### 正反饋循環及相關定義

來源：論文第四節

  正反饋循環 ≡ 個體語意流坍塌為信號、信號強化語意流方向、語意流再次坍塌的持續過程
    [← P1 + D3 + 坍塌，見§四]
    [循環]

  功能性收斂 ≡ 輸出信號模式趨近（信號端可觀察上限，不等於語意流收斂）
    [← P1 + P2 + P3 + P4；四條律合起來保證每個個體語意流不可複製，語意端差異必然存在，見§四]

  循環不穩定性 ≡ 正反饋循環因內外兩個來源持續累積而無法維持永續均衡的性質
    [← P1 + P2 + P4，見§五]

  不穩定性內部來源 ≡ 由P1 + P2 + P4推出的循環內部殘差累積機制
    [見§五]

  不穩定性外部來源 ≡ 環境變化對循環造成的外部壓力
    [環境事實；非從公設推導]

  代際替換 ≡ 死亡律持續作用導致舊語意流歸零、新個體在新信號環境形成語意流的過程
    [← P4，見§六]

### 循環替代模型概念定義

來源：論文第七節第三、四小節

  循環替代 ≡ 既有正反饋循環被新循環取代的動力學過程
    [必要條件：NC₁ ∧ NC₂ ∧ NC₃ ∧ NC₄；見推導七]
    [循環：穩定後新循環成為新的既有循環，整個結構可重複]

  循環形成 ≡ 共享語意流方向的個體子集形成新正反饋循環的過程
    [循環]

  壓制 ≡ 既有循環利用權力壓縮新循環信號傳播的動態機制
    [作者裁決：壓制是動態的欺軟怕硬機制，使用 ↝]
    [觸發條件：既有循環擁有制度性權力 ∧ 新循環尚未強大到反制]
    [退出條件：新循環強大後壓制消退]

  落差擴大 ≡ 既有循環信號容器宣稱與個體實際接收信號之間差距擴大的過程

  替換 ≡ 代際替換機制導致新循環個體輸出逐漸替代舊循環個體輸出的過程

  穩定 ≡ 新循環成為主流並建立阻力結構後的狀態

  信號容器進入 ≡ 新信號進入信號容器的事件
    [NC₁：使新循環在壓制下存活]

  持續新信號源 ≡ 小循環持續獲得強化信號的條件
    [NC₂：使新循環持續擴大]

  對等信號缺失 ≡ 既有循環無法產出與新循環對等的新信號的狀態
    [NC₃：使落差持續擴大]

  死亡壓力 ≡ P4（死亡律）在循環替代過程中的必要條件表達
    = 帶舊語意流個體持續消亡 ∧ 新個體在新信號環境形成語意流
    [NC₄：代際替換是循環替代的時間條件]

### 驅動力定義（經驗層）

來源：論文第六節

[以下為經驗層概念；來自經驗觀察，非從公設推導；清單非窮盡，每一項都不必然產生結果]

  生存與物質利益 ≡ 在統計上最常推動坍塌的基本內部刺激類型
    [包含：飢餓、口渴、寒冷等基本生存需求]

  安全與威脅 ≡ 製造緊迫度的刺激類型

  權力 ≡ {利益, 通道控制, 信號容器控制}

    [信號接觸、語意流形成環境、輸出決定、輸出後果]

  認同需求 ≡ 個體尋找語意流方向趨近的其他個體以形成群體並維持邊界的驅動力

## 公設

來源：論文第二節第一、二小節

  流變律(P1) ≡ ∀個體 ∀時刻: 信(個體, 時刻+1) ≠ 信(個體, 時刻)

  黑箱律(P2) ≡ ¬∃預測函數使得:
    語意流(個體, 時刻+1) = 預測函數(語意流(個體, 時刻), 信號(時刻))

  損耗律(P3) ≡ ¬∃無損編碼使得: 語意流(個體) ↦ 信號 且 無損

  死亡律(P4) ≡ 個體消亡 → 語意流(個體)終止 ∧ ¬∃恢復機制: 語意流(個體)恢復

### 公設的可挑戰條件

來源：論文第二節第三小節

  挑戰P1：∃時刻使得: 信(個體, 時刻+1) = 信(個體, 時刻)
  挑戰P2：∃預測函數使得: ∀個體 ∀時刻:
    語意流(個體, 時刻+1) = 預測函數(語意流(個體, 時刻), 信號(時刻))
  挑戰P3：∃無損編碼使得: 語意流(個體) ↦ 信號 且 無損
  挑戰P4：∃恢復機制使得: 個體消亡後語意流(個體)可恢復

  [各挑戰條件與對應公設構成邏輯否定關係]

## 推導

### 一、過濾 ← D3 + P1

來源：論文第三節第一小節

前提：D3（信號定義），P1（流變律）

  P1 ⇒ 語意流在每個時刻均處於特定方向（非靜止）
  D3 ⇒ 語意流當下方向決定哪些刺激可改變它（即決定信號/噪音區分）
  ⇒ 同一刺激進入不同個體（不同語意流方向），可能是信號也可能是噪音
  ⇒ 同一刺激進入同一個體在不同時刻，可能得到不同結果（P1保證方向已改變）
  ⇒ 語意流當下方向對刺激構成選擇性，此即過濾
  [推導來源：D3 + P1]

  過濾 ← D3 + P1 ✓

**阻力（過濾的性質）：**

  過濾機制意味著刺激與語意流方向存在「距離」
  刺激-語意流方向距離 ↝ 信號(刺激, 個體)可能性降低（反比關係）
  [從過濾定義推出]
  阻力非全有全無；已知通過狀態包含：
    噪音（完全擋回）、形狀改變後通過、完全通過
  [作者裁決：阻力非封閉分類，方向空間拓撲未定，不能聲稱窮盡通過狀態]

**知見障（阻力的結構性後果）：**

  信號(刺激, 個體) ⇒ Δ語意流(個體)方向 ≠ 0 [D3]
  ↝ Δ阻力分布(個體) [阻力定義：方向改變即阻力分布改變]
  [推導來源：D3 + 阻力定義]

  Δ阻力分布結果：
    部分刺激方向阻力降低 ∧ 其他刺激方向阻力升高（不可同時全降）
  知見障是結構性後果，非價值判斷

### 二、轉化 ← P2

來源：論文第三節第二小節

前提：P2（黑箱律）

  信號通過過濾進入語意流（D3）
  ⇒ 語意流方向改變
  ⇒ 改變的結果不可由輸入決定（P2）
  ⇒ 同一信號進入不同語意流 → 不同轉化結果（P2直接推出）
  ⇒ 同一信號進入同一語意流的不同時刻 → 可能不同轉化結果（P1 + P2）
  [推導來源：P2]

  轉化 ← P2 ✓

**觀察者效應（P2的結構性推論）：**

  ∀觀察嘗試: 觀察嘗試 ↝ 新刺激到達個體
  若 信號(新刺激, 個體) 成立 ⇒ 語意流方向改變（P2，D3）
  ⇒ 觀察到的語意流方向 ≠ 觀察前的語意流方向
  ⇒ 觀察即介入（結構性，非技術限制）
  [推導來源：P2]

### 三、坍塌 ← P3

來源：論文第三節第三小節

前提：P3（損耗律）

  個體輸出（說、寫、畫、做）↝ 語意流必須編碼為信號
  P3 ⇒ 此編碼必然有損
  ⇒ 語意流從持續過程變為離散信號，此即坍塌
  [推導來源：P3]

  坍塌 ← P3 ✓

**表達落差（P3直接推出）：**

  P3 ⇒ 語意流 ≠ 坍塌輸出的信號（必然成立）
  ⇒ ¬∃完全對應: 語意流 ↔ 輸出信號
  表達落差是結構性的，非溝通技巧問題
  [推導來源：P3]

**信號扭曲（基於坍塌的可觀察現象定義）：**

  個體輸出持續且可觀察地偏向特定方向 → 信號扭曲
  意圖在語意流內部 → P2封住 → 不可觀察
  框架不判斷蓄意或無意
  [推導來源：坍塌定義 + P2的封閉性]

### 四、正反饋循環 ← P1 + D3 + 坍塌

來源：論文第四節第一小節

前提：P1（流變律），D3（信號定義），坍塌（← P3）

**個體層面正反饋循環：**
[循環]

  信號到達個體
  ↝ 過濾放行（D3）
  ↝ 轉化（語意流方向改變，P2）
  ↝ 坍塌為行為（P3有損）
  ↝ 行為結果成為新信號
  ↝ 新信號強化語意流既有方向（知見障反向效應：阻力降低面向）
  ↝ 下一次同類信號更易通過過濾 [回到起始]

  [推導來源：D3 + P1 + P3（坍塌）+ 知見障（阻力降低面向）]
  [循環退出條件：P4（個體消亡）∨ 語意流方向根本改變（P1 + P2）]

**群體層面正反饋循環：**
[循環]

  大量個體在相似信號環境中運作
  ↝ 過濾和轉化模式功能性趨近（功能性收斂）
  ↝ 輸出信號強化信號環境
  ↝ 信號環境塑造下一代個體語意流（代際替換 + P4）
  ↝ [回到起始]

  [推導來源：個體層面正反饋循環 + 代際替換（← P4）]
  [循環退出條件：循環不穩定性觸發 ∨ 全員死亡（P4）]

**功能性收斂（← P1 + P2 + P3 + P4）：**

  群體層面可觀察（信號端）：大量個體輸出信號模式趨近
  P1 + P2 + P3 + P4 ⇒ □(語意流(個體₁) ≠ 語意流(個體₂)) [對任意個體₁ ≠ 個體₂]
  [來源：P1 + P2 + P3 + P4；四條律合起來保證每個個體語意流的不可複製性：
    P1 持續運作（每一刻都不同）
    P2 方向不可由外部決定（不可被信號鎖定）
    P3 不可無損外化（不可被複製出去）
    P4 死後不可恢復（不可被重建）]
  ⇒ 功能性收斂是框架能在群體層面宣稱的上限：信號模式趨近，語意端差異必然存在

### 五、循環不穩定性 ← P1 + P2 + P4

來源：論文第四節第二小節

前提：P1（流變律），P2（黑箱律），P4（死亡律）

**不穩定性內部來源 ← P1 + P2 + P4：**

  P1 ⇒ ∀個體: 語意流持續各自變化 → 循環內殘差持續累積
  P2 ⇒ 方向變化不可預測 → 循環無法預先補償殘差
  P4 ⇒ 代際替換持續引入不可預測新個體（新個體語意流在新環境重新形成）
  [推導來源：P1 + P2 + P4]

**不穩定性外部來源（環境事實）：**

  信號容器在變 ∧ 環境在變
  環境變化 ⊥⊥ 循環方向約束（環境變化不受循環約束）
  循環方向與環境變化方向持續分歧 ↝ 落差在時間中擴大
  [來源：環境事實，非公設推導]

**兩個來源同時作用：**

  不穩定性內部來源 ∧ 不穩定性外部來源
  [作者裁決：兩個來源非窮盡宣稱，論文未明確標記為窮盡分類]

  □(正反饋循環 → ¬永續均衡態)
  [來源：P1 + P2 + P4共同推出；維護循環的行動本身也受P1、P2、P4約束]

  循環不穩定性 ← P1 + P2 + P4 + 環境事實 ✓

### 六、代際替換 ← P4

來源：論文第四節第三小節

前提：P4（死亡律）

  P4 ⇒ 每次個體消亡，語意流歸零且不可恢復
  新個體在不同信號環境中形成語意流（P1保證語意流重新開始 + 環境差異）
  ↝ 人口比例改變 ↝ 循環方向改變
  [推導來源：P4 + P1]

  補充推導：文明延續 ≠ 語意傳承

    P2 ⇒ 語意流不可由信號決定 ⇒ 語意不可原樣被信號傳遞
    P3 ⇒ 語意流不可無損編碼為信號 ⇒ 傳遞必然有損
    ⇒ ¬∃語意傳承: 文明延續以語意傳承為基礎
    [推導來源：P2 + P3]

    文明延續 ≡ 循環狀態再生產
    = 下一代在上一代信號容器環境中重新形成各自語意流
    [信號容器存續，語意流各自重新形成，不是複製]

  代際替換 ← P4 ✓

### 七、循環替代模型 ← PC₁ + PC₂ + 正反饋循環 + P4

來源：論文第七節第三、四小節
[循環：穩定後新循環₁成為新的既有循環₀，整個結構可重複]
[不可退出聲明：論文未給出循環替代模型的退出條件]

在前置條件 PC₁（既有循環₀穩定運作）+ PC₂（新信號進入且方向不同）成立的條件下：

**步驟一：循環形成**
[循環]

  PC₂ ⇒ ∃個體子集 ⊂ 循環₀個體: 信號(新信號, 個體) 成立（D3）
  個體子集接收新信號 ↝ 轉化（P2）
  ↝ 個體子集坍塌輸出新方向信號（P3）
  ↝ 個體子集互相強化輸出 ↝ 新循環₁正反饋建立 [循環標注]
  新循環₁輸出方向 ≠ 循環₀輸出方向 ↝ 對抗

  [推導來源：PC₂ + D3 + P2（轉化）+ P3（坍塌）+ 正反饋循環定義]
  [新循環₁退出條件：見步驟五穩定 ∨ 新循環₁面臨下一輪循環替代]

**步驟二：壓制（條件分支）**

  [作者裁決：壓制是動態的欺軟怕硬機制，使用 ↝]

  條件甲（壓制觸發）：
    既有循環₀擁有制度性權力 ∧ 新循環₁尚未強大到反制
    ↝ 壓制(新循環₁, 信號傳播) ∧ 壓制(新循環₁, 個體輸出) ∧ 壓制(新循環₁, 輸出後果)
    ↝ 新循環₁被壓縮

  壓制退出條件：新循環₁強大到既有循環₀無法有效壓制 ↝ 壓制消退

  條件乙：新信號已進入信號容器 [NC₁] →
    ¬消滅(新循環₁)（信號容器讓新循環₁在壓制下存活）

  [壓制影響替代速度，不影響替代方向（前提：NC₁∼NC₄均滿足）]
  [推導來源：正反饋循環 + 信號容器定義（信號容器讓信號存活）]

**步驟三：落差擴大**

  NC₂（持續新信號源）↝ 新循環₁持續產出新信號強化自身
  NC₃（對等信號缺失）↝ 循環₀ ∄ 對等新信號輸出
  ↝ 落差(循環₀信號容器宣稱, 個體實際接收信號) 持續擴大
  ↝ 循環₀空轉

  [推導來源：NC₂ + NC₃]

**步驟四：替換**

  P4 ⇒ 循環₀中帶舊語意流個體持續消亡（死亡律必然作用）
  NC₁（信號容器進入）⇒ 新信號存於信號容器
  新個體在含新循環₁信號的環境中形成語意流（代際替換）
  ↝ 新個體輸出匯入新循環₁
  ↝ 循環₀正反饋斷裂

  [推導來源：P4（代際替換）+ NC₁]

**步驟五：穩定**

  新循環₁成為主流循環
  ↝ 新循環₁建立信號容器 ↝ 產生阻力結構
  ↝ 新循環₁開始自我保護
  → 新循環₁重複循環₀的結構性行為（阻力 + 壓制 + 空轉）
  [作者裁決：「新循環₁開始自我保護 → 重複循環₀結構性行為」屬於建模跑出的觀察，section 7 在經驗層，非推導跳步]

  [循環₁退出條件：新循環₁面臨下一輪循環替代，整個結構重複]
  [推導來源：正反饋循環定義（建立阻力結構）+ 經驗觀察]

**必要條件（NC₁∼NC₄，任一不滿足則循環替代不完成）：**

  NC₁（信號容器進入）: ∃信號容器: 新信號 ∈ 信號容器
  NC₂（持續新信號源）: ∃持續信號源: 新循環₁持續強化
  NC₃（對等信號缺失）: ∄對等新信號: 循環₀可產出 ∧ 支撐循環₀自身
  NC₄（死亡壓力）: P4作用 → 循環₀個體消亡 ∧ 新個體在新信號環境形成語意流
