## 一、原語與定義

來源：論文第一節

### 1.1 原語

本框架的原語不另定義，僅指認。

個體 (Individual) — 可指認的存在。
刺激 (Stimulus) — 到達個體的一切，可來自外部或內部。

### 1.2 本篇概念定義

信 ≡ 個體的意識狀態
  ¬∃f: 信 → 完全描述
  ¬∃枚舉: 信 → {x₁, x₂, ..., xₙ}
  信包含深層、中層、淺層

語意流 ≡ d信/dt
  語意流不是產物，是信持續變化的過程

信號(σ, i) ↔ Δ方向(信(i), σ) ≠ 0
噪音(σ, i) ↔ Δ方向(信(i), σ) = 0
  信號定義在接收端（個體 i）

信號容器 ≡ 信號停留的地方
  ∈ {書本, 聲波, 圖像, 建築, 制度文本, 數位檔案}

通道 ≡ 信號從一個個體到達另一個個體的路徑
  中間可能經過多個信號容器

信任 ≡ 語意流對特定通道上的加權
  同樣的信號，從被信任的通道來和從不被信任的通道來，語意流的方向變化完全不同


## 二、公設

來源：論文第二節

### 2.1 公設列表

P1 流變律: ∀i ∀t: 信(i, t+1) ≠ 信(i, t)
  語意流持續運作，無靜止時刻

P2 黑箱律: ¬∃f: 信(i, t+1) = f(信(i, t), 信號(t))
  核心公設：語意流的下一刻方向不可由當下方向與信號決定
  此為框架與一切信號層面理論的分界線

P3 損耗律: ¬∃g: 語意流(i) ↦ 信號 · 無損(g)
  語意流不可無損編碼為信號

P4 死亡律: 死亡(i) → 語意流(i)終止 ∧ ¬∃恢復
  個體消亡，語意流不可恢復

### 2.2 公設的認識論位置

公設不是經驗假說，是公設。
其位置類似歐幾里得的平行公設——可選擇接受或不接受。
每條公設有獨立的挑戰條件。

### 2.3 AI 在公設中的位置

鎖死參數的 AI：¬P2 成立。此類 AI 不滿足黑箱律，行為可函數化，不屬於框架主要分析範圍。
放開參數的 AI：P2 開始部分成立 ↝ 開始在框架中運作
人類：P2 完全成立

### 2.4 可證偽性形式表達

挑戰P1（反對流變律）：∃i ∃t: 信(i, t+1) = 信(i, t)  ⊗  P1
  模型推導：P1 ⇒ ∀i∀t: 信(i, t+1) ≠ 信(i, t)

挑戰P2（反對黑箱律）：∃f: 信(i, t+1) = f(信(i, t), 信號(t))  ⊗  P2
  模型推導：P2 ⇒ ¬∃f: 信(i, t+1) = f(信(i, t), 信號(t))

挑戰P3（反對損耗律）：∃g: 語意流(i) ↦ 信號 · 無損(g)  ⊗  P3
  模型推導：P3 ⇒ ¬∃g: 語意流(i) ↦ 信號 · 無損(g)

挑戰P4（反對死亡律）：死亡(i) → ∃恢復(語意流(i))  ⊗  P4
  模型推導：P4 ⇒ 死亡(i) → 語意流(i)終止 ∧ ¬∃恢復


## 三、從公設推導基本功能

來源：論文第三節

### 3.1 過濾

D3（信號定義） + P1（流變律） ⇒ 過濾
過濾 ≡ 語意流當下方向決定哪些刺激構成信號、哪些構成噪音的機制

阻力
  過濾 ⇒ 阻力
  阻力 ≡ 過濾對特定刺激的排斥程度
    阻力 ∝ 距離（刺激方向, 語意流當下方向）
    阻力 ∈ {全擋（構成噪音）, 部分通過（信號形狀改變）, 完全通過}
  （從 過濾 推得）

知見障
  過濾 + D3 + P1 ⇒ 知見障
  知見障 ≡ 語意流方向改變導致阻力分布同步重組的結構性現象
    信號改變語意流方向 ↝ 新過濾條件生成
    ↝ 特定方向阻力降低 ∧ 其他方向阻力同時升高
  （從 過濾 + D3 + P1 推出）

### 3.2 轉化

P2（黑箱律） ⇒ 轉化
轉化 ≡ 信號通過過濾後在語意流中產生不可預測方向改變的過程

觀察者效應
  轉化 + P2 ⇒ 觀察者效應
  觀察者效應 ≡ 觀察語意流的行為本身構成刺激、通過過濾後改變語意流方向的現象
    觀察行為 = 刺激 ↝ 若通過過濾 ↝ 進入轉化 ↝ 語意流方向改變
    ∴ 觀察前後的語意流方向不同（P2）
  （從 轉化 + P2 推出）

### 3.3 坍塌

P3（損耗律） ⇒ 坍塌
坍塌 ≡ 語意流被編碼為外部信號的過程，必然有損（P3）

表達落差
  坍塌 + P3 ⇒ 表達落差
  表達落差 ≡ 語意流與其坍塌後輸出信號之間不可消除的結構性差距
  （從 坍塌 + P3 推出）

信號扭曲
  坍塌 + P3 ⇒ 信號扭曲
  信號扭曲 ≡ 個體輸出信號持續、可觀察地偏向特定方向的現象
    ¬∃判定意圖（意圖在語意流內部，P2 封鎖，不可觀察）
  （從 坍塌 + P3 推出）


## 四、從基本功能推導正反饋循環

來源：論文第四節

### 4.1 正反饋循環

P1 + D3 + P3 ⇒ 正反饋循環

推導鏈（因果過程）：

個體 A 的語意流坍塌為信號 ↝ 信號到達個體 B ↝ 通過 B 的過濾 ↝ 在 B 的語意流中轉化 ↝ B 的語意流方向改變 ↝ B 的語意流坍塌為信號 ↝ 信號到達 A ↝ 循環持續

循環在個體層面：信號到達 ↝ 過濾放行 ↝ 轉化改變語意流方向 ↝ 坍塌為行為 ↝ 行為結果成為新信號 ↝ 新信號強化既有方向 ↝ 下一次同樣信號更容易通過（阻力降低）。
（從 過濾 + 轉化 + 坍塌 組合推出）

循環在群體層面：大量個體在相似信號環境中運作，過濾和轉化模式趨近，輸出信號強化信號環境，信號環境塑造下一代個體的語意流。正反饋循環跨個體運作，形成家庭、同儕、社會、文明。
（從 正反饋循環 + P4 推出）

P2 ⇒ 功能性收斂
  群體層面所有觀察都在信號端。
  大量個體的輸出信號模式趨近——可觀察事實。
  但 P2 保證每個個體的語意流都不同，趨近永遠有殘差。
  功能性收斂是框架能宣稱的上限。
  （從 P2 推出）

退出條件（不可退出聲明）：¬∃內建終止條件。循環中斷僅由外部條件觸發——信號容器斷裂 ∨ 代際替換完成 ∨ 外部環境變遷（見 4.2 節循環不穩定性）。此為結構性限制，非循環內建終止。

### 4.2 循環不穩定性

P1 + P2 + P4 ⇒ 循環不穩定性

不穩定性內部來源
  P1 + P2 + P4 ⇒ 不穩定性內部來源
  不穩定性內部來源 ≡ 循環不穩定性中源自公設本身的成分
    = P1（語意流持續變化）∧ P2（方向不可預測）∧ P4（代際替換不可複製）
  （從 P1 + P2 + P4 推出）

不穩定性外部來源
  不穩定性外部來源 ≡ 循環不穩定性中源自環境變化的成分
    = 信號容器變化 ∧ 不受循環約束的環境變化
    不穩定性外部來源 ∉ 公設推出（環境事實）
  （從 循環不穩定性 推得）

### 4.3 代際替換

P4 ⇒ 代際替換
  個體死亡，語意流歸零且不可恢復。
  新一代個體在不同的信號環境中開始運作，形成不同的語意流。
  人口比例改變，循環方向改變。
  （從 P4 推出）

文明的延續不是語意的傳承（P2 + P3 否定此可能），
  是循環的狀態再生產。
  下一代在上一代留下的信號環境中形成自己的語意流——這就是傳統。
  （從 P2 + P3 + P4 推出）


## 五、框架不分類

來源：論文第五節

流變律（P1）預設時間軸——語意流持續運作，不存在靜止的時刻。
分類需要把對象定住才能歸類，框架裡沒有東西是定住的。
框架提供的是基本功能（過濾、轉化、坍塌）和正反饋循環。
任何現象都是這些工具在具體條件下跑出來的軌跡。
建模跑出來的反覆型態就是模式——模式是建模的產物，不是建模的前提。
模式的數量是顆粒度的函數，不可窮舉。
框架教的是建模方法，不是模式清單。


## 六、驅動力

來源：論文第六節

語意流在個體內部持續運作（P1），不需要外部驅動。
坍塌是否發生，由語意流的當下方向決定（P2，不可預測）。
框架不能解釋為什麼一個特定個體在特定時刻選擇行動——在 P2 的不可預測性範圍內。
但建模需要搭條件，需要知道什麼東西在驅動循環。

經驗觀察顯示的常見驅動力類型（不可窮舉）：

生存與物質利益 ≡ 飢餓 ∧ 口渴 ∧ 寒冷等內部刺激在統計上推動坍塌的驅動力類型
  不可窮舉，統計傾向非必然

安全與威脅 ≡ 威脅信號在統計上壓低過濾阻力的驅動力類型
  威脅 ↝ 緊迫度 ↝ 阻力降低 ↝ 坍塌加速

權力 ≡ {利益, 通道控制, 信號容器控制} 的組合，覆蓋循環所有環節的驅動力類型
  控制信號接觸 ∧ 塑造語意流形成環境 ∧ 決定輸出許可 ∧ 決定輸出後果

意義追尋 ≡ 個體主動尋求新信號、主動進入轉化的內在驅動力類型

認同需求 ≡ 個體尋找語意流方向趨近的其他個體、形成群體並維持邊界的驅動力類型
  認同需求 ↝ 主動尋找功能性收斂個體 ↝ 群體形成 ∧ 邊界維持


## 七、建模

來源：論文第七節

### 7.1 循環替代模型

循環替代
  D3 + 正反饋循環 + P4 ⇒ 循環替代
  循環替代 ≡ C₁ 取代 C₀ 成為主流循環的完整動力學過程
    = 循環形成 ↝ 壓制（條件性）↝ 落差擴大 ↝ 替換 ↝ 穩定
    必要條件：信號容器進入 ∧ 持續新信號源 ∧ 對等信號缺失 ∧ 死亡壓力

前置條件：
  C₀: 既有循環，正反饋穩定運作，信號容器完整

啟動條件：
  σ: 新信號進入，與 C₀ 方向不同
  ∃ 個體子集 S ⊂ C₀: 信號(σ, i) 對 S 中的個體成立（D3）

循環形成
  D3 + 正反饋循環 ⇒ 循環形成
  循環形成 ≡ 個體子集 S ⊂ C₀ 互相強化輸出、形成新正反饋循環 C₁ 的過程
    S 互相強化輸出 ↝ 形成 C₁
    C₁ 輸出方向 ≠ C₀ 輸出方向 → C₁ ⊗ C₀
  （從 D3 + 正反饋循環 推出）

壓制
  壓制 ≡ C₀ 利用制度性權力限制 C₁ 信號傳播、個體輸出及輸出後果的行動
    C₀ 擁有制度性權力 →
      C₀ 壓制 C₁ 的信號傳播、個體輸出、輸出後果
      C₁ 被壓縮
    （從 權力 + 循環形成 推出）
    σ ∈ 信號容器 → C₁ ≠ ∅
    （從 信號容器 + P3 推出）

落差擴大
  正反饋循環 + 信號容器 ⇒ 落差擴大
  落差擴大 ≡ C₀ 信號容器宣稱與個體實際接收信號之間差距持續增大的狀態
    C₁ 持續產出新信號 ↝ C₁ 自我強化
    C₀ ¬∃新信號 ↝ C₀ 空轉
  （從 正反饋循環 + 信號容器 推得）

替換
  P4 + 代際替換 ⇒ 替換
  替換 ≡ C₀ 正反饋斷裂、新個體輸出持續匯入 C₁ 的過程
    P4 ↝ C₀ 個體消亡（語意流不可恢復）
    新個體在含 C₁ 信號的環境中形成語意流 ↝ 新個體輸出匯入 C₁ ↝ C₀ 正反饋斷裂
  （從 P4 + 代際替換 推出）

穩定
  循環替代 ⇒ 穩定
  穩定 ≡ C₁ 成為主流循環、建立信號容器並產生阻力結構的狀態
    C₁ 成為主流 ↝ C₁ 建立信號容器 ↝ 阻力結構形成 ↝ C₁ 重複 C₀ 的結構性行為
  （從 循環替代 推得）

### 7.2 必要條件

從模型中識別的四個必要條件（任何一個不滿足，循環替代不會完成）：

信號容器進入
  信號容器進入 ≡ σ 被記錄於信號容器、使 C₁ 在壓制下存活的前提條件
    ¬∃信號容器進入 → 壓制 → C₁ = ∅
    （從 壓制 推出）

持續新信號源
  持續新信號源 ≡ C₁ 循環替代所需的持續信號強化來源
    ¬∃持續新信號源 → ¬∃循環替代
    （從 循環形成 + 正反饋循環 推出）

對等信號缺失
  對等信號缺失 ≡ C₀ 無法產出支撐自身的新信號的狀態
    對等信號缺失 → 落差擴大
    （從 落差擴大 推出）

死亡壓力
  死亡壓力 ≡ P4 在 C₀ 個體上的持續作用，代際替換的時間條件
    P4 ↝ C₀ 個體消亡 ↝ 代際替換
    ¬∃死亡壓力 → ¬∃代際替換 → ¬∃循環替代
    （從 P4 + 代際替換 推出）

### 7.3 預測

模型對以下條件變量產生預測：

權力壓制的有無影響替代速度，不影響替代方向。
  有制度性壓制（日心說案例），替代慢。
  無制度性壓制，替代快。
  但四條件滿足時，替代方向不變。

落差擴大的速度影響替代速度。
  新信號產出越快、越不可否認，落差擴大越快，替代越快。

信號容器的耐久性影響小循環的存活能力。
  印刷書比手抄本耐久，數位數據比印刷品更耐久。
  越耐久，壓制越難消滅小循環。


## 八、量化的空間與天花板

來源：論文第八節

框架是形式化的，但不量化。
禁止的不是數學化，是量化——給語意端賦數值。

賦值需要測量，測量需要接觸被測量的對象。
P2 說語意流的下一刻方向不可由當下方向與信號決定——語意流的內部不可穿透。
P3 說語意流不可還原為信號——語意端不可編碼為信號端的數值。
任何將數值賦予語意現象的操作，都在假裝穿透了一個原則上不可穿透的黑盒。
一個沒有測量來源的數值不是近似值，是虛構值。

信號端可以量化。
  信號端的輸出模式可觀察、可測量、可統計。
  合作與對抗的程度可以用群體內部輸出信號模式的統計相似度代理。
  語意流深層的穩定性可以用信號容器的存續年數、經典被引用的頻率代理。
  循環空轉的程度可以用信號容器的宣稱與可觀察現實之間的落差代理。

所有量化都在信號端，不在語意端。
每一個指標和它試圖代理的語意現象之間，都隔著 P2 + P3 那道牆。
這是框架的量化天花板，由公設本身決定，不是技術限制。


## 九、與既有理論的關係

來源：論文第九節

### 9.1 Shannon

Shannon：處理信號在通道中的保真度。
框架：處理信號到達個體之後發生什麼。
Shannon 的終點是框架的起點。
關係：起點邊界，各管各的。

### 9.2 不可判定性

P2（黑箱律）是結構性不可判定在意識領域的延伸。
  哥德爾：形式系統中的不完備定理。
  海森堡：粒子層面的不確定性原理。
  圖靈：計算層面的停機問題。
  框架：意識層面的 P2。

### 9.3 社會物理學

社會物理學從物理學搬了方法論和量化工具。
框架從物理學搬了方法論但不搬量化。

三個關鍵差別：

一、理性人假設：
  社會物理學預設人為優化器。
  框架的 P2 直接否定——思考不是計算。

二、量化前提：
  社會物理學把信號端的量化當成語意端的測量。
  框架明確區分，拒絕偽裝的測量。

三、文化變量：
  社會物理學模型中人為無差別粒子。
  框架中語意流就是文化變量，不同語意流產生不同軌跡。

### 9.4 Luhmann

Luhmann 的社會系統論從社會學方向獨立觸及了框架的多條公設。

P2（黑箱律）：心理系統對社會系統不可穿透。
P1（流變律）：意義永遠指向其他可能性，不靜止。
P3（損耗律）：溝通拆成三段選擇，理解由接收端決定。
觀察者效應：二階觀察理論。

邊界在個體：
  Luhmann 的基本單位是溝通，不是人。
  框架的基本單位是個體——語意流發生在個體身上。

### 9.5 Peirce

Peirce 的符號學從邏輯學方向獨立觸及了框架的核心結構。

P1（流變律）：unlimited semiosis——符號產生解釋項，解釋項本身是新的符號，過程永不終止。
信號定義在接收端：解釋項是接收者的產物。
轉化：符號在解讀中被轉化，不是被複製。
正反饋循環：habit（習慣）——反覆的符號過程形成穩定的解釋傾向。

邊界在終點：
  Peirce 安裝了真理收斂——系統能自我修正，能自救。
  框架不接受——P1 + P2 + P3 + P4 + 熵增，所有路都通向衰變。
  系統內部不存在逆轉衰變的機制。

### 9.6 Sperber

Sperber 的表徵流行病學是離框架最近的既有理論。
文化表徵在人際傳遞中不是被複製，而是被轉化。

Sperber 停在了路徑分化的問題上。
框架在 Sperber 停的地方繼續。
框架有兩個 Sperber 沒有的工具：
  「語意流」作為獨立於信號的過程（解釋路徑分化）
  信號端與語意端的硬分界（捕捉「信號統一但語意分裂」現象）


## 十、適用範圍與限制

來源：論文第十節

適用：任何信號到達個體之後產生語意流的現象。
  個體可以是人，也可以是黑箱律部分成立的 AI。

不適用：不涉及個體接收和處理信號的純信號層問題。
  判準：問「核心是信號到達個體之後發生了什麼嗎？」

限制：
  不處理真偽
  不處理價值
  不提供減少轉化的方法
  不預測時間
  不追蹤個體內心
  自身受公設約束——框架無法豁免自己的公設
