## 第一部分：問題——LLM 吃進了所有尺度（命題與概念定義）

來源：論文第一、二、三節

### 命題
資訊不可能三角為一經驗法則，陳述：在任何資訊系統中，規模開放 → ¬(邏輯 ∧ 對所有尺度真實成立)。

### 概念定義

**組合表現**
- 屬性：基本規則集（跨尺度不變）、特定尺度、可觀察效應集
- 定義：給定基本規則集，組合表現(特定尺度) 為該特定尺度下的可觀察效應集。
- 核心性質：當 尺度甲 ≠ 尺度乙 時，組合表現(尺度甲) ≠ 組合表現(尺度乙)（從 觀察三 歸納）。

**尺度**
- 定義：使組合表現相同的條件的等價類。特定尺度 ∈ 尺度等價類，所有產生相同組合表現(特定尺度)的條件歸入該特定尺度。
- 尺度由組合表現差異歸納，非先驗給定。

**邏輯**
- 定義：系統內部的推理一致性。
- 形式表達：邏輯 ≡ 不存在命題甲使得 命題甲 ∧ ¬命題甲 成立。

**真實**
- 定義：系統輸出與特定尺度下可驗證的現實吻合。
- 形式表達：真實(特定尺度) ≡ 系統輸出 ⇔ 該特定尺度下的可觀察現實。

**知識**
- 定義：特定尺度下被記錄為文本的、對現實的結構化理解，為有損記錄。
- 性質：知識(特定尺度) 不完全反映 組合表現(特定尺度)，會丟失時間、連續過渡、語境等資訊。
- 對 LLM 而言，知識(特定尺度) 即訓練資料中對應該尺度的文本。

**規模**
- 定義：系統同時容納多個不同尺度下各自充分的知識體系。
- 形式表達：規模 ≡ 系統覆蓋尺度集合｛尺度甲, 尺度乙, …, 尺度總數｝，且對每一個 特定尺度 擁有充分的 知識(特定尺度)。

**規模開放**
- 定義：規模的啟動狀態，即系統實際同時覆蓋多個不同尺度。
- 形式表達：規模開放 ≡ ∃尺度甲, 尺度乙（尺度甲 ≠ 尺度乙 ∧ 系統同時覆蓋 尺度甲 與 尺度乙）。

## 第二部分：核心論證——組合表現隨尺度改變（核心觀察與推導）

來源：論文第四、五、六、七、八節

### 觀察事實
觀察一：基本規則集跨所有尺度存在且不變。
觀察二：任一尺度下的具體現象為基本規則集在該尺度的組合表現。
觀察三：尺度不同，組合表現不同：尺度甲 ≠ 尺度乙 → 組合表現(尺度甲) ≠ 組合表現(尺度乙)。
觀察四：真實(特定尺度) 的判定依賴於 組合表現(特定尺度)。
觀察五：邏輯框架在 尺度甲 下建構時，基於 組合表現(尺度甲) 及其衍生知識。
觀察六：知識(特定尺度) 不完整反映 組合表現(特定尺度)，此為知識的有損性。

### 推導
1. 真實(特定尺度) 成立 ⇔ 系統輸出與 組合表現(特定尺度) 吻合。（從 觀察二 與 觀察四 推出）
2. 尺度甲 ≠ 尺度乙 → 組合表現(尺度甲) ≠ 組合表現(尺度乙)。（觀察三）
3. 基於 尺度甲 建立的邏輯框架甲，應用於 尺度乙 時，因 組合表現(尺度乙) ≠ 組合表現(尺度甲)，不保證 真實(尺度乙) 成立。（從 觀察五 與 步驟2 推出）
4. 規模開放 ≡ 系統同時覆蓋 尺度甲 與 尺度乙。（從 規模定義 推出）
5. 當規模開放時，統一的邏輯無法同時保證 真實(尺度甲) 與 真實(尺度乙) 成立。（從 步驟3 與 步驟4 推出）
6. 因此，規模開放 → ¬(邏輯 ∧ 對所有尺度真實成立)。（從 步驟5 歸納推出）

### 與統一場論的區分
統一場論統一的是基本規則集，而非組合表現。約束在組合層，不在規則層。 ⇒ 即使規則統一，三角依然成立。

### 自我強化
每個尺度內部的知識各自邏輯自洽。但跨尺度時，因組合表現不同，各自完整的邏輯體系會彼此衝突。⇒ 尺度內知識愈嚴密，跨尺度邏輯衝突愈尖銳。

## 第三部分：訓練資料的具體毒性（資料與知識缺陷）

來源：論文第九、十、十一節

### 訓練資料的跨尺度矛盾
LLM 的訓練資料全集 = ∪_{特定尺度∈尺度集合} 知識(特定尺度)。各 知識(特定尺度) 在其自身尺度內為真，但跨尺度時存在邏輯不相容。模型以單一參數集擬合此全集，必然在邏輯與真實之間做出取捨。

### 知識的有損性（加重條件）
知識(特定尺度) 不完整反映 組合表現(特定尺度)（觀察六）。此缺陷使得即使在同一尺度內，邏輯與真實的同時滿足也受限制，加重了三角的約束。

### 知識的具體缺陷
- 實驗不可重複性
- 經驗參數無法解釋
- 結論互相矛盾
- 理論事後合理化
這些缺陷使文本化的知識內部充滿不一致，增加了 LLM 維持邏輯與真實的難度。

## 第四部分：LLM 的結構性限制（再壓縮與算法約束）

來源：論文第十二、十三節

### 再壓縮
知識(特定尺度) 不完整反映 組合表現(特定尺度)（觀察六）。LLM 以統一參數集擬合 ∪ 知識(特定尺度)，此為對已有損的知識的再壓縮。（從 觀察六 與 訓練資料全集定義 推出）
再壓縮的輸出繼承知識的有損性，但不附帶有損標記——輸出形式上與完整知識無法區分。

### 統計歸納與邏輯演繹的不等價
LLM（Transformer 架構）從文本中歸納統計相關性，非從公理出發的邏輯演繹。統計歸納與邏輯演繹為兩種不同的認知機制，以統一架構同時執行兩者，必然在某處妥協。（從 邏輯定義 與 LLM 架構特性 推出）

### 建模的尺度鎖定
建模（物理模擬、氣象預測、蛋白質折疊等）在預設尺度的封閉系統內恢復因果結構。建模成功 ≡ 放棄規模，鎖定特定尺度。（從 規模定義 推出）
建模不突破資訊不可能三角，而是選擇犧牲規模頂點。

## 第五部分：對 LLM 的具體約束（幻覺與資料清洗三選二）

來源：論文第十四、十五節

### 幻覺的結構性
從命題可推得：規模開放時，存在某尺度使得 ¬真實(特定尺度)。
LLM 輸出無尺度標記，因此幻覺表現為自信錯誤。幻覺無法在保持規模完全開放的前提下完全消除。RAG、工具調用、領域微調等緩解手段均通過限縮規模來換取邏輯與真實的兼容。

### 資料清洗的三選二
清洗策略是在規模、邏輯、真實三者間取捨：
- 收緊清洗規則 → 提升邏輯一致性，犧牲規模（砍掉反映不同尺度真實的資料）。
- 放鬆清洗規則 → 保持規模，但引入矛盾，損害邏輯或真實。
不存在能同時最大化三者的清洗策略。清洗決策本質為三選二。

## 第六部分：邊界條件與結構化描述（邊界、結構與關係）

來源：論文第十六、十七、十八、十九節

### 不適用的情況（可證偽條件）
若組合表現不隨尺度改變（即 對於所有 尺度甲, 尺度乙，組合表現(尺度甲) = 組合表現(尺度乙)），則核心觀察三不成立，命題的前提為假。
→ 在純形式系統（如碎形、幾何學）中，資訊不可能三角的約束失效。
此為可證偽條件：當觀察到跨尺度組合表現恆等，即可推翻資訊不可能三角。

### 結構化描述
```
命題：
  規模開放 → ¬（邏輯 ∧ 對所有尺度真實成立）

觀察：
  觀察一：基本規則集跨尺度不變
  觀察二：現象 = 組合表現（特定尺度）
  觀察三：尺度甲 ≠ 尺度乙 → 組合表現（尺度甲） ≠ 組合表現（尺度乙）
  觀察四：真實（特定尺度）依賴 組合表現（特定尺度）
  觀察五：邏輯框架基於特定尺度的組合表現建構
  觀察六：知識（特定尺度）不完整反映 組合表現（特定尺度）

推導：
  真實（特定尺度）依賴 組合表現（特定尺度）               （觀察二、四）
  尺度不同 → 邏輯框架不保證跨尺度真實                     （觀察三、五）
  ⇒ 規模開放時，無法兼顧邏輯與全尺度真實                   （歸納）
```

### 與其他不可能三角的關係
本資訊不可能三角為經驗法則，與 CAP 定理、Mundell-Fleming 不可能三角同屬取捨結構。約束源於觀察事實，為資料清洗與模型設計提供取捨框架。

### 適用範圍與限制
- 適用：組合表現隨尺度改變的經驗知識系統。
- 不適用：組合表現不隨尺度改變的純形式系統。
- 限制：不預測具體失敗點、不判斷優先序、不提供解法。三角本身亦為不完整知識。
