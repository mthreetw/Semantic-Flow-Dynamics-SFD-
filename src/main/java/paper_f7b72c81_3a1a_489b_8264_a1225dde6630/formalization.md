## LLM 是第一個真的這樣做的系統

來源：論文第一節

結構性論點：人類知識體系歷史上始終按尺度分隔（物理分尺度、醫學分科別、工程分領域）。每個有效知識體系必須先鎖定尺度，才能同時達到邏輯自洽且與現實吻合。

LLM 打破此慣例：訓練資料跨越所有尺度，無分隔。
形式：LLM.訓練資料 = ∪_{尺度} 知識(尺度)

此節為後續論證建立問題語境，不引入新的形式定義。

## 命題

來源：論文第二節

在任何資訊系統中，當規模保持開放時，邏輯一致性與事實真實性不可同時滿足。

形式：資訊不可能三角 ≡ 規模 → ¬(邏輯 ∧ ∀尺度: 真實(尺度))

此為本篇核心命題。此為觀察歸納，非數學必然性（見第十七節注意事項）。
推導見「組合表現隨尺度不同——三角成立的推導」段。

## 概念定義

來源：論文第三節

**組合表現** ≡ 規則集在特定條件下相互作用的整體效應
  記號：組合表現(規則集, 尺度)
  可直接觀察、可測量
  規則集跨條件不變；各規則的相對權重與交互方式隨條件改變

**尺度** ≡ 使組合表現相同的條件的等價類
  記號：尺度（論文原文使用 s，本文改用中文語意名稱）
  尺度₁ = 尺度₂ ⇔ 組合表現(規則集, 尺度₁) = 組合表現(規則集, 尺度₂)（等價類定義）
  從組合表現的可觀察差異歸納而得，非先驗給定的分類

**邏輯** ≡ 系統內部的推理一致性
  形式：∀命題 ∈ 系統：¬(命題 ∧ ¬命題)
  [作者裁決] 原論文含 q 變量（`∀ 命題 p, q ∈ System`），確認為筆誤；q 已移除。

**真實(尺度)** ≡ 系統輸出與 組合表現(規則集, 尺度) 之間的一致性
  即：系統在尺度下的輸出與該尺度的組合表現吻合
  (尺度) 指定比對的是哪個尺度的組合表現；真實本身是描述一致性關係的概念，非謂詞函數
  [作者裁決] 「真實」是系統輸出與現實世界組合表現一致性的簡稱，與其他匯出概念同為實體概念。

**知識(尺度)** ≡ 尺度下被記錄為文本的、對現實的結構化理解
  知識(尺度) ⊂ 組合表現(規則集, 尺度)（真子集；不完整反映組合表現，見第十節）
  對 LLM 而言：知識(尺度) = 訓練資料中屬於該尺度的文本

**規模** ≡ 同時容納多個不同尺度下各自充分的知識體系
  形式：系統同時覆蓋至少兩個不同尺度，且在每個尺度下均擁有充分的知識(尺度)
  規模不是資料量，是知識多樣性（跨越的尺度數）
  [作者裁決] 「充分」為形容詞修飾語，非獨立形式概念，不需要形式化。

**資訊不可能三角** ≡ 規模 → ¬(邏輯 ∧ ∀尺度: 真實(尺度))
  此為觀察歸納，非數學必然性（見第十七節注意事項）

## 觀察事實

來源：論文第四、五、六節；結構化列出於第十七節

F1：基本規則跨尺度存在（規則集在所有尺度下均有效）
F2：具體現象 = 組合表現(規則集, 尺度)
F3：組合表現(規則集, 尺度₁) ≠ 組合表現(規則集, 尺度₂) 當 尺度₁ ≠ 尺度₂（觀察事實，不依賴湧現）

前置條件：F1 ∧ F2 ∧ F3（此三條為全篇推導的公共前提）

## 邏輯跨尺度，規則跨尺度，組合表現不跨尺度

來源：論文第四節

從 F1 推出：邏輯跨尺度成立 ∧ 規則集跨尺度存在
從 F2 + F3 推出：組合表現(規則集, 尺度₁) ≠ 組合表現(規則集, 尺度₂) ↝ 真實(尺度₁) 可能 ≠ 真實(尺度₂)

真實(尺度) 是規則在特定尺度下的組合表現，非規則本身。
組合方式不能從規則本身邏輯地推導，只能從該尺度下的現實觀察取得。

## 這個論證不依賴湧現

來源：論文第五節

F3 的成立不需要湧現假設。

論據（觀察事實）：
  電磁力與引力場結構相似（均為平方反比律），但：
  · 電磁力強度 ≫ 引力強度（比例約 10³⁶）
  · 電荷正負可抵消；質量不可抵消

∴ 同一規則集在原子尺度與天體尺度下：組合表現(規則集, 原子尺度) ≠ 組合表現(規則集, 天體尺度)
  從電磁力與引力的可觀察性質差異推出；不依賴湧現

湧現為加重條件：湧現 ↝ 組合表現差異更劇烈，但非 F3 的必要條件。

推論：資訊不可能三角的前提（F3）比湧現更基本，三角的適用比依賴湧現的論點更廣。

## 組合表現隨尺度不同——三角成立的推導

來源：論文第六節

前置條件：F2 ∧ F3

推導鏈：

步驟一：真實(尺度₁) 依賴 組合表現(規則集, 尺度₁)
  從 F2 + 真實(尺度) 的定義推出

步驟二：真實(尺度₂) 依賴 組合表現(規則集, 尺度₂)
  從 F2 + 真實(尺度) 的定義推出

步驟三：組合表現(規則集, 尺度₁) ≠ 組合表現(規則集, 尺度₂)
  F3（觀察事實）

步驟四：在 尺度₁ 下建立的邏輯框架基於 組合表現(規則集, 尺度₁)
  應用於 尺度₂ 時，因 組合表現(規則集, 尺度₂) ≠ 組合表現(規則集, 尺度₁)（步驟三），不保證真實(尺度₂) 成立
  從步驟一 + 步驟二 + 步驟三推出

步驟五：當規模同時覆蓋 尺度₁ 和 尺度₂，統一邏輯與所有尺度下的真實不可同時滿足
  從步驟四 + 規模的定義推出
  即：規模 → ¬(邏輯 ∧ ∀尺度: 真實(尺度))

注意（論文明確聲明）：「不保證」是觀察歸納，非數學必然性。

## 與統一場論的區分

來源：論文第七節

設統一場論成立：∃統一規則集描述所有四種力

資訊不可能三角的約束在從規則到現象的組合層，不在規則層：
  從統一規則集計算具體現象時，仍需代入特定尺度的邊界條件 ∧ 做近似 ∧ 選截斷
  ∴ 即使統一規則集存在，F3 依然成立，三角依然適用

形式：統一場論成立 → F3 不受影響 → 資訊不可能三角不受影響
  從「F3 為觀察事實，非由規則不統一推出」推出

## 三角的自我強化

來源：論文第八節

設：∀尺度 ∈ {尺度₁, 尺度₂}：知識(尺度) 完整 ∧ 各自邏輯嚴密

各尺度內部邏輯完美，但各體系的基礎假設在另一尺度下不成立（從 F3 推出）：
  尺度₁ 下的邏輯框架 ⊗ 尺度₂ 下的邏輯框架

推論：各尺度知識越完整，跨尺度的邏輯衝突越尖銳
  從 F3 + 邏輯的定義推出

對 LLM：訓練資料品質越高、各領域覆蓋越完整 ↝ 跨領域推理矛盾越明顯

## 每個領域的資料都帶著自己的毒

來源：論文第九節

LLM 訓練資料 = ∪_{尺度} 知識(尺度)

每個領域的資料帶有跨尺度矛盾（從 F3 + 知識的定義推出）：

物理領域：∃尺度₁ ∈ {廣義相對論適用尺度}, 尺度₂ ∈ {量子力學適用尺度}：知識(尺度₁) ⊗ 知識(尺度₂)
  各自分別自洽，在奇點處合起來矛盾

生物領域：生物系統非邏輯最優化 → 知識帶演化冗餘與矛盾
  同一功能需求在不同物種有完全不同的解決方案

人文領域：知識(尺度) 含被權力塑造的敘事，與觀察事實混合
  組合變量維度（人文） > 組合變量維度（物理）
  → 資訊不可能三角約束強度在人文領域更高

共同結構：∀領域 ∈ 訓練資料：∃尺度₁ ≠ 尺度₂：知識(尺度₁) ⊗ 知識(尺度₂)
  矛盾來源：F3（非資料品質問題）

## 知識是有損的

來源：論文第十節

觀察事實：∀尺度：知識(尺度) ⊂ 組合表現(規則集, 尺度)（真子集）

有損方式（結構性，可觀察）：
  · 丟掉時間：動態過程 ↦ 靜態記錄
  · 丟掉尺度間連續過渡：連續變化 ↦ 離散學科體系
  · 丟掉組合表現的完整細節：完整細節 ↦ 經驗參數與魔術數字
  · 丟掉語境：語境依賴命題 ↦ 看似普適的命題

加重條件意義：
  即使考慮單一尺度，知識(尺度) ⊂ 組合表現(規則集, 尺度) ↝ 邏輯 ∧ 真實(尺度) 不保證同時成立
  F3 ∧ 知識有損 ↝ 資訊不可能三角的約束更嚴

## 知識的具體缺陷

來源：論文第十一節

以下均為觀察事實，作為知識有損性的具體實例：

實驗不可重複：∃研究成果 使得 ¬可重複（再現性危機）
  → 訓練資料含無效記錄，且與有效記錄文本形式相同，不可分辨

經驗參數無法解釋：∃無法解釋的參數 ∈ 知識(尺度)
  → 有效知識 ⊗ 邏輯嚴密標準（真正能用的知識常是最不符合邏輯嚴密標準的）

結論互相矛盾：∃問題甲：知識(尺度₁) ↝ 結論甲 ∧ 知識(尺度₂) ↝ ¬結論甲，尺度₁ ≠ 尺度₂
  從 F3 推出：不同尺度的真實可以不同，非錯誤

理論事後合理化：∃結論 使得 結論先行 ∧ 理論後設
  → 知識(尺度) 含事後歸因，混入推導結構

## LLM 是對不完整知識的再壓縮

來源：論文第十二節

知識(尺度) 已有損（第十節）；LLM 以統一參數擬合訓練資料，再做一次壓縮：
  訓練資料 → 統一參數（再次損失資訊），但每一層輸出看似完整而自信

LLM 的規模 = 訓練資料的知識多樣性（跨越的尺度數）：
  要覆蓋人類知識廣度 → 必須納入觀點衝突、邏輯不嚴謹、事實有誤的資料
  從知識(尺度) 在現實中的樣貌推出（第十節）

來源：論文第十三節

現行主流架構（Transformer）：統計相關性歸納，非邏輯演繹

統計歸納 ⊗ 邏輯演繹（兩種不同的認知機制）

  但：「何時用哪個模型」的判斷 = 尺度判斷 → 受資訊不可能三角約束

形式：建模成功 → ¬規模（犧牲規模頂點）
  從「建模 = 鎖定已知尺度」+ 規模的定義推出

## 幻覺是結構性的，但可以管理

來源：論文第十四節

LLM 系統性偏好：規模大 ∧ 邏輯看似嚴密 ∧ 真實性不可控

由資訊不可能三角（規模 → ¬(邏輯 ∧ ∀尺度: 真實(尺度))）推出：
  ∃尺度：¬真實(尺度)

幻覺的形式：
  知識(尺度) 丟掉語境（第十節）→ 命題不帶尺度標記
  ∴ ∃尺度：¬真實(尺度) ↝ 呈現為無尺度條件的自信輸出（幻覺）
  從知識有損性（語境丟失）+ 資訊不可能三角推出

迴避策略 = 犧牲規模：
  RAG：收窄至檢索文件 → 知識(尺度) 縮小 → ¬規模
  工具調用：真實(尺度) 判斷外包至可驗證系統 → ¬規模
  領域微調：鎖定特定尺度 → ¬規模

形式：∀迴避策略：迴避策略有效 → ¬規模
  從資訊不可能三角 + 各迴避策略的定義推出

結論：¬∃策略 使得 規模 ∧ 邏輯 ∧ ∀尺度：真實(尺度)
  幻覺率可降低，但降低的每種手段均犧牲規模

## 資料清洗的三選二

來源：論文第十五節

資料清洗 = 在三個頂點之間取捨：

清洗規則收緊 ↝ 邏輯↑ ∧ 規模↓（砍掉跨尺度真實的資料）
清洗規則放鬆 ↝ 規模↑ ∧ 邏輯↓（引入噪音和矛盾）

形式：¬∃清洗規則 使得 規模 ∧ 邏輯 ∧ ∀尺度：真實(尺度) 同時最大化
  從資訊不可能三角推出

具體衝突（各為觀察事實）：

時序矛盾：∃問題甲, ∃知識甲, 知識乙 ∈ 知識(尺度)：知識甲 ⊗ 知識乙（不同時期關於同一問題的相反結論）
  兩者可能在各自條件下均為真實，其條件差異未被明確記錄

文本形式相同矛盾：∃知識甲（教科書記錄）, 知識乙（實務記錄）∈ 知識(尺度)：知識甲 ⊗ 知識乙
  在純文本層面無法分辨；實務知識的尺度條件隱藏在工程師手感裡，從未成為文本

跨文化矛盾：∃尺度₁ ≠ 尺度₂：知識(尺度₁) ⊗ 知識(尺度₂)（不同法域、不同歷史敘述）
  選哪個即在特定尺度下犧牲真實

三選二的優先順序：
  優先順序依語境決定（即依尺度決定）→ 優先順序判斷本身受資訊不可能三角約束

## 三角不適用的地方

來源：論文第十六節

適用條件：F3 成立，即 組合表現(規則集, 尺度₁) ≠ 組合表現(規則集, 尺度₂)
不適用條件：∀尺度₁, 尺度₂：組合表現(規則集, 尺度₁) = 組合表現(規則集, 尺度₂)（組合表現尺度不變）

可證偽條件：若 ∀尺度₁, 尺度₂：組合表現(規則集, 尺度₁) = 組合表現(規則集, 尺度₂)，則 F3 不成立，三角推導瓦解。

判準：有無交互作用
  有交互作用 → 組合可能隨尺度改變 → F3 可能成立 → 三角適用
  純結構性、無交互作用的形式系統 → 三角不適用

不適用例：
  碎形：同一規則在所有尺度下 組合表現(規則集, 尺度) 相同
  幾何學：只描述空間結構，不涉及力的組合
  純數學：無交互作用

LLM 的分線（從上述判準推出）：
  純形式推理（數學、邏輯）：∀尺度₁, 尺度₂：組合表現(規則集, 尺度₁) = 組合表現(規則集, 尺度₂) → 三角不適用
  涉及經驗知識：F3 成立 → 三角適用

## 結構化描述

來源：論文第十七節

論文第十七節自身即為結構化描述，形式化文件予以對應並標記符號映射。

符號映射（論文原文 → 本篇概念名）：
  Scale → 規模
  Logic → 邏輯
  Truth(s) → 真實(尺度)
  K(sⱼ) → 知識(尺度ⱼ)
  System → 系統（論文中未作為獨立概念定義，為分析對象的統稱）
  R → 規則集
  s → 尺度（下標索引：尺度₁, 尺度₂, ...）
  D → 訓練資料
  θ → 統一參數
  p → 命題（量化變量）

論文第十七節形式定義（轉錄並對應）：

  規模 = ∪_{尺度} 知識(尺度)，且每個尺度下的知識充分
  邏輯 = ∀命題 ∈ 系統：¬(命題 ∧ ¬命題)  [作者裁決] 原論文含 q 變量，確認為筆誤；q 已移除。
  真實(尺度) = 系統輸出與尺度下可驗證的現實吻合

推導（與「三角成立的推導」段一致）：
  由 F2：真實(尺度) 依賴 組合表現(規則集, 尺度)
  由 F3：組合表現(規則集, 尺度₁) ≠ 組合表現(規則集, 尺度₂)
  ∴ 尺度₁ 下建立的邏輯框架應用於 尺度₂ 時，不保證真實(尺度₂)
  ∴ 規模 → ¬(邏輯 ∧ ∀尺度：真實(尺度))

注意（論文明確聲明）：「不保證」是觀察歸納，非數學不可能性。三角是經驗法則，不是定理。

加重條件：
  知識(尺度) ⊂ 組合表現(規則集, 尺度) ↝ 即使在單一尺度內，邏輯 ∧ 真實(尺度) 不保證同時成立

LLM 約束：
  訓練資料 = ∪_{尺度} 知識(尺度)
  LLM 以統一參數擬合訓練資料
  由資訊不可能三角：¬∃統一參數 使得 ∀尺度：真實(尺度) 在統一邏輯下成立

## 適用範圍與限制

來源：論文第十九節

適用：∀資訊系統 使得 F3 成立（∃尺度₁ ≠ 尺度₂：組合表現(規則集, 尺度₁) ≠ 組合表現(規則集, 尺度₂)）
不適用：純形式系統 使得 ∀尺度₁, 尺度₂：組合表現(規則集, 尺度₁) = 組合表現(規則集, 尺度₂)

三角不判斷：
  · 具體在哪個環節失敗（不預測失敗位置）
  · 三個頂點的優先順序（優先順序依尺度與語境決定，受三角自身約束）
  · 解決方案（描述結構性限制，非可工程克服的問題）

三角不解釋：
  · 尺度的本質
  · 為什麼 F3 成立（F3 為觀察事實起點，不被解釋）

元限制：
  資訊不可能三角自身 ∈ 知識(尺度)
  ∴ 資訊不可能三角也是有損的（第十節） ∧ 也受自身約束
