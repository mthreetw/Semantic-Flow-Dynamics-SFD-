## 定義

來源：論文第三節

以下按依賴順序排列（被依賴者先定義）。規則 為 core 原語，不在此定義。

組合表現 ≡ 規則集 R 在特定條件下相互作用的整體效應 C(R)
  性質：可直接觀察、可測量
  規則集跨條件不變，但各規則的相對權重與交互方式隨條件改變
  ∴ 不同條件下的 C(R) 可以不同

尺度 ≡ 使組合表現相同的條件的等價類，以 s 表示
  正式：條件 c₁ ≡_s c₂ ⟺ C(R, c₁) = C(R, c₂)
  記為 C(R, s) 時，s 是對「產生相同組合表現的條件集合」的命名
  尺度 不是先驗分類，而是從組合表現的可觀察差異歸納得出

邏輯 ≡ ∀ p, q ∈ System: ¬(p ∧ ¬p)（系統內部推理一致性）

真實(s) ≡ System 的輸出 ↦ 與 C(R, s) 吻合
  依賴：尺度

知識(s) ≡ C(R, s) 的有損文本化記錄，K(s) ≠ C(R, s)（觀察事實四）
  依賴：尺度

規模 ≡ System 同時容納 ∪ 知識(sⱼ)，j = 1, ..., m，m ≥ 2
  依賴：知識 → 尺度

資訊不可能三角 ≡ 以 {規模, 邏輯, 真實} 為頂點的結構性取捨約束：
  當規模開放（m ≥ 2）時，統一的 邏輯 與 ∀s: 真實(s) 不可同時滿足
  （由核心推導推出）

## 觀察事實（公設）

來源：論文第四節、第五節

F1: 規則跨尺度存在
  ∀s: R(s) = R（規則集本身不隨尺度改變）

F2: 具體現象 = 組合表現
  具體現象(s) ≡ C(R, s)

F3: 組合表現隨尺度改變
  ∃ s₁ ≠ s₂: C(R, s₁) ≠ C(R, s₂)
  注意：與先前版本不同，F3 在新定義框架下的意涵是：
  存在可區分的組合表現 regime（即世界不是碎形）——這是更清晰的經驗主張。
  F3 不依賴湧現（論文第五節論證）

F4: 知識有損性（加重條件，非三角成立必要條件）
  ∀s: K(s) ≠ C(R, s)

## 核心推導——資訊不可能三角成立

來源：論文第六節

前置條件：F1, F2, F3

步驟一：從 F2 推出
  真實(s₁) ← 依賴 C(R, s₁)
  真實(s₂) ← 依賴 C(R, s₂)

步驟二：從 F3 推出
  ∃ s₁ ≠ s₂: C(R, s₁) ≠ C(R, s₂)

步驟三：從步驟一 + 步驟二 推出
  在 s₁ 下建立的邏輯框架 L₁ 基於 C(R, s₁)
  L₁ 應用於 s₂ 時，因 C(R, s₂) ≠ C(R, s₁)
  → L₁ 不保證 真實(s₂) 成立

步驟四：從步驟三 + 規模定義 推出
  當規模同時覆蓋 s₁ 和 s₂（m ≥ 2）
  → 統一的邏輯 L 與所有尺度下的 真實(s) 不可同時滿足

結論：資訊不可能三角 成立
  規模 ∧ 邏輯 ∧ ∀s: 真實(s) → ⊥（經驗歸納意義，非形式邏輯矛盾）

注意：三角是經驗法則，「不保證」基於歸納而非演繹。

## 統一場論的區分

來源：論文第七節

統一場論成功 → 規則 R 統一
但：規則 R 統一 ⊬ ∀s₁, s₂: C(R, s₁) = C(R, s₂)
三角約束在組合表現層，不在規則層
∴ 統一場論 ⊬ 消除資訊不可能三角

## 三角的自我強化

來源：論文第八節

∀s: 知識(s) 在尺度 s 內可各自邏輯完美
但：∃ s₁, s₂: 邏輯(s₁) ⊗ 邏輯(s₂)（廣義相對論 vs 量子力學）
知識(s) 越完整 ∧ 越嚴密 → 跨尺度邏輯衝突更尖銳（自我強化）

## LLM 的三角約束

來源：論文第五部分

D = ∪ 知識(sⱼ)，j = 1,...,m → LLM 訓練 = 規模開放的資訊系統
由三角：¬∃θ: ∀s: 真實(s) 在統一邏輯下成立

幻覺形式推導（對應第十四節）：

步驟一：從核心推導
  規模開放 → ¬∃θ: ∀s: 真實(s) 在統一邏輯下成立
  ∴ ∃s: ¬真實(s)

步驟二：從 F4 + 第十節
  F4: K(s) ≠ C(R, s)
  具體有損方式（論文第十節）：尺度標記是語境的一部分，文本化時丟失
  ∴ 知識文本 = 不帶尺度條件的「看似普適命題」

步驟三：從步驟二推出
  LLM 訓練資料 = 不帶尺度標記的文本
  ∴ LLM 輸出繼承「宣稱普適真實」的形式

步驟四：從步驟一 + 步驟三推出
  ∃s: ¬真實(s) ∧ 輸出宣稱普適真實
  ∴ 幻覺 ← 以普適形式呈現、但在某些尺度下不符現實的輸出
  此推導不需要額外公設——自然語言不附帶尺度標記是 F4 的直接推論

迴避策略 = 限定規模 → 換取邏輯 ∧ 真實
  RAG → 規模收窄至已檢索文件
  工具調用 → 真實性外包給可驗證系統
  領域微調 → 規模鎖定特定尺度

## 邊界條件與可證偽性

來源：論文第十六節

三角適用：∃ s₁ ≠ s₂: C(R, s₁) ≠ C(R, s₂)（F3 成立）
三角不適用（可證偽條件）：∀ s₁, s₂: C(R, s₁) = C(R, s₂)（F3 不成立）
  例：碎形、幾何學、純數學

可證偽性：
  ∀ s₁, s₂: C(R, s₁) = C(R, s₂) ⊗ 資訊不可能三角成立
