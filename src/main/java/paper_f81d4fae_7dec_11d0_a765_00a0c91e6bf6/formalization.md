## 二、本文新定義

來源：論文第一章 1.3

### D-1 行為模板與制度模板

行為模板 ≡ 個體面對刺激的預設行動腳本
  （從 40a22ff8.過濾 + 40a22ff8.正反饋循環 推出：反覆通過過濾的信號在語意流中固化為行動傾向）

制度模板 ≡ 跨個體協調行為輸出的共用信號結構
  存續的三個必要條件（缺一不可，覆蓋循環狀態空間的三個獨立維度）：
    條件一（信號可通過性）：個體過濾允許模板信號通過（覆蓋「形成」維度）
    條件二（成本降低）：使用模板的協調成本低於不使用（覆蓋「持續」維度）
    條件三（非零和內容）：模板的核心信號輸出非零和（覆蓋「不自毀」維度）
  三條件充分性：任何提議的第四條件必須指出第四個獨立維度；不能則可分解為三個維度的重述

模板 ≡ 行為模板 ∨ 制度模板
  （行為模板與制度模板不互斥：制度模板在個體層面表現為行為模板）

### D-2 零和信號環境與非零和信號

零和信號環境 ≡ 信號環境，其中互動的結構性輸出為：個體甲的收益 = −個體乙的收益
  （環境屬性，定義在信號端可觀察輸出上）

非零和信號 ≡ 信號，其互動的結構性輸出中個體甲的收益 ≠ −個體乙的收益
  （信號屬性，可均得或均失）

零和信號環境 ↔ 非零和信號的主導比例趨近於零
  （零和環境不要求非零和信號完全缺席，要求其比例低到功能上不起作用）

### D-3 保護

保護 ≡ 在新循環脆弱期（已開始正反饋但尚未建立阻力結構），使其存活的外部干預
  （從 40a22ff8.循環替代 的 NC₁ 前提顯性化推出：信號容器進入需要物理環境允許，即保護存在）

### D-4 皇帝

皇帝 ≡ 在給定地理範圍內壟斷暴力使用的個體或組織
  皇帝的存續邏輯：
    任何能對皇帝施加暴力的獨立結構 → 威脅皇帝存在
    皇帝的 40a22ff8.過濾 將獨立結構編碼為威脅 → 拆除是唯一理性輸出
  （從 40a22ff8.過濾 + 40a22ff8.知見障 + 40a22ff8.權力 推出）

### D-5 家庭

家庭 ≡ 以生育為前提而建立的獨立組織
  定義承重結構：生育（唯一不可外包）
  五個功能面向（附加屬性，非定義核心）：
    物質供給、生育、非零和信號初始注入、初級社會化、道德模板傳遞
  附加功能可由外部結構接手：部落、宗族、教會、學校、社區
  家庭功能健全度 ≡ 附加功能的實際承擔程度
  不可替代性的分析命題基礎：生育不可外包 → 以生育為前提的獨立組織不可取消

### D-6 再生

再生 ≡ 語意流承載循環的人口基礎的持續補充過程
  數量維度：家庭數量 × 生育率，由家庭決定
  質量維度：新個體語意流初始化品質，由家庭附加功能 + 外部結構共同決定
  兩維度不獨立：數量由家庭決定，質量由家庭和外部結構共同決定

### 無敵之人

無敵之人 ≡ 行為輸出由零和模板驅動、不具備非零和互動能力、刑罰不構成行為約束的個體
  術語借用：西村博之 2008「無敵の人」；本篇重新定義——西村描述的是系統退化的異常輸出，
  本篇定義的是結構性輸出（見第五章 5.5 的完整動力學）

  三條生產路徑（行為輸出不可區分，下游分析只依賴輸出特徵）：
    路徑甲（D-5 缺損）：家庭附加功能不健全且外部結構清零 → 語意流從未被初始化
      （從 D-5 + 命題二B 推出）
    路徑乙（信號環境淹沒）：家庭功能尚存，但信號環境整體零和 → 家庭注入被稀釋至功能上不可區分
      （從 40a22ff8.功能性收斂 + D-2 推出）
    路徑丙（覆寫）：已初始化的個體進入持續零和信號環境 → 非零和模板被覆寫
      （從 P1 + D-2 推出）

### D-7 重建

重建 ≡ 新的正反饋循環從形成走到穩定的完整過程
  三層必要條件（同時滿足才能重建）：
    物理前提：資源存量高於恢復閾值（D-10）
    信號前提：至少一種語意流初始化結構存在（命題二B）
    保護機制：四條路徑至少一條可用（命題一）
  （從 40a22ff8.循環替代 + 命題一 + 命題二B + D-10 推出）

### D-8 統治成本

統治成本 ≡ 維持暴力壟斷所需的持續資源投入
  物理成本：維持暴力優勢的直接物質投入
  信號成本：維持被統治者服從信號所需的投入（制度模板可降低信號成本）
  統治成本 = 物理成本 + 信號成本

### D-9 崩潰

崩潰 ≡ 既有正反饋循環的穩定條件不再滿足、保護機制失效的狀態
  （從 命題一 + D-7 推出：四條路徑全部不可用且資源跌破 D-10，重建無法啟動）

### D-10 恢復閾值

恢復閾值 ≡ 使重建能夠啟動的最低物質資源存量
  農業社會：閾值低（個體持有田、井、種子，可脫離系統存活）
  現代社會：閾值高（個體生存物質前提集中在基礎設施，手裡什麼都沒有）
  （從 D-7 物理前提 + 第六章 6.3 語境提取）

### D-11 忠誠

忠誠 ≡ 個體或組織與系統的綁定關係，按代價不可逆程度分三種類型

  即時交易（第一層）≡ 支付在時即服從、支付停止即關係歸零的純現金綁定
    典型主體：基層執行者（監控員、基層執法人員、外賣員、流水線工人）
    對錢敏感度：最高（¬∃延遲）
    失效模式：二元斷崖（¬∃緩衝）

  位置依附（第二層）≡ 位置本身的價值（尋租空間、晉升機會）驅動的複雜計算
    典型主體：官員系統
    對錢敏感度：中（有自行向下搜刮的能力）
    失效模式：自我搜刮加速螺旋（40a22ff8.黑箱律：行為輸出不可預測）

  忠誠（第三層，狹義）≡ 個體願意承受不可逆代價（受傷、死亡）的行為傾向
    與 40a22ff8.信任 的區分：信任是信號層面的加權；忠誠是行為層面的，定義在行動上
    存在域：**只存在於暴力組織內部**（軍隊、武警、安全機構）
    產生機制：訓練和組織結構的產物，不可用金錢直接購買
    失效模式：最慢，但一旦失效不可逆

  三層性質（從 D-11 全定義推出）：
    敏感度遞減（第一層 > 第二層 > 第三層）
    失效速度遞減（第一層以天計；第三層以月到年計）
    失效是級聯的：每一層的失效模式恰好是下一層的失效輸入

### D-12 神聖性

神聖性 ≡ 暴力壟斷者在特定信號容器面前自行停止破壞行為的現象
  路徑一判定準則：∃信號容器 通過 D-12 判定 ↔ 路徑一可用

### D-13 三層盾

三層盾 ≡ 核武器在崩潰動力學中提供的三層防禦結構，逐層剝落且不可逆

  核盾（外層）：擋外部軍事介入
    力量來源：不確定性（¬∃確定發射能力，但「不確定對方能不能引爆」本身就是盾）
    衰減機制：核材料物理壽命（氚半衰期、維護體系崩潰），時間尺度以十年計

  常規威懾（中層）：擋碎片互攻和公開叛離
    謝林焦點效應：不知道別人是否仍信，理性選擇是繼續掛北京的牌子
    衰減機制：財政螺旋吃掉後勤、燃料、薪餉，衰減快於核盾

  品牌慣性（內層）：擋公開否認
    性質：協調博弈的信號層焦點，無物理基礎
    衰減機制：非線性——一旦足夠多人同時不信，一夜崩潰

  核心不對稱：進攻效用低（不能炸自己想控制的人口和城市）∧ 防禦效用高（不確定性=盾）
  關鍵限制：三層盾是碎片之間的穩定器，不是碎片內部的穩定器
  （從 4.5.1 核心不對稱 + 4.5.2 物理結構 推出）

## 三、核心推導

來源：論文第一章 1.4–1.7

### 3.1 核心推導一：循環形成必然

P1 + 40a22ff8.過濾 + P3 ⇒ 循環形成必然

P1 ↝ 語意流持續變化 → 40a22ff8.過濾 持續區分刺激
P3 ↝ 語意流持續坍塌為輸出信號
多個個體在共同信號環境中運作 ↝ 40a22ff8.功能性收斂 開始 ↝ 正反饋建立

□「永遠不形成任何循環」不可能成立
  （□ 來自 P1 + P3 + 40a22ff8.過濾 的組合；只要有人活著在互動，某種循環就會長出來）

### 3.2 命題一：保護路徑窮舉

命題一 ≡ 循環穩定所需保護的路徑恰好有四條，且僅此四條

2×2 窮舉推導：
  維度一：保護力量來源 = 系統內部 ⊕ 系統外部（邊界是給定的，非此即彼）
  維度二：約束方式 = 信號約束（坍塌前改變語意流方向）⊕ 暴力約束（坍塌後物理阻止行為）

  行為產出路徑：語意流→過濾→轉化→坍塌→輸出→行為
  介入點只有坍塌前和坍塌後，不存在第三種介入點
  ∴ 2×2 = 四條路徑且僅四條

路徑一 ≡ 內部信號約束 = 神聖性（D-12）
路徑二 ≡ 內部暴力約束 = 皇帝（D-4）+ 制度模板
路徑三 ≡ 外部信號約束 = 和平注入
路徑四 ≡ 外部暴力約束 = 軍事介入

排他性補充：
  經濟 → 信號環境刺激源分布改變 → 通過信號約束生效（不是第五條路）
  技術 → 暴力能力分布改變 → 通過暴力約束生效（不是第五條路）
  生物約束（飢餓、疾病）→ 語意流輸入刺激改變 → 通過信號約束生效

穩定條件：路徑一 ∨ 路徑二 ∨ 路徑三 ∨ 路徑四 可用 → 穩定有可能
封閉條件：路徑一 ∧ 路徑二 ∧ 路徑三 ∧ 路徑四 全不可用 → 穩定的結構性基礎不存在
（從 2×2 窮舉 + 行為產出路徑分析 推出）

### 3.3 命題二A：家庭不可替代（分析命題）

命題二A ≡ 家庭（以生育為前提的獨立組織）是代際再生的必要條件

推導：
  P4 ↝ 個體死亡 → 循環存續需要新個體 → 新個體需要被生育
  生育需要以此為前提的獨立組織（D-5 定義）
  ∴ 家庭不可替代是分析命題：生育不可外包 → 以生育為前提的獨立組織不可取消
  （從 P4 + D-5 定義推出；不可證偽）

### 3.4 命題二B：語意流初始化結構必要（經驗命題）

命題二B ≡ 代際再生還需要至少一種能提供語意流初始化的結構

推導：
  新個體被生育 ≠ 新個體能參與循環
  新個體需要語意流被初始化（D-1 三條件要求：D-5 第三層附加功能）
  P2 ↝ 語意流初始化不可從外部直接寫入 → 需要持續的非零和互動
  此功能家庭可提供，外部結構（部落、宗族、教會、學校）亦可提供

  失敗條件：D-5 附加功能不健全 ∧ ∄外部結構 → 代際再生在質量維度上失敗 → 輸出無敵之人
  （從 P2 + D-5 + D-1 三條件推出；可證偽：若新型外部結構湧現，命題被推翻）

### 3.5 無間地獄定義

無間地獄 ≡ D-7 重建的三層條件同時被突破，且循環形成仍必然發生的持續狀態

形式表達：
  □循環形成（從 3.1 推出）
  ∧ ¬∃保護機制（四條路徑全不可用）
  ∧ ¬∃語意流初始化結構（命題二B 失敗條件）

  設 T(t) = 稅基，M(t) = 維穩需求
  隱含前提一：T'(t) < 0（稅基單調遞減，從財政螺旋正反饋推出）
  隱含前提二：M'(t) > 0 且 M(t) → ∞（維穩需求無上界：命題三柱二 + 無敵之人結構性持續輸出保證）
  隱含前提三：∃t₀ 使 T(t₀) > M(t₀)（系統曾經能運作，歷史事實）
  由介值定理：三個隱含前提同時成立 → ∃t* 使 T(t*) = M(t*)
  ∴ 交叉必然發生，不需要任何函數形式
  每種財政手段使用 ↝ 加速交叉點到來（印鈔/借貸/削減/發錢均適用）
  → 財政手段不是延遲，是加速

現代 D-10 特性（從 D-10 + 現代基礎設施初始條件推出）：

### 8.4 崇禎螺旋

崇禎螺旋 ≡ 中央鎮壓螺旋與地方搜刮螺旋互相加速、均指向財政終點的動力學過程

中央螺旋（循環，從 D-4 + D-8 + 三層忠誠結構推出）：
  鎮壓 ↝ 消耗資源 ↝ 加稅 ↝ 更多城市崩潰 ↝ 更多暴動 ↝ 加稅
  退出條件：鎮壓能力 > 暴動規模（此條件下財政螺旋使其不可維持，不可退出）

  與歷史崇禎的三個差異（從 D-13 + 三層忠誠結構 + 財政螺旋推出）：
    差異一：鎮壓產出受過訓練的無敵之人（復員回崩潰城市）
    差異二：現代稅基恢復周期 ≫ 農業一個種植季
    差異三：核盾壓縮每個決策窗口（見核盾時間壓縮）

地方螺旋（循環，從 D-11 + 命題三棘輪推出）：

  退出條件：預期改變（盲區保證不可退出）
  搜刮對象精確地是離爆炸最近的人口（無敵之人）

雙螺旋互相加速（從 兩個螺旋 + 盲區推出）：
  中央加稅 = 地方搜刮授權 ∧ 地方搜刮製造暴動 = 中央加稅理由
  地方螺旋比中央快（信息更準確，更早開始搜刮）

核盾時間壓縮（從 D-13 + 4.5.6 獨立門檻悖論推出）：
  分散存放 ↝ 第一個叛離軍區自動獲得核材料控制權 ↝ 兩個時鐘同時倒數：
    政治時鐘：不動手等於告訴所有人你不敢（信號邏輯）
    核時鐘：核材料每多一天在叛軍手裡，髒彈可能性增加一分
  ↝ 北京唯一理性輸出：立刻消滅第一個拿到核材料的叛軍
  致命悖論：速戰速決需要強大軍隊，但清洗掏空軍官團（6.8.1-6.8.2）

  ∴ 崇禎螺旋決策窗口從以年計壓縮為以週計

### 8.5 城市死亡物理學

  → 人口被迫向農村擴散（農村=無敵之人大本營，無法承接）

### 9.1 命題六：逐輪遞減

### 9.2 命題五：非永恆性與終態

命題五 ≡ 無間地獄不是永恆狀態，有兩類終止條件；四條路徑持續鎖死時，系統持續向第二類靠近（框架決定方向，不決定哪一類先到達）

第二類終止條件：動力學載體消失（人口和物質基礎跌破 D-10）→ P4 在人口層面的集體實現

核盾加固效應（從 D-13 + 6.8.8 推出）：
  核盾鎖定碎裂狀態 → 第一類終止條件被鎖得比無核武器情景更死
  外層（核盾）有物理壽命上限，最終剝落後碎片鎖定消失
  ∧ 外層剝落時下層的溶解早已跑完

### 9.3 兩層終態

兩層終態 ≡ 動力學的空間收斂形態，由 D-13 三層盾的尺度下限決定

核春秋（上層，從 D-13 + 4.5.6 獨立門檻悖論推出）：
  ≡ 幾十個有核材料的大碎片，被 D-13 外層鎖定，互不可滅
  名義上北京附庸，實際聽調不聽宣（4.5.6 獨立門檻悖論）
  時間尺度：以十年計（受制於核材料物理壽命）
  對比歷史類比：春秋是漏斗（劍有用→最終統一），核春秋是平底鍋（核盾鎖住碎裂→不收斂）

海地化（下層，從 命題六 + 無敵之人動力學推出）：
  ≡ 大碎片內部裂成的無數小碎片，跑無核的純暴力博弈
  資源節點控制 = 人口控制，時間尺度：以月計

兩層關係（從 D-13 + 命題六推出）：
  上層穩定（D-13 外層鎖定）∧ 下層持續溶解（財政螺旋 + 命題六）

  核材料不因碎片內部秩序歸零而消失——它還在倉庫裡，只是看守它的人也是無敵之人了
