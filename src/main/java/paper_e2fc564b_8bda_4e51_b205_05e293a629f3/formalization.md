## 一、宣告區

來源：論文第一節（1.2 核心定義）

### 前置條件

40a22ff8.P1–P4 全部成立（繼承自 40a22ff8）
3f8b1a9e.生物性 成立——不可關閉

### 框架邊界宣告

本篇研究對象：規定作為壓縮機制的形成、運作與失效條件
規定 ⊂ 3f8b1a9e.成文層（規定是制度成文層的子集）
差異來源：強制力（規定與其他制度形態的結構性差異只有一個來源）

可證偽元條件（從論文前提宣告繼承）：
  路徑一：∃情境：P1 ∧ P2 ∧ P3 ∧ P4 成立 ∧ 本篇命題不成立 ⊗ 本篇推導
  路徑二：直接挑戰 P1/P2/P3/P4（見 40a22ff8 §2.3）

### 背書規定

背書規定 ≡ 以強制力執行規定，使違反代價對受規者結構性為正
（本篇原語，不從上游推出）

### 受規者

受規者 ≡ 有義務服從規定 ∧ 無能力背書規定的個體
  條件一：有義務服從規定
  條件二：無能力背書規定
  兩個條件必須同時成立：
    ¬條件二（單有服從義務）= 完整政治身份描述，不是動力學上的不對稱位置
    ¬條件一（單有排除背書）= 規定覆蓋範圍之外的人
    條件一 ∧ 條件二 → 動力學上的結構性不對稱位置

### 規定

規定 ≡ 有強制力背書的成文壓縮機制
  邊界條件一（成文）：必須固定在獨立於個人語意流的 40a22ff8.信號容器 裡
    推導：40a22ff8.P3 → 語意流不可還原為信號 → 成文是壓縮的唯一可行形式
  邊界條件二（強制力）：違反代價不依賴對方在意關係才有效
  邊界條件三（壓縮機制）：讓大量個體的行為輸出趨近，不需要每次重新協商
  三個邊界條件缺一不構成規定（論文§1.2明確宣告）

可證偽條件（規定定義）：∃有強制力的成文協調機制：不屬於本篇定義之規定 ⊗ 規定定義

宗教法的動力學身份（條件分類，不作為 export）：
  情況甲：有國家暴力執行 → 是規定（強制力背書存在，與世俗法律動力學相同）
  情況乙：只有社群排除 → 強制力有效的條件是退出成本夠高；退出成本決定邊界
  情況丙：純靠信仰 → 是勸說，不是規定
  分叉點：強制力背書是否存在

### 勸說

勸說 ≡ 個體自願服從的壓縮機制，強制成本趨近於零
  （← 3b1c4d8e.幻覺（陰面機制）的對立面：勸說不依賴幻覺潤滑，不屬於陰面機制）

規定 vs 勸說：
  規定：強制成本永遠為正（陰面，← 3b1c4d8e.幻覺（陰面機制）所描述的機制類型）
  勸說：強制成本趨近於零（陽面，語意流方向自發改變）
  兩者是替代關係，不是互補關係
  勸說覆蓋的範圍決定規定需要啟動多少次
  ¬封閉分類（Q10裁決：兩者不窮盡所有壓縮機制）

### 正當性信號

正當性信號 ≡ 使個體語意流地形形成「應該服從」低阻力方向的信號機制
  效果：降低強制成本，不依賴強制力直接啟動
  機制：信號改變語意流地形（← 40a22ff8.阻力）↝ 服從方向的阻力降低 ↝ 強制力啟動次數減少
  正當性信號有效 ↝ 壟斷者用更少的暴力維持更大的覆蓋範圍
  正當性信號失效 ↝ 強制成本上升：投入更多暴力 ∨ 覆蓋範圍收縮

## 二、規定的起源條件

來源：論文第二節

### §2.1 不成文層的兩個結構性上限

前置條件：熟人群體靠 3f8b1a9e.不成文層 壓縮；社群排除是不成文層的最強強制手段

規模化上限 ≡ 3f8b1a9e.不成文層壓縮機制在群體規模超過臨界門檻後結構性失效的狀態
  失效原因：群體超過門檻 → 共享循環歷史消失 → 不成文層壓縮基礎不存在
  暴力不能解決：壟斷者不能同時在每個地方
  （從 3f8b1a9e.不成文層定義推出：不成文層依賴物理條件和日常協調，規模化破壞這個基礎）

陌生人上限 ≡ 3f8b1a9e.不成文層壓縮機制在陌生人之間結構性失效的狀態
  失效原因：陌生人之間無共享語意流地形 → 所有依賴共享歷史的壓縮機制全部失效
  （從 3f8b1a9e.不成文層定義推出：不成文層依賴共同的物理條件和協調歷史）

規模化上限 ∧ 陌生人上限 ↝ 規定的動力學起源
  推導：規定是唯一可以在規模化條件下、在陌生人之間、不依賴共享語意流地形運作的壓縮機制
  （從 兩個上限定義 + 規定定義推出）

陌生人規模下規定的三個結構性要求（屬性，非獨立概念）：
  抽象化：不依賴判斷者認識當事人
  強制力不依賴關係：違反代價結構性為正（← 邊界條件二）
  可計算性極高：詮釋空間立刻被尋租（← 3b1c4d8e.尋租空間）

### §2.2 規定是陌生人合作的基礎設施

命題：規定是唯一可以在規模化條件下維持大規模陌生人合作的壓縮機制
（從 規模化上限 + 陌生人上限 + 規定定義推出；此為本篇的核心定位命題）

### §2.3 文字是結構性前提

推導（從 40a22ff8.P4 + 40a22ff8.P3 推出）：
  40a22ff8.P4 → 個體消亡 → 語意流終止 ∧ ¬∃恢復
  ∧ 40a22ff8.P3 → 語意流不可無損編碼為信號
  → 規定若依賴個人語意流儲存 → 個人消亡 → 規定隨之變形（← P4 + P3 的聯合效果）
  文字讓 40a22ff8.信號容器 第一次可以脫離個人語意流獨立存在
  → 規定第一次可以跨越個人死亡存續
  ⇒ ¬文字 → ¬規定（文字是規定的結構性前提）

文字帶來的兩個規定獨有能力（屬性，非獨立概念；從 文字讓信號容器獨立 推出）：
  可計算性：給定情境，可以對照 40a22ff8.信號容器 推導應該輸出什麼；規則與執行分離，判決可被檢驗
  可比較性：兩條規定可以並排，看是否一致、矛盾、哪個優先；矛盾的結構性累積從這裡啟動

## 三、規定的生成機制

來源：論文第三節

### §3.1 立法的觸發結構

命題：規定是被觸發出來的，不是被設計出來的

推導（從 40a22ff8.P2 + 40a22ff8.P3 推出）：
  立法者在特定觸發事件條件下輸出條文
  立法者輸出 ← 40a22ff8.P2（輸出不可由輸入決定）
  立法者輸出 ← 40a22ff8.P3（語意流坍塌成條文必然損耗）
  立法者語意流地形由其位置 ∧ 歷史 ∧ 利益結構塑造（不可觀察，← 40a22ff8.P2）
  → 立法者主觀真誠的立法，客觀上和尋租輸出無法區分（← 40a22ff8.P2 封死觀察窗）

任何規定系統 = 無數個局部輸出的歷史沉積物
  沒有人設計過整體，沒有人對整體負責，也沒有人真正理解整體

立法輸入端非系統性（矛盾的底層來源，見§6.1）：
  立法輸入 ∝ 觸發事件分布
  觸發事件分布是非系統性的
  → 同一立法者在不同時刻的輸出無系統性關聯（← 40a22ff8.P1：語意流持續漂移）

可證偽條件（立法觸發命題）：∃立法者：能夠設計規定系統整體 ∧ 其輸出不受自身語意流地形影響 ⊗ 立法觸發命題
  （← 40a22ff8.P2 黑箱律否定此可能）

### §3.2 執行分布的極端不平等

命題：條文的執行分布必然是極端不平等的，不是立法品質的產物

前置條件：執行需要資源 ∧ 資源回報必須超過成本 ∧ 執行者從執行中提取不對稱回報
  （← 3b1c4d8e.尋租空間）

[熱點正反饋循環]（明確標記為循環）：
  執行密集 ↝ 代價信號製造 ↝ 行為壓縮 ↝ 持續違反和執行機會 ↝ 3b1c4d8e.尋租空間維持 ↝ 執行密集
  退出條件：執行資源耗盡 ∨ 熱點行為消失

[冷區正反饋循環]（明確標記為循環）：
  執行稀疏 ↝ 代價信號稀疏 ↝ 壓縮失效 ↝ 執行者無動機進場 ↝ 執行稀疏
  退出條件：外部驅動力介入（政治壓力 ∨ 資源投入 ∨ 媒體關注）

兩個循環同時在同一系統中跑 → 執行分布從結構上趨向極端不平等
  （從 3b1c4d8e.尋租空間 + 40a22ff8.P1 + 40a22ff8.P2 推出）

大量法條作為正當性信號包裝存在，從來不被執行，也不需要被執行（見§4.3）

## 四、規定的結構性特徵

來源：論文第四節

### §4.1 單向性

命題：規定只向下壓縮，從來不向上約束

推導（從 背書規定定義 + 607cd714.暴力壟斷者推出）：
  背書規定的強制力來自 607cd714.暴力壟斷者
  同一個壟斷者可以修改或廢除規定
  → 規定對壟斷者沒有獨立的約束力
  ⇒ 規定對壟斷者的約束 = 背後集體強制力的強度（≠ 條文強度）

可證偽條件（單向性命題）：∃情境：條文獨立約束最高壟斷者 ∧ ¬∃集體強制力背書 ⊗ 單向性命題

元規定 ≡ 宣稱約束最高暴力壟斷者的規定
  有效條件：集體強制力強度 > 0
  元規定強度 = 集體強制力強度（不等於條文強度）
  集體強制力消散 → 元規定約束力立刻歸零（從 單向性命題推出）

集體強制力 ≡ 多個行為者共同調動、可以背書元規定的強制力
  凝聚條件（三個，屬性，非獨立概念；同時成立才能凝聚）：
    外部威脅夠清楚：聯合抵抗成本 < 各自被壟斷者任意處置的成本
    脫隊成本夠高：脫離集體轉向壟斷者的收益 < 集體崩潰後暴露在壟斷者面前的損失
    共享不成文層夠深：維持集體強制力的協調成本可以承受
  任何一個條件鬆動 → 集體強制力分散 → 元規定約束力退化
  三個條件同時成立 → 每個行為者的最優解都是留在集體裡 → 元規定可以長期穩定
  （三個凝聚條件本身就是集體行動均衡的機制，不需要另一個機制來「保證」它）

管轄邊界上移動力學（描述性推導，不作為 export）：
  在元規定管轄邊界外的人 → 有動機把壟斷者拉入覆蓋範圍
  歷史趨勢：從貴族到資產階級到普選——複雜度驅動，不是主動讓步
  （複雜度驅動就是機制；歷史演化序列是校準，不是需要被形式推導的定理）

### §4.2 強制成本結構性為正

強制成本 ≡ 壟斷者維持規定有效壓縮所需的持續資源投入
  結構性來源：3f8b1a9e.生物性的暴力成分 ↝ 強制力是陰面機制（← 3b1c4d8e.幻覺（陰面機制））

不可歸零推導（從 40a22ff8.P1 + 40a22ff8.阻力推出）：
  威懾信號需要持續生成（執行是信號的輸出，執行需要資源）
  威懾信號停止 → 40a22ff8.P1 語意流持續漂移 ↝ 服從方向漂移 → 服從逐漸鬆動
  就算個體已內化規定，潛在違反者仍需威懾信號維持服從
  ⇒ 強制成本不可歸零（定義性特徵，非設計缺陷）

可證偽條件（強制成本命題）：∃機制：威懾信號停止後，受規者語意流服從方向不漂移，強制成本可歸零 ⊗ 強制成本命題

## 七、AI衝擊

來源：論文第七節

### §7.1 套利識別成本歸零

套利識別成本 ≡ 在規定系統中識別矛盾和套利空間所需的認知資源和時間成本
  AI條件下：套利識別成本歸零（AI可暴力運算出所有矛盾）
  驅動：3f8b1a9e.生物性的貪婪成分 ↝ 套利能力被充分使用（結構性推導，非道德問題）

連鎖效應（從 套利識別成本定義 + §3.2執行分布推出）：
  套利識別成本歸零 ↝ 所有冷區法條同時激活（可以系統性援引 ∧ 要求執行）
  執行容量固定 ∧ 冷區法條大量湧入 ↝ 執行通道被淹沒
  ↝ 支撐熱點冷區分布的正反饋循環被打亂
  瓶頸轉移：從知識移動到通道（誰能讓案件被執行 = 新的 3b1c4d8e.尋租空間）

### §7.2 正當性幻覺破裂

命題：正當性信號的運作條件在AI條件下結構性地被破壞，且不可逆

推導（從 正當性信號定義 + 套利識別成本歸零推出）：
  正當性信號的運作依賴：大部分人不知道規定系統裡有多少矛盾和套利空間
  套利識別成本歸零 ↝ AI把所有矛盾暴露 ↝ 「規定中立 ∧ 可計算 ∧ 人人平等」的宣稱結構性無法維持

不可逆性推導（從 40a22ff8.P1 + 40a22ff8.阻力推出）：
  「原來可以這樣」進入 3f8b1a9e.不成文層
  低阻力方向從「應該服從」漂移到「看能不能找到空間」
  40a22ff8.P1 → 語意流地形改變後不會自動回去 → 不可逆

傳統文化的結構性弱勢（從 3f8b1a9e.不成文層 + 40a22ff8.阻力推出）：
  不成文層裡「不把規定用到極限」的道德預期越深 → 越暴露在字面套利攻擊下
  使用AI最大化個人利益 → 在傳統文化不成文層下幾乎全部是不道德行為
  兩套邏輯（條文字面極限 ∧ 道德不成文預期）之間無對等關係 → 單向剝削結構

### §7.3 完美字面遵守的場景

命題：完美字面遵守加惡意使用，規定系統完全沒有工具回應

推導（從 自我指涉結構 + 套利識別成本歸零推出）：
  字面合法的完全套利 → 每一步有條文依據 ∧ 每一步無懈可擊
  違法 → 可被執行 ∧ 可被懲罰 ∧ 可被修補
  字面合法的完全套利 → 規定系統 ¬∃工具回應 ∧ 受害者 ¬∃說理空間

真正被摧毀的（從 3f8b1a9e.不成文層推出）：
  互動雙方語意流地形裡「不把規定用到極限」的低阻力方向
  這個低阻力方向住在 3f8b1a9e.不成文層裡，從來沒有寫進條文

連鎖效應：自我指涉結構在所有維度全面啟動（從 自我指涉結構 + 套利識別成本歸零推出）：
  每一個被援引的邊緣法條都是一個新的自我指涉起點
  系統在所有層次同時面對被不成文層緩衝的根本問題

### §7.4 執行容量崩潰後的退縮

推導（從 §2.2陌生人上限 + 多頭壟斷者結構推出）：
  執行容量崩潰 ↝ 衝突 ¬∃出口 ↝ 衝突退回到誰有更大的直接強制力
  私人暴力填補真空 ↝ 熟人網絡和地方壟斷者重新成為主要仲裁者
  陌生人互動問題不消失（← 陌生人上限：陌生人規模的壓縮機制無法退回不成文層）

候補壓縮機制——平台（從 規定定義 + 陌生人上限推出）：
  平台 vs 國家規定的關鍵差異：退出成本結構不同
    平台退出成本 ≪ 國家退出成本 → 壓縮機制的強制力結構不同
    平台規定的覆蓋邊界由退出成本決定（不由暴力決定）
  平台規定跑的動力學：與國家規定完全相同（§3.1 ∧ §6.1 ∧ §6.3 ∧ §7.1 全部適用）
  退出成本更低 → 系統更脆

### §7.5 不成文層的記錄

推導（從 40a22ff8.P1 + 40a22ff8.P2 + 3f8b1a9e.不成文層定義推出）：
  3f8b1a9e.不成文層不會真空，永遠在記錄真實發生的事
  規定系統失效後記錄內容：條文是武器 ∧ 「不把規定用到極限」是弱點 ∧ 字面套利是生存策略 ∧ 正式合作是陷阱
  ↝ 進入大量個體語意流地形（← 40a22ff8.阻力）↝ 刻出穩定的低阻力方向
  ↝ 成為下一個制度必須面對的物理條件

區分命題（從 40a22ff8.P3 損耗律推出）：
  不成文層記錄的是「正式系統是陷阱」，不等於「合作本身不可能」
  40a22ff8.P3 → 兩者不等價（對正式系統的不信任不等於對合作本身的否定）
  高信任封閉社群仍可在不成文層支撐的邊界內合作
  依賴正式規定系統的陌生人合作規模結構性退縮（← 陌生人上限）

### §7.6 AI衝擊後的三種終態

本篇引用上游概念（Q8裁決）：3f8b1a9e.轉型, 3f8b1a9e.無政府, 3f8b1a9e.滅亡

AI衝擊 ↝ 現有規定壓縮機制失效 ↝ 大規模陌生人合作基礎設施動搖（← 陌生人上限）

  3f8b1a9e.轉型：出現新的壓縮機制，在AI條件下維持大規模陌生人合作
    規定系統形式可能完全不同，但功能性替代現有系統
  3f8b1a9e.無政府：新的壓縮機制沒有出現，或只在熟人邊界內有效
    大規模陌生人合作規模退縮，制度退縮到熟人社會尺度穩定下來
    無政府是穩定終態，不是過渡狀態
  3f8b1a9e.滅亡：壓縮機制失效速度超過個體適應速度 ↝ 3f8b1a9e.可行域歸零

三種終態為封閉分類，繼承自 3f8b1a9e（3f8b1a9e.轉型 ⊕ 3f8b1a9e.無政府 ⊕ 3f8b1a9e.滅亡）
