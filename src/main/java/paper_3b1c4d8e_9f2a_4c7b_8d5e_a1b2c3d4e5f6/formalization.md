## 一、組織的起源

來源：論文第一節

### 前置條件

外部威脅存在（暴力 ∧ 天災 ∧ 其他群體）
個體在威脅面前沒有抵抗力
組織能力 ↝ 抵抗力（暴力碎形結構決定的收斂方向，非契約，非設計）

### 尋租空間

尋租空間 ≡ 組織中，某個體因擁有分配權而具備提取不對稱利益的結構性位置
  607cd714.暴力壟斷者存在 → 尋租空間存在
  （從 碎形頂端的分配權壟斷推出）
  尋租空間存在 ∧ 壟斷者是否提取：⊥⊥
  （結構推導，不依賴壟斷者動機或品格）
  「無私的領袖」¬∃消除尋租空間——空間存在，提取與否是行為選擇
  推導後果：下屬激勵結構 ∧ 信息悖論 ∧ 權力衰減全部從「空間存在」推出，不從「行為發生」推出

### 尋租行為

尋租行為 ≡ 壟斷者在結構中靠信號輸出實際提取不對稱回報的行為
  尋租空間存在 → 尋租行為 ∈ {發生, ¬發生}
  （取決於壟斷者行為選擇，不從結構必然推出）
  威脅路徑：不服從 → 負向後果；壟斷者可主動操作（製造負向後果）
  利益路徑：服從 → 正向後果；壟斷者可主動操作（製造正向後果）
  兩者共同特徵：可操作 ∧ 可設計 ∧ 強制成本 > 0

### 進入結構的被迫性

進入組織 = a1b2c3d4.被迫的賭注（外部威脅 vs 內部尋租的不可逃脫選擇）
個體拿自由換安全，但匯率由壟斷者定
壟斷者不知公平匯率（信息悖論），個體也不知（← 黑箱律）
但壟斷者有定價權
（從 607cd714.暴力壟斷者 + 外部威脅 + a1b2c3d4.被迫的賭注 推出）

## 三、權力太極

來源：論文第三節

### 陰面

陰面 ≡ {威脅路徑, 利益路徑} 組成的尋租結構，在組織中靠信號輸出提取不對稱回報
  威脅路徑：不服從 → 負向後果；壟斷者可主動操作
  利益路徑：服從 → 正向後果；壟斷者可主動操作
  結構特徵：可操作 ∧ 可設計 ∧ 強制成本 > 0
  陰面動力特徵（信號端可觀察，依 M2）：
    強制成本 > 0
    信息悖論（見第九節，前向引用）
    權力衰減（見第十節，前向引用）
    需要幻覺潤滑（見第四節，前向引用）
    壟斷者在提取（尋租行為發生）
  （從 607cd714.生物預設 的暴力 + 貪婪路徑 + 尋租行為 推出）

### 陽面

陽面 ≡ 語意流方向自行改變的自願結構，不從生物驅動力推出
  定義特徵：¬可操作 ∧ ¬可設計 ∧ ¬可製造（← 黑箱律：語意流方向不可設計）
  強制成本 → 0（語意流方向與輸出一致，不需外力維持服從）
  傳播成本 > 0（信號到達未接收者需要載體行動）
  陽面動力特徵（信號端可觀察，依 M2）：
    強制成本 → 0
    ¬∃尋租結構造成的信息悖論
    ¬∃尋租驅動的權力衰減
    ¬∃幻覺需求
    ¬∃提取

### 神聖性（引用上游）

[作者裁決] 本篇神聖性與 607cd714.神聖性 為同一概念，從本篇 exports 移除，改用上游定義。

陽面在太極結構中的運作：
  607cd714.神聖性 ↝ 陽面（壟斷者對神聖性信號容器自行低頭 = 語意流方向與約束一致）
  607cd714.神聖性 ≠ 尋租：¬∃不對稱提取，壟斷者自行停手
  強制成本 → 0（黑箱律：神聖性來源不可知、不可設計、不可製造）
  （從 607cd714 4.4 + 黑箱律 推出）

### 知識的雙面性

知識的雙面性 ≡ 知識橫跨陰陽兩面、作為陰陽轉化機制的結構性雙面性
  陰中之陽：
    壟斷者壟斷知識靠信息差尋租
    但知識具有降低信息差的結構性傾向（可被學會 ∧ 會洩漏 ∧ 會傳播 ∧ 會被偷學）
    傾向方向確定，速度受制度性阻力約束（專利 ∧ 軍事機密 ∧ 國家機密 ∧ 壟斷性技術門檻可延緩）
    → 尋租結構裡藏著瓦解尋租的種子（但可被延緩）
  陽中之陰：
    神聖性傳播需要解釋 → 解釋需要知識 → 誰掌握解釋權，誰就有信息差
    解釋權壟斷化 ↝ 陽面內部長出陰面（知識從傳播工具轉為尋租工具）
  知識是陰陽轉化的門（陰變陽 ∧ 陽變陰的機制）
  （從 607cd714 4.3 + 黑箱律 推出）

### 權力太極

權力太極 ≡ 組織中陰面（尋租結構）與陽面（自願結構）互為對立、互相消長，靠知識的雙面性作為轉化機制的動力結構
  動態性：權力太極(時刻) ≠ 權力太極(時刻₊₁)（← 流變律）
  不可穿透性：個體的陰陽歸屬在信號端不可判定（← 黑箱律）
  群體可觀測性：陰陽比例可透過群體行為統計測量觀測（← 40a22ff8.功能性收斂）
    觀測工具：民意調查 ∧ 支持率 ∧ 信任度調查 ∧ 維持成本佔比
  開放性：黑箱律封死窮舉，可能存在尚未辨識的機制
  陰陽消長約束：陰面 ∧ 陽面 → 非獨立，互為消長

可證偽條件（18.1）：
  ∃歷史案例: [持續穩定的權力結構 ∧ 陰面和陽面比例持續不變（¬∃消長）] ⊗ 權力太極

### 幻覺（陰面機制）

幻覺（陰面機制）≡ 陰面運作中壟斷者與被控制者各自持有的雙重認知偏差，作為陰面的潤滑劑

### 成本結構

成本結構 ≡ 陰陽兩面成本性質的系統性差異

    強制成本 → 0（語意流方向與輸出一致，不需外力繼續信）

    載體維持成本 > 0（陽面被污染的根源：傳播信號的人要吃飯 → 組織 → 尋租空間）
    統一成本 > 0（← 黑箱律 + 損耗律：自願者各自跑向不同方向，解釋分歧累積）
  陰面成本：
    威脅成本：最高，需暴力機關 ∧ 監控系統 ∧ 執行人力

      傳播方向：可沉澱於信號容器，累積效果降低成本
  關鍵差異：
    陰面成本 = 強制成本（停止付出則服從停止，必須持續）
    陽面成本 = 傳播成本 + 載體維持成本（可沉澱，不是每刻都付）

失敗條件對比：

## 七、合一與分離

來源：論文第七節

### 合一與分離

合一與分離 ≡ 陰陽兩面在同一或不同控制主體中的配置，兩種選擇各帶結構性代價

合一：
  合一 ≡ 壟斷者 = 陰面主體 ∧ 陽面主體（陰陽混在同一控制者手中）
  結構動力鏈（從 流變律 + 黑箱律 + 607cd714 4.1 + 607cd714 4.4 推出）：
    陰陽混合 ↝ 陰面腐蝕陽面
    自己約束自己：砸線成本 = 0（線在自己手裡）↝ 約束力趨零
    退化路徑：陽面崩潰 → 退回純陰面 → 成本劇增
    ∨ 神聖反噬（陽面標準反過來審判壟斷者）
  好處：結構簡單，決策快，協調成本低

分離：
  分離 ≡ 壟斷者 = 陰面主體 ∧ 陽面載體 ≠ 壟斷者（陰陽分屬不同主體）
  結構動力鏈（從 流變律 + 黑箱律 + 607cd714 4.1 推出）：
    陰陽分開 ↝ 陰面推越線 ↝ 陽面約束（砸不掉，在別人手裡）↝ 被迫停手 ↝ 陽面維持
  必要條件：陽面載體有獨立的自願來源維持自身
    ¬∃獨立自願來源 → 分離名存實亡（退化為合一）
  代價：陽面與陰面脫鉤 ↝ 信號環境中陽面地位下降 ↝ 世俗化
  雙向保護：
    保護陽面不被陰面吃掉（主要功能）
    保護陰面不被陽面的道德標準綁架（降低政治領袖道德風險成本）
  兩邊各自被自己的標準審判：陽面被道德標準審判；陰面被政治效能審判

壽命差異（從 7.1–7.3 + 5.2 推出）：
  分離：陽面耗散來源 = 解釋裂痕（黑箱律 + 損耗律）
  合一：陽面耗散來源 = 解釋裂痕 + 陰面寄生
  多一個耗散源 → 壽命短一個量級
  → 合一結構以百年計，分離結構以千年計

判準：看實際陰陽控制，不看制度名義

可證偽條件（18.3）：
  ∃系統性歷史案例: [合一結構政體存續時間持續超過同時期分離結構政體 ∧ 陽面未被腐蝕] ⊗ 合一與分離
  邊界備註：地理隔離延長的存續不是反例（威脅未到達，不是結構穩定）∧ 換壟斷者不換結構不是存續

（從 第三章 + 第五章 推出）

## 十二、革命悖論

來源：論文第十二節

### 革命悖論

革命悖論 ≡ 革命的成敗取決於革命前替代性陽面循環的成熟程度，而非革命行為本身
  前提：革命行為本身 = 最極端的暴力，摧毀舊結構（含掛在上面的陽面基礎）

真空型革命 ≡ 替代性陽面循環不存在或未成熟
  → 舊陽面摧毀，新陽面無根，陰面填入真空
  → 新政權起點比革命前更差（物質條件更差 ∧ 陽面歸零）
  → 陰面循環立刻啟動，起點更低

對齊型革命 ≡ 替代性陽面循環在革命前已獨立運作
  → 革命把陰面結構對齊到已存在的陽面（← 40a22ff8.循環替代）
  → 結構損傷小，恢復快，陽面完好

最殘酷推導：
  最需要革命的地方 = 最不具備革命成功條件的地方
  壓迫越深 ↝ 信號通道被切斷 ↝ 替代性陽面越難獨立生長
  → 需要革命的程度 ∝ 替代性陽面條件之不具備（正相關）

「足夠長的時間」= 經驗參數，論文自陳不是形式推導能給出的數字
  形式命題只主張方向：時間越長 ↝ 替代性陽面根越深 ↝ 革命後穩定性越高
  閾值明確留在形式推導範圍之外（不是論文跳步，是論文誠實標出邊界）

必要條件（能建起替代性陽面循環的條件）：
  地理隔離 ∨ 宗教獨立性 ∨ 獨立信號容器系統
  = 非革命者能控制的歷史和地理給定值

（從 第三章 + 第五章 + 40a22ff8.循環替代 推出）

可證偽條件（18.7）：
  ∃真空型革命: [新政權陽面比例立即且持續高於革命前舊政權 ∧ 高陽面不依賴革命前已存在的陽面基礎] ⊗ 革命悖論（真空型）
  ∨ ∃對齊型革命: [結構損傷與真空型革命無顯著差異] ⊗ 革命悖論（對齊型）

  陽面對陰面：成本不對稱
    陽面方：強制成本 → 0（語意流自願，無強制維持費用）
    陰面方（無陽面基礎）：維持成本持續上升
      幻覺斷裂 ↝ 尋租全部成本露出 ↝ 認同崩潰 ↝ 成本爆炸
  機制（從 黑箱律 + 40a22ff8.功能性收斂 推出）：
    大量個體語意流各自在黑箱裡跑（黑箱律）
    ↝ 各自跑出「不再服從」的輸出（功能性收斂）
    → 陰面幻覺斷裂 → 尋租全部成本露出

必要條件（任一不足則結構不成立）：
  條件₁：陽面有獨立的自願來源（壟斷者不擁有且無法製造的信號容器）
  條件₂：信號能傳播（壟斷者不能完全切斷信號通道）
  條件₃：壟斷者不能說「我們」（無法啟動同一個自願來源）

    神聖性傳播需解釋 → 解釋需知識 → 掌握解釋權者有信息差 → 信息差 = 尋租空間

## 十五、信號通道與速度

來源：論文第十五節

本節無新概念定義。應用上游概念分析技術對太極速度的影響。

形式立場：
  黑箱律 → 技術不改變語意流黑箱的性質 → 技術不改變太極的方向
  技術改變的是信號到達的速度和數量（信號容器物理性質）

速度效應（結構性後果）：
  陰面循環加速：尋租反饋循環更快跑（信息失真更快放大 ∧ 不滿更快傳播）
  陽面循環加速：神聖反噬更快發生，載體破碎速度加快
  不穩定結構存續時間壓縮：崩潰時間尺度從「世紀」壓縮到「年」甚至「月」
  信息悖論放大：技術放大信號供給，未放大壟斷者認知頻寬（生物性限制）→ 信息差擴大

效率雙面性（從 第三章 3.4 推出）：
  每項技術進步同時放大陰面和陽面
  實際被放大哪一面取決於控制權分布（太極本身決定）
  → 技術不決定歷史方向，加速歷史方向的兌現

可證偽條件（18.9）：
  ∃系統性歷史案例: [信號通道速度顯著提升後，不穩定結構平均存續時間不縮短甚至延長] ⊗ 速度效應
  邊界備註：壟斷者利用技術提升監控能力可能延緩崩潰，但不改變方向
