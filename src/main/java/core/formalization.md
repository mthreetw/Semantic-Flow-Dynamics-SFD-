# Core 原語公理界定

本文件界定框架的六個原語在本框架中的語意邊界。原語是預理論概念，不依賴框架內任何論文的概念來定義。所有論文的形式化以此為前提。

本文件由作者手動維護，不經 AI 生成流程。

---

## 時間

時間 ≡ 物理時間（可由時鐘測量的物理持續）

¬(時間 = 主觀時間感受)
¬(時間 = 社會學意義的「時代」)
¬(時間 = 敘事結構中的時序)

邊界：論文中「母親時間」「儀式時間」等概念是時間的社會配置——物理時間被分配到特定活動上。原語「時間」本身不含分配方式，分配方式由各論文定義。

## 空間

空間 ≡ 物理空間（可由距離測量的三維空間）

¬(空間 = 社會空間)
¬(空間 = 心理空間)
¬(空間 = 網絡拓撲中的抽象空間)

邊界：論文中「家庭空間」等概念是空間的社會配置——物理空間被賦予特定功能。原語「空間」本身不含功能屬性，功能屬性由各論文定義。

## 個體

個體 ≡ 經驗世界中可指認、可區分、可追蹤的單一實體

∀個體: 可以指著說「這一個」
¬(個體 = 抽象概念)
¬(個體 = 統計平均)
¬(個體 = 不可指認的集合趨勢)

邊界：個體的粒度由論文語境決定。同一個人在一篇論文中是個體，在另一篇中可能是更大個體（家庭）的組成部分。原語「個體」不預設粒度。

## 刺激

純粹認知活動 ≡ 不依賴即時物質過程觸發、僅由意識自身產生的心智活動（思考、想像、推理）
刺激 ≡ 一切可能改變個體狀態的來源 ∧ ¬純粹認知活動

¬(刺激 = 思考)
¬(刺激 = 想像)
¬(刺激 = 推理)
¬(刺激 = 白日夢)

邊界：激素分泌、衰老、疼痛、飢餓等物質過程是刺激——它們不是個體「想」出來的。白日夢不是刺激，但白日夢中肚子餓了，餓是刺激。

## 死亡

死亡 ≡ 生物體不可逆地停止一切生命功能

死亡 → □¬(生命功能恢復)
¬(死亡 = 社會性死亡)
¬(死亡 = 文化意義的消亡)
¬(死亡 = 組織的解散)
¬(死亡 = 信仰的瓦解)

邊界：框架中「死亡壓力」「慢性死亡」等概念是建構在此原語之上的論文概念，描述通往生物學死亡的社會機制或路徑，不改變死亡本身的定義。

## 規則

規則 ≡ 可由觀察和測量確認的法則

邊界：規則不預設領域，也不預設來源。

## 原語間關係

六個原語彼此獨立，不可互相定義：

時間 ⫫ 空間 ⫫ 個體 ⫫ 刺激 ⫫ 死亡 ⫫ 規則

¬∃f: 時間 → 空間
¬∃f: 空間 → 個體
¬∃f: 個體 → 刺激
¬∃f: 刺激 → 死亡
¬∃f: 規則 → 時間
¬∃f: 規則 → 空間
¬∃f: 規則 → 個體
¬∃f: 規則 → 刺激
¬∃f: 規則 → 死亡
（所有方向皆然，不可互相還原）

個體存在於時間和空間中，接收刺激，終於死亡——但這些是論文層的論證，不是原語層的定義。規則決定了刺激如何作用於個體、組合方式如何隨條件改變——但這同樣是論文層的論證。原語層只聲明它們各自獨立存在。
