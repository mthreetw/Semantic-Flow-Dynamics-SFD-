## 四、終態動力學

來源：論文第 3.1—3.7 節

### 崩潰後預設狀態

來源：論文第 3.1 節

崩潰 ↝ 長期不穩定（預設）
不穩定期間：應力 ↝ 繼續在 607cd714.模板 網絡傳導，沿 40a22ff8.阻力 最小路徑走
傳導結果 ↝ 加速備用模板形成 ∨ 使落點繼續漂移（不可預測）
結果 ↝ 沉澱為下一輪歷史條件（← 沉澱 ∧ 不可逆性定理）

### 穩定化條件

來源：論文第 3.2 節

穩定化條件（布林值）≡ ∃備用模板 ∧ 在落點穩定前被足夠多的人接受並實踐，形成 3f8b1a9e.制度
  穩定化條件 → 40a22ff8.功能性收斂重建 → 轉型
  ¬穩定化條件 → 不穩定持續 → 終態走向 無政府 ∨ 滅亡
  ∃備用模板 ¬→ 穩定化條件成立（應力傳導可能不走備用模板路徑）

### 轉型動力學

來源：論文第 3.4 節

轉型 = 突變 ⊕ 漸變（封閉分類）

突變成立條件：可觀察維度 ∃清晰斷點 ∧ 舊主體消失可指認
漸變成立條件：可觀察維度連續（¬∃可指認斷點）∧ 落點不可觀察維度根本不同

### 永久崩潰狀態動力學

來源：論文第 3.5 節

知識大爆炸臨界點 ⇒ 環境變化率 > 最大不成文層適應率（持續且永久）
⇒ ¬∃轉型穩定態
⇒ 永久崩潰狀態

永久崩潰狀態：
  備用模板反覆出現 ↝ 被下一波衝擊打散（∵ 環境變化率 > 適應率）
  + 3f8b1a9e.不成文層代際傳遞斷裂（← 40a22ff8.死亡律）
  + ∀外部文明同步進入此狀態（¬∃外部備用模板可借入）
  → 永久崩潰狀態 ↝ 無政府 ⊕ 滅亡（慢速路徑，時間尺度不可確定）

### 無政府動力學

來源：論文第 3.6 節

高階 607cd714.模板 失效 ↝ 陌生人協同成本極高（¬共同行為預期）
低階 607cd714.模板（熟人信任 ∧ 3f8b1a9e.生物性）繼續運作
應力 ↝ 沿 40a22ff8.阻力 最小路徑 → 熟人協同路徑
協同半徑 ↝ 文明尺度收縮至熟人社會尺度

結果：大尺度極端暴力 ∥ 小尺度極強互助（同一機制在兩個尺度的輸出）

### 滅亡

來源：論文第 3.7 節

3f8b1a9e.可行域 = ∅ → 滅亡（3f8b1a9e.物理條件不再支撐任何 607cd714.模板 運作）
□歷史黑幕（¬∃倖存者，¬∃記錄）（□ 來自：歷史黑幕定義 ∧ 40a22ff8.死亡律）
