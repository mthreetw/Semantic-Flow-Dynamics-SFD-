## 本篇概念定義

來源：論文第一至十六節

沒有語意流 ≡ 信號源的響應可由函數決定，流變律至死亡律不成立
  （從 黑箱律 + 經驗觀察 推出）

有語意流 ≡ 信號源的響應不可由輸出決定，流變律至死亡律從對面也成立
  有語意流的操作性判定受黑箱律約束：觀察不可確認函數不存在，只能估計
  （從 黑箱律 推出）

互動 ≡ 個體向有語意流的信號源坍塌輸出，並接收其響應的過程
  （從 有語意流 + 坍塌 推出）

耦合循環 ≡ 穿過黑箱的正反饋循環——循環的兩端都是黑箱，你的坍塌輸出是對方的信號輸入，對方的坍塌輸出是你的信號輸入
  個體甲坍塌輸出 ↝ 信號到達個體乙 ↝ 乙的過濾 ↝ 乙的轉化 ↝ 乙坍塌輸出 ↝ 信號到達甲 ↝ 甲的過濾 ↝ 甲的轉化 ↝ 甲坍塌輸出 ↝ 循環持續
  耦合循環繼承正反饋循環的結構，新增：信號場不再被動，循環穿過另一個黑箱
  （從 正反饋循環 + 有語意流 推出）

雙向不透明 ≡ 黑箱律與損耗律在耦合循環中雙向成立的結構性後果
  黑箱律從甲成立：甲的語意流方向不可由當下方向與信號決定
  黑箱律從乙成立：乙的語意流方向不可由當下方向與甲的信號決定
  損耗律從甲成立：甲的語意流不可還原為甲的輸出信號
  損耗律從乙成立：乙的語意流不可還原為乙的輸出信號
  ⇒ 雙方都只接收到對方的有損輸出，不是對方的語意流
  （從 黑箱律 + 損耗律 推出）

不可預測性相乘 ≡ 耦合循環中每一輪不可預測性穿過兩個黑箱的結構性後果
  甲的坍塌輸出不可預測（黑箱律）↝ 到達乙後效果不可預測（黑箱律從乙成立）↝ 乙的響應到達甲後效果再次不可預測（黑箱律回到甲）
  （從 黑箱律雙向 推出）

功能性發散 ≡ 兩個黑箱的坍塌輸出從相容走向不相容的過程
  功能性發散 = 功能性收斂的反向
  瞬間發散：斷崖觸發，一次跳到不相容，通道關閉
  漸進發散：雙方語意流地形各自漂移，功能性收斂的窗口越來越窄直到消失
  崩潰在耦合層，不在個體層——個體的語意流沒有崩，是兩個語意流之間的耦合循環斷了
  （從 循環不穩定性 + 流變律 + 黑箱律 + 死亡律 推出）

語意流地形 ≡ 個體此前全部坍塌序列的沉積物所構成的阻力分布
  文化、成見、情緒、經驗、信任結構 = 過去正反饋循環刻出的阻力分布
  語意流地形不是互動的背景，是互動的初始條件
  （從 正反饋循環 + 知見障 推出）

估計 ≡ 在雙向不透明下，對信號源響應模式的猜測
  [作者裁決] 三個層級為估計的屬性，不拆分為獨立概念
  估計精度有結構性天花板（黑箱律封住對方語意流，損耗律保證對方坍塌輸出有損）
  三個層級：
    零知識：對信號源無觀察歷史，僅自身語意流地形的投射
    文化知識：群體級響應模式統計規律，個體殘差仍在（黑箱律保證）
    個體觀察：長期坍塌輸出序列可反推，取得成本最高，流變律保證持續過期
  估計精度受知見障約束——在自己的知見障裡猜對方的地形
  深思熟慮增加精緻度，不增加準確度；準確度只在外部信號到達時校準
  （從 雙向不透明 + 被迫的賭注 + 黑箱律 + 損耗律 推出）

偏好 ≡ 語意流地形中，阻力夠低、方向夠寬、足以讓耦合循環在裡面跑的區域
  偏好不是奢侈品，是生存必需品：沒有偏好，地形全是斷崖，全是斷崖就死了（死亡律）
  偏好的存在是淘汰壓力的殘留——死亡律篩掉斷崖密度過高的地形
  （從 死亡律 + 過濾 + 耦合循環 推出）

斷崖 ≡ 語意流地形中阻力不連續躍升的結構特徵
  [作者裁決] 斷崖與禁忌為兩個獨立概念——斷崖是地形結構，禁忌是觸發事件
  觸發時通道關閉，信號降級為噪音，單次觸發，不可逆
  偏好衝突的代價是連續的（阻力升高，通道存續）；斷崖觸發的代價是不連續的（通道關閉）
  （從 過濾 + 阻力 推出）

禁忌 ≡ 斷崖被觸發的事件——坍塌輸出踩到對方語意流地形中的斷崖，導致通道關閉
  禁忌的辨識優先級高於偏好的辨識（從風險的攻防不對稱推出）
  禁忌觸發可以是單向不透明的——通道關閉，但對方的坍塌輸出可能沒有明顯變化
  個體自己也不一定知道禁忌是什麼，直到被觸發
  （從 斷崖 + 黑箱律 + 損耗律 推出）

風險壓縮 ≡ 在黑箱律約束下壓縮互動風險的結構性需求與機制的總稱
  風險的結構性存在（不可預測性相乘 + 斷崖）∧ 必須持續輸出（被迫的賭注）⇒ 對風險壓縮的結構性需求
  三種機制：關係、名聲、制度
  （從 不可預測性相乘 + 斷崖 + 被迫的賭注 推出）

關係 ≡ 反覆耦合循環產生的沉積物——互相校準過的響應模式估計、共享的信號環境、只有雙方懂的信號簡碼
  沉積物不屬於任何一方，是耦合循環本身的產物
  功能：把估計從零知識拉到個體觀察；斷崖可見，高阻力方向可辨識
  建立需要不可逆的坍塌投資，不保證回報
  關係的慣性：共享結構具有獨立的重建成本（沉沒結構不是心理謬誤，是真實的重建成本）
  關係的斷裂：禁忌觸發一次摧毀（攻防不對稱）
  關係的殘響：一方消亡或離開 ↝ 沉積物進入殘響擴散 ↝ 影響此後所有互動的初始條件
  （從 耦合循環 + 估計 + 單向坍塌 + 殘響擴散 推出）

名聲 ≡ 過去坍塌輸出的累積沉積物，停留在信號場中，到達所有潛在的信號源
  功能：讓不認識你的信號源也能把估計從零知識直接跳到接近個體觀察
  被動名聲：過去坍塌輸出的自然沉積（經驗觀察）
  主動名聲建設：刻意坍塌輸出改變所有潛在信號源的估計（經驗觀察）
  名聲攻擊：反向的信號設計，降低對方的名聲（經驗觀察）
  名聲的斷崖結構與禁忌觸發同構——慢慢累積，一次歸零
  名聲的穿透力來自過去不可逆坍塌的累積投資
  （從 信號容器 + 估計 + 信任 推出）

制度 ≡ 規則、契約、法律、市場慣例——把有語意流的信號源的響應壓縮成近似可預測
  壓縮越徹底 ↝ 互動退化為近似可預測 ↝ 語意流的作用空間被壓縮到可忽略
  博弈論完全適用的地方 = 語意流被制度壓縮到不在場的地方
  （從 有語意流 + 沒有語意流 + 黑箱律 推出）

坍塌空間 ≡ 約束條件（物理的、文化的、制度的）壓縮後剩餘的可能坍塌範圍
  約束越多 ↝ 坍塌空間越窄 ↝ 功能性收斂的機率越高
  （從 過濾 + 物理約束 + 知見障 推出）

壓縮光譜 ≡ 從約束多且坍塌空間窄（如超市）到約束少且坍塌空間寬（如相親）的連續分布
  語意流的作用空間越小 ↝ 經濟學和博弈論越有效
  語意流的作用空間越大 ↝ 經濟學和博弈論越失效
  （從 制度 + 坍塌空間 推出）

碰撞痕跡 ≡ 兩個不透明的坍塌序列碰撞的結果
  「價格」不是兩條曲線的交叉點，是碰撞痕跡
  （從 黑箱律 + 損耗律 + 坍塌 推出）

統計殘留 ≡ 大量黑箱在約束條件下的坍塌殘留出的可觀察模式
  一個交易中成交是碰撞；一萬個交易中成交是統計
  跟氣體定律同構：每個分子不可預測，大量分子產生統計規律
  供需曲線是統計殘留的描述，不是機制的描述
  （從 黑箱律 + 物理約束 + 大數 推出）

驅動力不對稱 ≡ 耦合循環中雙方的被迫程度不對稱
  不對稱直接影響坍塌輸出模式
  不對稱隨信號場狀態實時變動（流變律）
  （從 被迫的賭注 + 驅動力 推出）

價值 ≡ 語意流在那一刻的狀態，非商品的屬性亦非個體的穩定偏好
  流變律 → 價值持續變動
  黑箱律 → 連個體自己都不知道覺得值多少
  「值不值」是事後的合理化
  （從 流變律 + 黑箱律 推出）

貨幣 ≡ 功能性收斂的極致產物——沒有任何兩個人對同一面額的語意流是一樣的，但所有人的坍塌輸出在信號端相容
  貨幣完全是語意流動的產物，本身不代表任何物理實在
  經濟學所稱的「信心」= 大量語意流功能性收斂的歷史沉積物
  通貨膨脹 = 功能性收斂的偏移；惡性通脹 = 功能性收斂的崩潰（正反饋循環反方向跑）
  （從 功能性收斂 + 黑箱律 推出）

市場 ≡ 大量耦合循環的統計殘留呈現出的可觀察模式
  市場不是一個地方，不是一個機制
  「市場失靈」= 約束條件變了，新的統計殘留長出新的模式
  （從 統計殘留 + 耦合循環 推出）

## 一、起點與操作性定義

來源：論文第一節

信號源分類（經驗觀察）：
  沒有語意流的信號源：響應可由函數決定（石頭、風、鏡子、機器）
  有語意流的信號源：響應不可由函數決定，黑箱律從對面也成立

分類本身受黑箱律約束 ↝ 不能確認對面有語意流，只能估計 ↝ 分類是操作性的，不是本體論的
（從 黑箱律 推出）

互動定義：互動 ≡ 個體向有語意流的信號源坍塌輸出，並接收其響應的過程
（從 有語意流 + 坍塌 推出）

三篇遞增結構（不加新公設，流變律至死亡律已足夠）：
  語意流動力學：信號場給定
  被迫的賭注：必須輸出且不可逆
  互動動力學：信號場裡有些信號源也有語意流

## 二、為什麼互動

來源：論文第二節

驅動力存在（經驗觀察）：五類常見驅動力（生存與物質利益、安全與威脅、權力、意義追尋、認同需求），清單不可窮舉

驅動力指向信號場的不同部分（經驗觀察）：

驅動力 ∧ 被迫的賭注 ⇒ 互動的必要性
  驅動力指向有語意流的信號源 ∧ 必須輸出（被迫的賭注）⇒ 互動不是選擇，是別無選擇
  （從 驅動力 + 被迫的賭注 推出）

## 三、耦合循環

來源：論文第三節

正反饋循環 + 有語意流 ⇒ 耦合循環

推導鏈（因果過程）：
  個體向有語意流的信號源坍塌輸出 ↝ 對方響應 ↝ 響應到達，通過過濾 ↝ 語意流方向改變 ↝ 再次坍塌輸出 ↝ 循環形成
  （從 第二節 + 正反饋循環 推出）

與語意流動力學的正反饋循環的結構性差異：
  正反饋循環：信號場被動
  耦合循環：信號場不再被動，循環穿過另一個黑箱，對面也有流變律至死亡律
  （從 有語意流的操作性定義 推出）

## 四、耦合循環的結構性後果

來源：論文第四節

### 4.1 雙向不透明

黑箱律雙向 ∧ 損耗律雙向 ⇒ 雙向不透明
  黑箱律從甲成立 ∧ 黑箱律從乙成立 → 你穿不透對方，對方穿不透你
  損耗律從甲成立 ∧ 損耗律從乙成立 → 雙方都只接收到對方的有損輸出
  （從 黑箱律 + 損耗律 推出）

### 4.2 不可預測性相乘

黑箱律雙向疊加 ⇒ 不可預測性相乘
  甲的坍塌輸出不可預測（黑箱律）
  ↝ 到達乙後效果不可預測（黑箱律從乙成立）
  ↝ 乙的響應到達甲後效果再次不可預測（黑箱律回到甲）
  ⇒ 每一輪循環，不可預測性穿過兩個黑箱
  （從 黑箱律雙向 推出）

### 4.3 每次坍塌改變循環本身

流變律 + 單向坍塌 ⇒ 循環在每一次坍塌之後都不是坍塌之前的那個循環
  你的每一次坍塌不可逆（單向坍塌）↝ 語意流已被改變（流變律）↝ 過濾條件不同（知見障）↝ 下一次坍塌的初始條件不是上一次的初始條件
  同時：你的坍塌輸出到達對方 ↝ 改變對方的語意流 ↝ 對方的過濾條件也不同
  ⇒ 不存在均衡態
  （從 流變律 + 單向坍塌 + 知見障 推出）

循環不穩定性 + 流變律 + 黑箱律 + 死亡律 ⇒ 功能性發散
  耦合循環繼承正反饋循環的循環不穩定性
  功能性收斂隨時可能走向功能性發散
  （從 循環不穩定性 + 流變律 + 黑箱律 + 死亡律 推出）

### 4.4 信號場裡黑箱數量不限定

耦合循環對數量沒有約束——一對一到一對多，同一結構
  坍塌輸出受物理約束（一張嘴、有限注意力、有限時間）↝ 耦合循環在你這端永遠是窄口
  過濾自動處理落差：大量信號源的信號同時到達 ↝ 過濾把大部分降為噪音 ↝ 實際耦合數量遠小於信號場中存在的數量
  （從 第三節 + 損耗律 + 物理約束 推出）

## 五、範疇分裂

來源：論文第五節

黑箱律 ⇒ 計算與決定是兩件獨立的事
  此為上游概念 a1b2c3d4-e5f6-7890-abcd-ef1234567890.計算與決定的範疇分裂 在互動語境中的展開
  （從 黑箱律 推出）

黑箱律 + 不可預測性相乘 ⇒ 「策略」不存在
  策略預設可預測後果然後選擇最佳 ↝ 不可預測性相乘否定此前提
  黑箱律否定你能預測自己下一步輸出什麼
  ⇒ 沒有可預測的後果，就沒有可選擇的策略
  （從 不可預測性相乘 + 黑箱律 推出）

過濾 + 信任 + 雙向不透明 ⇒ 不存在脫離通道和接收方地形的獨立策略
  同一信號從不同通道進入 ↝ 效果完全不同
  決定效果的不是信號內容，是通道的信任加權、接收方的語意流地形、信號場的當下狀態
  （從 過濾 + 信任 + 雙向不透明 推出）

## 六、為什麼成交不應該發生

來源：論文第六節

雙向不透明 ∧ 不可預測性相乘 ∧ 損耗律雙向 ∧ 黑箱律封住自己 ∧ 每次坍塌改變循環本身 ⇒ 成交在結構上不應該發生

推導步驟：
  雙向不透明 → 你不知道對方要什麼（從 4.1 推出）
  不可預測性相乘 → 你不知道你的輸出到達對方之後會產生什麼效果（從 4.2 推出）
  損耗律雙向 → 雙方對彼此的理解結構性地不完整（從 損耗律 推出）
  黑箱律 → 你不知道自己要什麼（「需求」在互動中被互動本身改變）（從 黑箱律 + 流變律 推出）
  損耗律 + 黑箱律 → 語意流各跑各的（你的 X ≠ 對方的 Y）（從 黑箱律 + 損耗律 推出）
  ⇒ 每一個條件都在增加失敗的機率，沒有一個條件在保證成功
  ⇒ 成交才是需要解釋的事
  （從 4.1 + 4.2 + 4.3 + 黑箱律 + 損耗律 推出）

### 8.1 估計的結構

  猜的依據 = 對方過去的坍塌輸出（有損的、離散的、過期的信號）

### 8.2 第二層有效的推導

  （從 死亡律 + 物理約束 + 功能性收斂 推出）

死亡律 + 過濾 + 耦合循環 ⇒ 偏好是生存必需品
  活下來的地形 ↝ 斷崖密度落在可存活範圍 ∧ 有足夠大的低阻力區域（偏好）
  （從 死亡律 + 過濾 + 耦合循環 推出）

死亡律 + 正反饋循環 ⇒ 語意流地形被兩股力量塑形

死亡律 + 上述推導 ⇒ 第二層估計有效
  面對任何活著的黑箱 ↝ 可假設斷崖密度可存活、偏好區域大致可辨
  不是因為文化知識精確，是因為死亡律已篩掉地形完全無法預測的個體
  「常識」「禮貌」「社交直覺」= 對可存活地形的統計規律的經驗編碼（不是策略，是淘汰殘留的描述）
  （從 死亡律 + 過濾 + 功能性收斂 推出）

## 十一、坍塌輸出的可觀察模式

  （從 黑箱律 + 知見障 推出）

## 十二、成交：功能性收斂

來源：論文第十二節

### 12.1 功能性收斂不是語意收斂

黑箱律 + 損耗律 ⇒ 成交不需要雙方理解彼此
  信號端坍塌輸出銜接了，語意端從來沒有對齊過
  （從 黑箱律 + 損耗律 推出）

### 12.2 成交是碰撞，不是計算

黑箱律 + 知見障 + 坍塌 ⇒ 成交是碰撞
  成交 = 兩個黑箱各自沿著自己的阻力分布坍塌輸出 ↝ 輸出恰好撞上雙方都能接受的點
  沒有人算出了這個點，它是撞上的
  碰撞痕跡的定義見本篇概念定義
  （從 黑箱律 + 知見障 + 坍塌 推出）

### 12.3 暴力約束

死亡律 + 制度 + 驅動力 ⇒ 交換空間的因果鏈

因果鏈（含經驗前提）：
  生物性暴力是起點（經驗觀察）
  ↝ 最強者可暴力直接拿走
  ↝ 全拿則死（死亡律：拿太多，底下人餓死或聯合反抗）
  ↝ 暴力壟斷者被迫留餘地（不是道德，是活下來的那些恰好沒拿太多）
  ↝ 壓制所有其他人的暴力（國家、法律、警察、軍隊 = 暴力壟斷的制度化）
  ↝ 商業空間 = 「不能全拿」和「不許別人拿」之間的空間
  ↝ 在此空間裡「拿走」的成本高於「交換」的成本 ↝ 交換成為必要
  （從 死亡律 + 制度 + 驅動力 推出；其中「生物性暴力」「最強者壟斷」為經驗前提）

### 12.4 為什麼撞得上

物理約束 + 過濾 + 功能性收斂 ⇒ 約束條件把坍塌空間壓窄
  物理約束（經驗觀察）：錢有限、商品存在、時間有限、身體限制
  過濾約束：知見障沉積出阻力分布，語意流沿最深的溝走（從 知見障 推出）
  文化約束：功能性收斂的歷史產物（貨幣、價格慣例、交易流程）進一步壓窄（從 功能性收斂 推出）
  約束越多 ↝ 窗口越窄 ↝ 成交機率越高
  （從 物理約束 + 知見障 + 功能性收斂 + 制度 推出）

### 12.5 統計殘留

黑箱律 + 物理約束 + 大數 ⇒ 統計殘留
  一個人買一條魚 ↝ 黑箱律全面運作 ↝ 不可預測
  一萬個人買魚 ↝ 大量黑箱在類似約束下被壓縮到相似範圍 ↝ 殘留出看起來像規律的模式
  供需曲線 = 經濟學的統計力學
  經濟學的有效性不需要理性人假設，只需要約束條件和大數
  （從 黑箱律 + 物理約束 + 大數 推出）

### 12.6 經濟學的重新框定

以下現象不是反常，是框架的自然推論：

泡沫：正反饋循環在群體層面跑起來了
  越多人買 ↝ 信號越強 ↝ 過濾阻力越低 ↝ 方向越一致
  崩盤 = 循環跑到物理約束邊界然後斷裂

一價定律失效：價格是碰撞痕跡，每次碰撞初始條件不同
  一價定律只在制度把語意流壓縮到零時成立
  （從 碰撞痕跡 + 制度 推出）

品牌溢價：品牌 = 名聲 ↝ 風險壓縮有價值 ↝ 知見障讓你持續選已選過的 ↝ 正反饋循環鎖死

## 十三、建模示範：菜市場

  物理約束（經驗觀察）+ 過濾 + 黑箱律 → 坍塌空間已被壓得很窄（從 黑箱律 + 物理約束 + 過濾 推出）

### 13.2 進場與耦合循環啟動

個體進入信號場 ↝ 個體的存在已經是坍塌輸出 ↝ 到達所有攤販的過濾 ↝ 耦合循環已在跑
  他還沒說一個字，耦合循環已經在跑
  （從 耦合循環 推出）

### 13.3 驅動力不對稱

客人的驅動力指向整個市場，走掉成本接近零（經驗觀察）
老闆的驅動力被綁定在這一攤（攤租、進貨、貨會壞）（經驗觀察）
⇒ 耦合循環裡雙方的被迫程度不對稱
不對稱隨信號場狀態實時變動（流變律）
  （從 被迫的賭注 + 驅動力 + 流變律 推出）

### 13.4–13.6 交易結構與成交

商品非標準化、價格非固定（經驗觀察）
老闆報價 = 坍塌輸出，不是計算結果（從 黑箱律 推出）
客人聽了價格，反應不可預測——沒有明確底線（從 黑箱律 推出）
還價不可逆，動機在互動中被互動本身改變（從 黑箱律 + 4.3 推出）
雙方語意流各跑各的（從 黑箱律 + 損耗律 推出）
信號場裡其他信號源同時作用（從 4.4 推出）
成交 = 物理約束壓窄 + 文化約束壓窄 + 兩個坍塌序列撞上（從 12.1 + 12.4 推出）

### 13.7 可觀察模式

有些老闆送蔥、報價實在、聊家常——送蔥的攤位熟客比例在統計上傾向較高（經驗觀察）
相關性可用風險壓縮解釋——但解釋是事後描述，不是老闆的動機
  老闆的坍塌輸出是幾十年沉積物的產物（從 黑箱律 + 風險壓縮 推出）

### 13.8 壓縮光譜

菜市場 → 超市 → 無人超市：信號場裡有語意流的信號源被制度逐級移除（從 制度 推出）
成本結構轉移：菜市場成本在跑耦合循環，超市成本在價格（從 制度 推出）
菜市場仍然存在：壓縮掉的東西恰好是其他驅動力的滿足來源（從 驅動力 + 流變律 推出）

### 13.9 可證偽預測

以下預測從建模結構直接產出：

預測一：熟客的交易輪數在統計上少於生客
  模型推導：估計在個體觀察層 ↝ 風險已壓縮 ↝ 坍塌空間更窄 ↝ 輪數更少
  可證偽條件：∃市場: 熟客交易輪數在統計上 ≥ 生客 ⊗ 預測一

預測二：傍晚成交價在統計上低於早上
  模型推導：老闆的驅動力壓力隨時間升高（貨會壞）↝ 坍塌空間偏移
  可證偽條件：∃市場: 傍晚成交價在統計上 ≥ 早上 ⊗ 預測二

預測三：生客被報高價的機率高於熟客
  模型推導：估計在零知識層 ↝ 試探空間大
  可證偽條件：∃市場: 生客被報高價機率 ≤ 熟客 ⊗ 預測三

預測四：壓縮程度越高的零售形態，價格離散度越低
  模型推導：語意流的作用空間被移除 ↝ 碰撞痕跡趨近一致
  可證偽條件：∃零售形態對: 壓縮程度高者價格離散度 ≥ 壓縮程度低者 ⊗ 預測四

預測五：名聲好的攤販生客轉熟客的速率較高
  模型推導：名聲壓縮風險 ↝ 估計從零知識跳向個體觀察更快
  可證偽條件：∃市場: 名聲好的攤販轉化速率 ≤ 名聲差的攤販 ⊗ 預測五

預測六：一次嚴重負面體驗消滅關係的機率遠大於多次正面體驗建立關係的速率
  模型推導：攻防不對稱——建設幾百次坍塌累積，摧毀一次
  可證偽條件：∃人群: 正面體驗建立關係的速率 ≥ 負面體驗消滅關係的速率 ⊗ 預測六

預測七：同一客人不同日期對同一攤的行為模式不完全相同
  模型推導：流變律 + 黑箱律 ↝ 語意流地形持續變化
  可證偽條件：∃客人: 不同日期行為模式完全相同（可函數化）⊗ 預測七

預測八：菜市場交易速度在統計上慢於超市，但價格離散度高於超市
  模型推導：語意流作用空間大小差異
  可證偽條件：∃市場對: 菜市場交易速度 ≥ 超市 ∧ 菜市場價格離散度 ≤ 超市 ⊗ 預測八

## 十四、建模示範：相親

來源：論文第十四節

### 14.1 跟菜市場的結構性差異

菜市場 vs 相親（同一結構在不同參數下展開）：

  菜市場：商品存在，物理刺激豐富
  相親：要評估一個黑箱的未來所有坍塌輸出模式，黑箱律完全封住
  （從 黑箱律 推出）

  菜市場：功能性收斂標準清楚（錢換菜）
  相親：什麼算收斂，雙方都不知道
  （從 黑箱律 推出）

  菜市場：走掉成本接近零
  相親：機會的稀缺性不可估計
  （從 黑箱律 推出）

  菜市場：驅動力主要一個
  相親：五個驅動力全部同時在場互相干擾
  （從 驅動力 推出）

  菜市場：過濾慢慢跑
  相親：過濾在前幾秒完成大幅偏移
  （見 14.2）

### 14.2 前幾秒的過濾

外貌信號通道寬、到達速度快、阻力低 ↝ 在其他信號到達之前已大幅偏移語意流方向（經驗觀察 + 從 過濾 + 知見障 推出）
第一輪過濾結果不可逆地改變後續所有信號接收條件（從 知見障 + 單向坍塌 推出）
經濟條件信號也在前幾秒到達——跟生存驅動力直接相關，阻力結構上就是低的（從 驅動力 + 過濾 推出）

### 14.3 沒有交易軸

菜市場有價格作為交易軸，相親沒有（從 黑箱律 + 損耗律 推出）
你不知道自己要什麼——清單是事後合理化（從 黑箱律 + 知見障 推出）

### 14.4 禁忌的主導地位

相親的斷崖多、隱蔽、個體殘差大（從 估計 + 禁忌 推出）
禁忌觸發是單向不透明的——通道已關閉，坍塌輸出可能沒有明顯變化（從 黑箱律 + 損耗律 + 禁忌 推出）

### 14.5 風險壓縮的失效

三種風險壓縮機制全部失效或接近失效：
  關係：不存在，估計在零知識層（從 關係 推出）
  名聲：部分存在但高度有損且容易被主動建設（從 名聲 推出）
  制度：最弱——社會禮儀壓制最真實的信號（從 制度 推出）
相親令人焦慮 = 結構性風險沒有壓縮手段
  （從 風險壓縮 推出）

### 14.6 為什麼相親的「成交率」極低

相親的約束條件極少 ↝ 坍塌空間幾乎沒有被壓縮 ↝ 撞上的機率結構性地低
不是相親「太難」，是約束太少
菜市場成交率高不是因為人更理性，是因為約束更多
  （從 坍塌空間 + 壓縮光譜 推出）

### 14.7 結束的模糊性

菜市場結束乾淨，相親結束不乾淨
離開後語意流繼續跑 ↝ 方向不可預測 ↝ 功能性收斂在相親中不是一個時刻，是漫長、模糊的過程
  （從 流變律 + 黑箱律 + 功能性收斂 推出）

### 14.8 可證偽預測

預測一：前幾分鐘的可觀察行為模式在統計上強於後續對話內容預測最終結果
  模型推導：過濾在前幾秒完成大幅偏移
  可證偽條件：∃人群: 後續對話內容的預測力 ≥ 前幾分鐘可觀察行為模式 ⊗ 預測一

預測二：介紹人評價與實際見面印象的吻合度在統計上低
  模型推導：損耗律 + 黑箱律 ↝ 評價是介紹人的坍塌輸出，有損
  可證偽條件：∃人群: 介紹人評價與見面印象吻合度在統計上高 ⊗ 預測二

預測三：當事人事後對「為什麼喜歡/不喜歡」的解釋跟其可觀察行為模式的相關性在統計上低
  模型推導：黑箱律 + 損耗律 ↝ 解釋是事後合理化
  可證偽條件：∃人群: 事後解釋與行為模式相關性在統計上高 ⊗ 預測三

預測四：社會壓力越大的群體禁忌觸發閾值在統計上較高，但一旦觸發通道關閉速度不變
  模型推導：驅動力權重偏移 ↝ 閾值升高；禁忌的不連續結構 ↝ 關閉速度不受閾值影響
  可證偽條件：∃群體: 閾值不隨社會壓力變化 ∨ 通道關閉速度隨閾值升高而變慢 ⊗ 預測四

預測五：同一人對條件高度相似的對象在不同日期做出不同判斷的機率顯著高於零
  模型推導：流變律 + 黑箱律 ↝ 語意流地形持續變化
  可證偽條件：∃人群: 同一人對相似對象在不同日期判斷完全一致（可函數化）⊗ 預測五

預測六：有熟人背書的相親進入第二次見面的機率高於平台匹配
  模型推導：名聲壓縮 ↝ 估計跳過零知識層
  可證偽條件：∃人群: 平台匹配的進入二次見面機率 ≥ 熟人背書 ⊗ 預測六

預測七：「見了很多人都沒感覺」的報告頻率隨相親次數增加而上升
  模型推導：知見障累積 ↝ 過濾越來越窄
  可證偽條件：∃人群: 報告頻率隨相親次數增加而下降或不變 ⊗ 預測七

### 14.9 壓縮光譜

菜市場和相親 = 壓縮光譜的兩端
  菜市場：約束多，坍塌空間窄，成交率高。博弈論的近似部分有效。
  相親：約束少，坍塌空間寬，成交率低。博弈論完全失效。
  中間地帶：房屋交易、求職面試、商業談判——位置由語意流的作用空間大小決定
  框架的價值在劃出既有理論的適用邊界
  （從 壓縮光譜 推出）

## 十五、適用範圍與限制

來源：論文第十五節

適用：任何涉及向有語意流的信號源坍塌輸出的場景
  個體可以是人，也可以是黑箱律部分成立的 AI
  不限於兩個個體——一個黑箱面對整個充滿有語意流的信號源的信號場

不適用：
  不處理應不應該互動
  不處理信號場中沒有語意流的部分（回歸物理學）
  不處理單一主體內部決策（回歸被迫的賭注）
  不處理客觀規律的內容本身
  不提供出口

限制：
  不追蹤個體內心（黑箱律封住）
  不預測時間
  不預測具體行為
  建模的日常語言描述受損耗律約束，必然有損
  框架的表述本身也是信號，框架無法豁免自己的公設

三篇的關係：同一個框架，一個條件的遞增
  語意流動力學：信號場給定
  被迫的賭注：必須輸出且不可逆
  互動動力學：信號場裡有些信號源也有語意流

## 十六、與既有理論的關係

來源：論文第十六節

### 古典經濟學

成交是預設狀態 ⊗ 成交才需要解釋（框架立場）
供需曲線 = 統計殘留的描述，不是機制的描述
經濟學的有效性不需要理性人假設，只需要約束條件和大數
（從 統計殘留 推出）

### 博弈論

預設選項已知、收益已知、理性選擇 ⊗ 黑箱律全面否定此三項
  選項不可窮舉（黑箱律），收益不可量化（損耗律 + 黑箱律），選擇不是計算的輸出（黑箱律）
博弈論在語意流被制度壓縮到可忽略時成為有效近似
（從 黑箱律 + 損耗律 + 制度 推出）

### 行為經濟學

先預設理性基準，再列出偏離 ⊗ 框架：不存在理性基準
黑箱律 → 行為不是偏離了可決定的基準，是基準本身不存在
（從 黑箱律 推出）

### 交易成本經濟學

前提是交易本身沒問題 ⊗ 框架：交易本身需要檢驗
（從 第六節 推出）

### 資訊經濟學

「資訊不對稱」預設對稱的可能 ⊗ 框架：不透明是結構性的，不是可修復的
給雙方完全相同的資訊，語意流各跑各的，結果照樣不可預測
（從 黑箱律 推出）

### Bourdieu 的慣習

收斂：行為是沉積物的產物
分歧：慣習是靜態描述，不追蹤在互動中的即時改變；耦合循環追蹤此改變
（從 耦合循環 推出）

### Geertz 的巴扎經濟

高度吻合：巴扎的根本問題是資訊搜尋（雙向不透明 + 非標準化 = 極度不確定）
Geertz 是描述，框架提供形式結構
（從 雙向不透明 推出）

### 進化心理學

擇偶偏好的統計觀察與過濾結構吻合
分歧：進化心理學把權重當固定參數 ⊗ 框架：權重隨語意流地形實時變動
（從 語意流地形 + 流變律 推出）

### 婚姻市場理論

博弈論在婚戀領域的延伸，壓縮光譜已說明適用邊界
（從 壓縮光譜 推出）

### 依戀理論

依戀類型 = 初始語意流地形的分類，觀察有效
分歧：把類型當固定人格特質 ⊗ 框架：地形隨語意流持續變化，類型是統計近似
（從 語意流地形 + 流變律 推出）
