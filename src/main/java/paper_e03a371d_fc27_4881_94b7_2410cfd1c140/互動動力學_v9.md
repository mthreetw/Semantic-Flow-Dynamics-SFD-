## 摘要

兩個黑箱。互相穿不透（P2 雙向成立），互相聽不懂（P3 雙向有損），各自不知道自己要什麼（P2 封住自己），語意流各跑各的方向。在這些條件下，任何形式的成交在結構上都不應該發生。

但人類每天成交幾十億次。

經濟學、博弈論、交易成本理論都把成交當作預設狀態——理性行為者找到互惠的交換點，然後成交。需要解釋的是失敗。本文翻過來：成交才是需要解釋的事。

從語意流動力學的公設出發，增加一個條件——信號場裡有些信號源也有語意流——推導出耦合循環及其結構性後果。在此結構上回答：在 P2 和 P3 同時成立的條件下，成交是怎麼發生的？答案是功能性收斂——不是理解，不是最優化，是兩個不透明的坍塌序列恰好撞上了雙方都能接受的點。

推論的自然落點：供需曲線不是機制的描述，是大量黑箱在物理約束下的坍塌殘留的統計描述。經濟學的有效性不需要理性人假設，只需要約束條件和大數。泡沫、一價定律失效、品牌溢價、恐慌拋售——全部不是反常現象需要補丁，是框架的自然推論。

本文不加新公設。P1–P4 已足夠。

**關鍵詞：** 互動動力學、耦合循環、功能性收斂、成交、統計殘留、風險壓縮

## 一、起點與操作性定義

〔公設〕你是黑箱。P1–P4 對你成立。你的語意流持續運作，方向不可由當下方向與信號決定，不可還原為信號，你消亡則語意流終止。

〔公設〕信號場無限，持續到達。← P1 + D3

〔經驗〕信號場裡的信號源，從你這端觀察，分兩類：

**沒有語意流。** 石頭、風、鏡子、回音、機器。它們響應你的輸出——你踢石頭它動，你站在鏡子前它映——但響應可由函數決定。P1–P4 不成立。物理學管。

**有語意流。** 它響應你的輸出，但響應不可由你的輸出決定。函數 f 不存在。P2 從對面也成立。

〔公設〕第二類的操作性定義：P1–P4 從對面也成立。← 黑箱律

〔推導〕這個分類本身受 P2 約束。你觀察了一百次響應，都不符合任何已知函數，但你不能確認函數不存在——也許你還沒找到。你永遠不能確認對面有語意流，只能估計。分類是操作性的，不是本體論的。← P2

從你這個黑箱看出去，世界就是一個信號場。你分不出哪個信號源是石頭、哪個是風、哪個是另一個黑箱——你只接收物理刺激，刺激穿過你的過濾，改變你的語意流方向。但你可以觀察到：信號場的某些部分，在你輸出之後，響應模式改變了，而且改變不可由你的輸出決定。

**定義：互動 ≡ 個體向有語意流的信號源坍塌輸出，並接收其響應的過程。**

愛情、交易、對抗、說服、激勵、教育、養育、治療、談判、領導、欺騙、安慰、競爭、合作、霸凌、傳教、審訊、表演——人類把這些當作不同的現象，建了不同的學科，寫了不同的理論。差別在參數，不在機制。

三篇的遞增：信號場給定 → 必須輸出且不可逆 → 信號場裡有些信號源也有語意流。一個條件的遞增，不加新公設。

## 二、為什麼互動

〔經驗〕驅動力存在。語意流動力學列出五類常見的驅動力：生存與物質利益、安全與威脅、權力、意義追尋、認同需求。清單不可窮舉，每一項都不必然產生結果。

〔經驗〕驅動力指向信號場的不同部分。有些需求，沒有語意流的信號源就能滿足——你摘果子，果樹不需要有語意流。你按開關，燈亮了。

〔經驗〕但有些需求，結構上只有有語意流的信號源能滿足。交易需要對方願意交換，合作需要對方願意配合，愛需要對方也有語意流指向你，承認需要對方的坍塌輸出包含對你的回應，歸屬需要一群語意流功能性收斂的個體接納你。石頭給不了你這些，鏡子也給不了你。需要對方也有 P1–P4，也在過濾、轉化、坍塌。

〔推導〕你的驅動力指向了信號場中有語意流的那個部分。你必須向它輸出（被迫的賭注）。互動的原因不是你想互動，是你別無選擇。← 驅動力 + 被迫的賭注

## 三、耦合循環

〔推導〕你向有語意流的信號源輸出。它響應了。它的響應到達你，通過你的過濾，改變你的語意流方向，你再次坍塌輸出。它接收你的新輸出，再次響應。← 第二節 + v5 正反饋循環

循環形成了。

〔推導〕語意流動力學的正反饋循環，信號場是被動的。信號到達，過濾，轉化，坍塌，坍塌的結果進入信號場，信號場給定，循環的不穩定性來自 P1、P2、P4。

本文的循環，信號場不再被動。循環穿過了另一個黑箱。對面也有 P1–P4，也在過濾、轉化、坍塌。你的坍塌輸出是它的信號輸入，它的坍塌輸出是你的信號輸入。循環的兩端都是黑箱。← 第一節的操作性定義

**這是第三篇唯一真正新的結構：穿過黑箱的正反饋循環。稱為耦合循環。**

## 四、耦合循環的結構性後果

**4.1 雙向不透明**

〔推導〕P2 在你這邊成立：你的語意流的下一刻方向不可由當下方向與信號決定。P2 在對面也成立：它的語意流的下一刻方向不可由當下方向與你的信號決定。你穿不透它，它穿不透你。← P2 雙向

〔推導〕P3 也雙向成立。你的坍塌有損——你的語意流不可還原為你的輸出信號。它的坍塌也有損——它的語意流不可還原為它的輸出信號。雙方都只接收到對方的有損輸出，不是對方的語意流。← P3 雙向

**4.2 不可預測性相乘**

〔推導〕語意流動力學裡，你的坍塌輸出已經不可預測（P2）。現在你的坍塌輸出到達對方之後的效果也不可預測（P2 從對面成立）。對方的響應到達你之後的效果再一次不可預測（P2 回到你這邊）。每一輪循環，不可預測性穿過兩個黑箱。← P2 雙向疊加

**4.3 每次坍塌改變循環本身**

〔推導〕你的每一次坍塌不可逆。坍塌之後，你的語意流已經被改變（P1），你的過濾條件不同了（知見障），你的下一次坍塌的初始條件不是上一次的初始條件。同時，你的坍塌輸出到達對方，改變了對方的語意流（D3），對方的過濾條件也不同了，對方的下一次響應的初始條件也不是上一次的初始條件。循環在每一次坍塌之後都不是坍塌之前的那個循環。← P1 + 坍塌不可逆

沒有均衡態。博弈論預設均衡態存在——兩個理性玩家會收斂到一個穩定的策略組合。耦合循環沒有這個性質。循環的結構在每一輪之後都已改變，不存在「穩定下來」的可能。

〔推導〕耦合循環是正反饋循環，繼承語意流動力學的循環不穩定性——P1 持續變動，P2 方向不可預測，P4 個體消亡。功能性收斂隨時可能走向功能性發散。**功能性發散 ≡ 兩個黑箱的坍塌輸出從相容走向不相容的過程。** 瞬間發散：禁忌觸發，一次跳到不相容，通道關閉。漸進發散：雙方語意流地形各自漂移，功能性收斂的窗口越來越窄直到消失。崩潰在耦合層，不在個體層——個體的語意流沒有崩，是兩個語意流之間的耦合循環斷了。← v5 4.2 循環不穩定性 + P1 + P2 + P4

**4.4 信號場裡黑箱數量不限定**

〔推導〕耦合循環的定義（第三節）只要求信號場裡存在有語意流的信號源，對數量沒有約束。可能一個，可能一千個。一對一的對話和一個人面對整個市場，是同一個結構在不同數量下的展開。← 第三節

〔推導〕數量不限定，但你的坍塌輸出受物理約束——一張嘴、一個身體、有限的注意力、有限的時間。不管信號場裡有多少個黑箱，你的輸出通道就那麼窄。耦合循環在你這端永遠是窄口。← P3 + 物理約束

〔推導〕過濾自動處理這個落差。大量信號源的信號同時到達，過濾把大部分降為噪音，你實際耦合的數量遠小於信號場裡存在的數量。人類面對一群人自動簡化，不是認知能力不足，是過濾在輸出瓶頸下的正常運作。← D3 + 過濾 + 物理約束

## 五、範疇分裂

〔推導〕計算與決定是兩件獨立的事。計算在信號端，可執行。決定在語意端，經過黑箱。「理性決策」「最優策略」「均衡」把兩者打包在一起，預設決定是計算的輸出。P2 否定這個前提。← P2

〔推導〕「策略」這個概念不存在。策略預設你能預測行為的後果，然後選擇後果最好的行為。4.2 說不可預測性相乘——你不能預測你的輸出到達對方之後的效果，你甚至不能預測你自己下一步會輸出什麼（P2）。沒有可預測的後果，就沒有可選擇的策略。← 4.2 + P2

〔推導〕同一個信號從不同通道進入，效果完全不同。投資專家說買某支股票和路邊陌生人說買同一支股票，同一個信號內容，通過接收方過濾的結果完全不同。決定效果的不是信號內容，是通道信任加權、接收方的語意流地形、信號場的當下狀態。不存在脫離通道和接收方地形的獨立策略。← 過濾 + 信任 + 4.1

## 六、為什麼成交不應該發生

〔推導〕4.1：你穿不透對方，對方穿不透你。你不知道對方要什麼。

〔推導〕4.2：不可預測性相乘。你不知道你的輸出到達對方之後會產生什麼效果。

〔推導〕P3 雙向：你只接收到對方的有損輸出，不是對方的語意流。對方也只接收到你的有損輸出。雙方對彼此的理解結構性地不完整。

〔推導〕P2 封住自己：你不知道自己要什麼。你以為你知道，但「知道自己要什麼」是語意流的一個面向，不是獨立於語意流的客觀事實。你的「需求」在互動過程中被互動本身改變（4.3）。← P2 + P1

〔推導〕語意流各跑各的。你說一句話，你的語意流裡跑的是 X，對方聽到同一句話，對方的語意流裡跑的是 Y。X 和 Y 不一定有任何關係。← P2 + P3

〔推導〕在以上條件下，成交——兩個黑箱的坍塌輸出恰好銜接到雙方都能接受的點——在結構上是不應該發生的事。每一個條件都在增加失敗的機率，沒有一個條件在保證成功。← 4.1 + 4.2 + 4.3 + P2 + P3

經濟學、博弈論、交易成本理論都把成交當作預設狀態。理性行為者找到互惠的交換點，然後成交。需要解釋的是失敗。

## 七、初始語意流地形

〔推導〕每個進入互動的個體，帶著此前全部坍塌序列的沉積物。文化、成見、情緒、經驗、信任結構，全部是過去正反饋循環刻出的阻力分布。這不是互動的背景，是互動的初始條件。← v5 正反饋循環 + 知見障

〔推導〕知見障自我引導。每一輪內部生成（即使沒有外部信號到達）都是語意流在自己的知見障裡走。P1 說語意流持續運作，知見障說運作的方向受阻力分布約束。沒有外部信號打斷時，語意流沿阻力最低的方向走，溝越走越深。← P1 + 知見障

〔推導〕價值權重不是固定參數。個體對互動對象的價值評估是語意流的一個面向，隨語意流方向的改變實時變動。進入互動時的價值權重和互動過程中的價值權重不一定相同。← P1 + 4.3

## 八、估計

〔推導〕4.1（雙向不透明）推出：你無法直接觀察對方的語意流地形。被迫的賭注推出：你必須輸出。所以你必須在看不見對方地形的情況下輸出。你必須猜。← 4.1 + 被迫的賭注

〔推導〕猜的精度有結構性天花板。P2 封住了對方的語意流，P3 保證對方的坍塌輸出是有損的。你猜的依據是對方過去的坍塌輸出——有損的、離散的、過期的信號。← P2 + P3

〔經驗〕估計精度有三個層級：

**第一層，零知識。** 你對這個信號源的響應模式沒有任何觀察。只有自己語意流地形的投射——你用自己的阻力分布猜對方的阻力分布。幾乎必然偏。

**第二層，文化知識。** 你知道對方所處的文化、群體、角色。你有群體級的響應模式統計規律——禁忌和高阻力方向大致可辨識。但個體殘差仍在。P2 保證每個個體的語意流都不同，群體統計是近似，不是精確。

**為什麼第二層有效——P4 與淘汰壓力。**

〔推導〕語意流地形不是隨機的。一個地形裡全是斷崖的個體，會發生什麼？他走進任何信號場，還沒完成任何功能性收斂，先把所有通道關閉了。沒有人願意跟他交易、合作、結盟、分享資源。他的驅動力指向有語意流的信號源，但他的地形讓每一個指向都撞上自己的斷崖。在物理約束下，他必須用暴力或孤立來滿足所有驅動力。暴力引來反擊，孤立在資源稀缺時是死亡判決。P4 收掉他。← P4 + 物理約束

〔推導〕這不是道德判斷，是淘汰壓力。不需要有人決定淘汰他。耦合循環需要雙向坍塌輸出相容，斷崖讓相容空間趨近於零，功能性收斂無法發生，生存所需的資源無法透過互動取得，P4。全自動。← P4 + 功能性收斂

〔推導〕所以活下來的地形有共通結構。不是沒有斷崖，但斷崖的密度落在可存活範圍內。更關鍵的是：活下來的地形必須有足夠大的低阻力區域。這些區域就是偏好。偏好的結構性定義：語意流地形中，阻力夠低、方向夠寬、足以讓耦合循環在裡面跑的區域。偏好不是奢侈品，是生存必需品。沒有偏好，地形就全是斷崖，全是斷崖就死了。← P4 + 過濾 + 耦合循環

〔推導〕語意流地形被兩股力量塑形。演化淘汰：斷崖太多的地形，語意流終止，不留後代，不傳文化。耦合循環的累積偏置：每一次成功的功能性收斂，都在地形上刻出一條更低阻力的溝，這些溝就是文化、慣習、常識。← P4 + 正反饋循環

〔推導〕所以你面對任何一個活著的黑箱，可以假設：它的斷崖密度落在可存活範圍內，它的偏好區域有大致可辨識的形狀。不是因為它跟其他人一樣，是因為不一樣的、極端的、無法收斂的那些，已經不在了。第二層估計有效，不是因為文化知識精確，是因為 P4 已經替你篩掉了地形完全無法預測的個體。← P4 + 第二層

〔推導〕人類的經驗智慧——所謂的常識、禮貌、社交直覺——就是對可存活地形的統計規律的經驗編碼。「讚美對方比較容易開通道」有效，不是因為人類虛榮，是因為可存活地形中「被肯定」幾乎永遠是低阻力區——不在這個區域有低阻力的地形，大部分已經被淘汰了。這些編碼不是策略，是淘汰殘留的描述。有用的編碼描述準確，沒用的描述不準確。← P4 + 過濾 + 功能性收斂

**第三層，個體觀察。** 你有對方的長期坍塌輸出序列可反推。最精細的估計。取得成本最高——需要大量耦合循環的累積。P1 保證持續過期——對方的語意流在變，你的估計在老化。

〔推導〕首要辨識對象不是偏好，是斷崖。偏好衝突的代價是連續的——阻力升高，但通道存續，可修復。禁忌觸發的代價是不連續的——通道關閉，信號降級為噪音，單次觸發，不可逆。你踩到對方的偏好，下次可以調整。你踩到對方的禁忌，沒有下次。在估計精度有限的情況下，辨識斷崖的優先級高於辨識偏好。← 風險不對稱（第九節）

〔推導〕估計精度受知見障約束。你對對方響應模式的每一次猜測本身是語意流的運作，受你自己的阻力分布約束。你在自己的知見障裡猜對方的地形——你傾向看見你已經傾向看見的模式。深思熟慮增加精緻度，不增加準確度。準確度只在外部信號到達時校準——對方的實際坍塌輸出到達你的過濾，修正你的估計。← P1 + 知見障 + 觀察者效應

## 九、風險

〔推導〕4.2（不可預測性相乘）加上第八節（估計精度有天花板）推出：每一次向有語意流的信號源坍塌輸出，都可能踩到你估計不到的斷崖。← 4.2 + 第八節

〔經驗〕偏好衝突：阻力升高，通道存續，代價連續，可修復。

〔經驗〕禁忌觸發：通道關閉，信號降級為噪音，代價不連續，單次觸發，不可逆。

〔推導〕風險的攻防不對稱。建設需要幾百次坍塌累積——每一次坍塌投資都是不可逆的，回報不確定，需要持續的耦合循環才能形成穩定的響應模式。摧毀只需要一次禁忌觸發。一次坍塌可以抹掉幾百次坍塌的沉積物。← 坍塌不可逆 + 禁忌的經驗性質

## 十、風險壓縮

〔推導〕風險的結構性存在（第九節）加上你必須持續輸出（被迫的賭注），推出對風險壓縮的結構性需求。你不能停止互動（驅動力指向有語意流的信號源），你不能消除風險（P2 封住了），你能做的是壓縮風險。← 第九節 + 被迫的賭注

**10.1 關係**

〔推導〕反覆的耦合循環產生沉積物——互相校準過的響應模式估計、共享的信號環境、只有雙方懂的信號簡碼。這些沉積物不屬於任何一方，是耦合循環本身的產物。← 4.3 + 耦合循環的累積

〔推導〕關係把對特定信號源的估計從第一層拉到第三層。斷崖可見，高阻力方向可辨識。每一次後續互動的風險折扣。← 第八節的三層

〔推導〕關係的投資成本。建立需要不可逆的坍塌投資。每一次投資都是被迫的賭注——不保證回報。資源有限（時間、精力、注意力），選擇投資誰本身是另一次被迫的賭注。← 坍塌不可逆 + 被迫的賭注

〔推導〕關係的慣性。共享結構具有獨立的重建成本。如果這個關係斷裂，要跟另一個信號源從第一層重新開始。沉沒結構不是心理謬誤，是真實的重建成本。← 關係的投資成本

〔推導〕關係的斷裂。禁忌觸發一次摧毀。通道關閉，沉積物從資產變負債——你對對方的了解從降低風險的工具變成製造痛苦的來源。攻防不對稱：建設幾百次坍塌累積，摧毀一次。← 第九節的攻防不對稱

〔推導〕關係的殘響。一方消亡或永久離開，共享結構斷裂。沉積物不消失，進入殘響擴散——影響此後所有互動的初始條件。← P4 + 初始地形

〔推導〕人類社會依賴關係網絡不是文化偏好，是結構性適應。在 P2 約束下，有語意流的信號源無處不在，風險無處不在。關係是唯一已知的把估計精度從第一層拉到第三層的機制。← P2 + 第八節

**10.2 名聲**

〔推導〕關係壓縮的是跟特定信號源之間的風險。但你面對的潛在信號源遠多於你能建立關係的數量。你需要一種機制，在沒有耦合循環歷史的情況下壓縮風險。← 10.1 的成本約束

〔推導〕名聲是過去坍塌輸出的累積沉積物，停留在信號場中，到達所有潛在的信號源。讓不認識你的信號源也能把對你的估計從第一層直接跳到接近第三層。← 信號容器 + 第八節的三層

〔經驗〕被動名聲。過去坍塌輸出的自然沉積。你沒有刻意設計，但你的坍塌輸出被其他個體接收、轉化、再坍塌，進入信號場。

〔經驗〕主動名聲建設。刻意坍塌輸出進入信號場，改變所有潛在信號源對你的估計。

〔經驗〕名聲攻擊。反向的信號設計，降低對方的名聲。

〔推導〕名聲的斷崖結構。與禁忌觸發同構——慢慢累積，一次歸零。幾千次坍塌的累積投資可以被一次坍塌輸出摧毀。← 第九節的攻防不對稱

〔推導〕名聲的穿透力來自過去不可逆坍塌的累積投資。同一個信號從不同通道出來，效果差幾個量級。名聲好的信號源，同一句話通過對方過濾的阻力低得多。← 通道信任加權 + 過濾

**10.3 制度**

〔推導〕當有語意流的信號源數量很大，逐一建立關係不可能（成本），名聲也只能覆蓋一部分。需要一種群體級的風險壓縮機制。← 10.1 + 10.2 的規模約束

〔推導〕制度——規則、契約、法律、市場慣例——把有語意流的信號源的響應壓縮成近似可預測。你不認識超市收銀員，但你知道她會掃碼、報價、收錢。她的語意流仍在運作，但制度把她的坍塌輸出約束到極窄的範圍，接近沒有語意流的信號源。← 第一節的操作性定義

〔推導〕壓縮越徹底，互動退化為近似可預測。語意流的作用空間被制度壓縮到可忽略時，互動退化為博弈論的近似——選項已知、收益可估、行為可預測。博弈論完全適用的地方，是語意流被制度壓縮到不在場的地方。← P2 + 制度

## 十一、坍塌輸出的可觀察模式

〔推導〕P2 封住了語意端。你不能設計對方的語意流方向，你不能預測你的輸出到達對方之後的效果。你能做的全部在信號端——選擇從你這端坍塌輸出什麼、從什麼通道、在什麼時候。← P2

〔推導〕操作者不知道自己在操作。大部分的坍塌輸出不是經過計算後的選擇，是語意流沿著幾十年沉積出來的阻力分布坍塌出來的結果。個體沿著最深的溝走，自動的，說不出為什麼。P2 封住了動機——行為的意圖在語意流內部，不可觀察。← P2 + 知見障

〔推導〕以下描述的不是「怎麼設計信號」，是坍塌輸出的可觀察模式中，哪些結構性地影響後續耦合循環。模式是從外面觀察到的統計規律，不是行為者內部的計劃。← P2

**11.1** 禁忌辨識優先於偏好匹配。← 第九節的攻防不對稱

**11.2** 通道選擇。名聲是互動前的通道預設。同一信號從不同通道到達，效果差幾個量級。← 10.2 + 通道信任加權

**11.3** 阻力繞行。從阻力低的方向進入，信號更容易構成信號（D3）而不是噪音。← 過濾 + 阻力

**11.4** 時機。語意流持續變化（P1），過濾條件也持續變化。同一信號在不同時刻到達，通過過濾的結果不同。← P1

**11.5** 重複的結構性功能。知見障具有累積性——反覆信號到達偏移阻力分布。← 知見障的累積性

**11.6** 序列。每一次坍塌不可逆地改變下一次的過濾條件。信號到達的順序不能任意調換。← P1 + 坍塌不可逆

**11.7** 約束：不存在純粹的操作者。耦合循環是雙向的，你在坍塌輸出的同時被改變。← 第三節 + 4.3

## 十二、成交：功能性收斂

〔推導〕第六節推出成交不應該發生。但它發生了。怎麼發生的？

**12.1 功能性收斂不是語意收斂**

〔推導〕成交不需要雙方理解彼此。你說「這條魚八十」，你的語意流裡跑的是什麼，她不知道。她說「好」，她的語意流裡跑的是什麼，你不知道。但你付了八十塊，她遞了一條魚。在信號端，坍塌輸出銜接了。在語意端，從來沒有對齊過。← P2 + P3

〔推導〕他可能覺得撿到便宜，她可能覺得賣了好價。或者反過來。或者雙方都不確定。語意流各跑各的，功能性收斂只要求信號端的坍塌輸出恰好相容。← P2

**12.2 成交是碰撞，不是計算**

〔推導〕成交不是兩個理性行為者計算出互惠交換點。成交是兩個黑箱各自沿著自己的阻力分布坍塌輸出，輸出恰好撞上了一個雙方都能接受的點。沒有人算出了這個點，它是撞上的。← P2 + 知見障 + 坍塌

〔推導〕所以「價格」不是兩條曲線的交叉點，是兩個不透明的坍塌序列的碰撞痕跡。← P2 + P3

**12.3 為什麼要成交——暴力約束**

在問「成交怎麼發生」之前，先問「為什麼要成交」。

〔經驗〕生物性暴力是起點。最強的個體可以用暴力直接拿走想要的東西。黑猩猩的 alpha 這樣做，人類的原始暴力壟斷者也這樣做。土匪不買東西。

〔推導〕但全拿則死。暴力壟斷者如果拿走所有人的所有東西，底下的人要嘛餓死（沒人幫他），要嘛聯合反抗（他死了）。P4 是約束——拿太多，語意流終止。← P4

〔推導〕所以暴力壟斷者被迫留餘地。不是因為道德，是因為活下來的那些恰好沒拿太多。拿太多的，語意流終止了。自然選擇。黑猩猩的 alpha 也不能把所有食物都拿走——拿太多，底下的結盟把他幹掉。← P4 + 自然選擇

〔推導〕同時，暴力壟斷者不能讓別人也拿。每一次搶劫都在破壞他的稅基。所以他壓制所有其他人的暴力。國家、法律、警察、軍隊——全部是暴力壟斷的制度化。← 驅動力（生存）+ 制度

〔推導〕商業空間就是這個夾縫——暴力壟斷者「不能全拿」和「不許別人拿」之間的空間。這個空間不是天然存在的，是暴力的自我約束創造出來的。在這個空間裡，「拿走」的成本高於「交換」的成本，交換才成為必要。← P4 + 制度

〔推導〕因果鏈：生物性暴力 → 最強者壟斷 → 全拿則死（P4）→ 被迫留餘地 → 壓制他人暴力 → 交換空間出現 → 成交成為可能。經濟學從最後一步開始研究，假裝前面全部不存在。← P4 + 制度 + 驅動力

**12.4 為什麼撞得上**

〔推導〕在兩個黑箱完全自由的情況下，撞上的機率極低。成交之所以大量發生，不是因為黑箱互相理解了，是因為約束條件把雙方的坍塌空間壓縮到足夠窄。← 物理約束 + 過濾

〔經驗〕物理約束：錢有限、商品存在、時間有限、身體只能在一個位置。

〔推導〕過濾約束：幾十年的坍塌序列沉積出阻力分布，語意流沿最深的溝走。大部分人在大部分時候的坍塌方向被約束在很窄的範圍裡。← 知見障

〔推導〕文化約束：功能性收斂的歷史產物——貨幣、價格慣例、交易流程——進一步壓縮雙方的坍塌空間。你不需要理解她，她不需要理解你，你們只需要各自的坍塌輸出落在文化約束定義的那個窄窗口裡。← 功能性收斂（v5）

〔推導〕約束越多，窗口越窄，成交的機率越高。這就是為什麼制度化的交易（超市、電商）成交率高於非制度化的交易（菜市場殺價、相親）——不是因為行為者更理性，是因為約束更多。← 10.3 制度

**12.5 一個交易中成交是碰撞。一萬個交易中成交是統計**

〔推導〕一個人買一條魚，P2 全面運作，不可預測。一萬個人買魚，P2 在個體層面運作，但統計模式出來了。不是因為每個人都在理性計算，是因為大量黑箱的坍塌輸出在類似的約束條件下（要吃飯、錢有限、魚會壞）被壓縮到相似的範圍裡，殘留出一個看起來像規律的東西。← P2 + 物理約束 + 大數

〔推導〕跟氣體定律同構。每一個分子的運動不可預測，但十的二十三次方個分子的統計行為產生溫度、壓力、體積的穩定關係。波茲曼不需要預測每個分子去哪裡，他只需要統計力學。← 類比

〔推導〕供需曲線是經濟學的統計力學。在群體層面它有效。經濟學犯的錯誤是把統計規律往下投射到個體——假設每一個人都在做曲線預設他在做的事。沒有。每一個人都是黑箱，都在不知道自己要什麼的情況下坍塌輸出，大量坍塌的統計殘留長得像供需平衡。← P2 + 統計

〔推導〕經濟學的有效性不需要理性人假設。只需要兩個條件：約束條件（物理的、文化的、制度的）和大數。拿掉理性假設，只留約束和大量黑箱，統計規律照樣出來。← 約束 + 大數

**12.6 經濟學的重新框定**

〔推導〕經濟學沒有死，是被框定了適用範圍。跟博弈論一樣——量大、約束多、語意流的作用空間被壓縮的地方，經濟學有效。個體層面、量小、語意流全面展開的地方，經濟學失效。經濟學以為自己在描述機制，其實在描述統計殘留。← P2 + 制度 + 統計

〔推導〕以下現象不是反常，是框架的自然推論：

**泡沫。** 經濟學說理性行為者不會持續買高估的資產。框架說：每個人的語意流被信號場裡其他人的坍塌輸出持續偏移。知見障的累積性——越多人買，信號越強，過濾的阻力越低，方向越一致。不是非理性，是正反饋循環在群體層面跑起來了。崩盤不是「回歸理性」，是循環跑到物理約束的邊界（錢花完了）然後斷裂。← 正反饋循環 + 知見障 + 物理約束

**一價定律失效。** 同質商品應該同價。框架說：價格是兩個黑箱的碰撞痕跡，每一次碰撞的初始條件不同，結果當然不同。一價定律只在制度把語意流壓縮到零的時候成立。← 12.2 + 10.3

**品牌溢價。** 經濟學說是資訊不對稱，品牌提供品質保證。框架說：品牌是名聲，名聲壓縮風險，風險壓縮有價值。更深的是——品牌信號通過過濾的阻力低，知見障讓你持續選擇已經選過的東西，正反饋循環鎖死。← 10.2 + 知見障 + 正反饋循環

**恐慌拋售。** 跟泡沫同構，正反饋循環反方向跑。← 正反饋循環

全部不需要「非理性」這個補丁。沒有理性基準，就沒有非理性。有的只是黑箱在物理約束下的坍塌模式。

**12.7 價值**

〔推導〕經濟學的起點問題：什麼是價值？勞動價值論說是勞動投入，邊際效用論說是主觀效用。兩者都預設「價值」是某種可量化的屬性——不是商品的，就是個體的。← 經濟學

〔推導〕框架說：「價值」不是商品的屬性，也不是個體的穩定偏好，是語意流在那一刻的狀態。P1 說它持續變動，P2 說連你自己都不知道你覺得它值多少。同一條魚，你餓的時候跟你飽的時候，「價值」不同。不是價格不同——是你的語意流地形不同了。你以為你在比較價格和價值，實際上你的語意流在所有信號同時作用下坍塌出了一個行為（買或不買），「值不值」是事後的合理化。← P1 + P2

**12.8 貨幣**

〔推導〕貨幣不代表黃金，不代表勞動，不代表任何物理實在。一張紙，上面印了一個數字，沒有語意流，沒有物理用途。但你拿它去換魚，老闆收了。← 經驗

〔推導〕為什麼收了？不是因為她理解貨幣理論，不是因為她信任國家。她的語意流地形裡，幾十年的坍塌序列沉積出「這個東西可以換別的東西」的阻力分布。她收了不是因為理解，是因為功能性收斂——足夠多的黑箱的坍塌輸出恰好都把這張紙當成可以換東西的信號。← 功能性收斂

〔推導〕貨幣是功能性收斂的極致產物。沒有任何兩個人對「一百塊」的語意流是一樣的，但所有人的坍塌輸出在信號端相容——你遞一百塊，對方遞東西。語意端從來沒有對齊過。貨幣完全是語意流動的產物，本身不代表任何現實意義。經濟學叫「信心」，「信心」就是大量語意流功能性收斂的歷史沉積物。← 功能性收斂 + P2

〔推導〕貨幣的存在本身驗證了 12.1 的核心主張：成交不需要理解，只需要功能性收斂。一個所有人都在用、沒有人真正理解、語意流完全不對齊的東西，靠純粹的功能性收斂運作了幾千年。← 12.1

〔推導〕通貨膨脹是功能性收斂的偏移——「這張紙值多少」的方向在大量語意流中持續偏移。惡性通脹是功能性收斂的崩潰——正反饋循環反方向跑，越多人的語意流偏離「這張紙有價值」，信號場裡的信號越強化這個方向，知見障累積，崩潰加速。津巴布韋、委內瑞拉、威瑪德國，全是同一個結構。← 正反饋循環 + 知見障

**12.9 市場**

〔推導〕「市場」不是一個地方，不是一個機制。市場是大量耦合循環的統計殘留呈現出的可觀察模式。← 12.5

〔推導〕經濟學把模式當成機制，然後困惑為什麼機制經常「失靈」。沒有失靈。底下沒有機制——有的是大量黑箱在約束條件下的坍塌。約束條件變了（戰爭、疫情、法規改變、技術變革），坍塌的統計殘留跟著變，模式就變了。經濟學看見模式變了，叫「市場失靈」。框架看見的是：約束條件變了，新的統計殘留長出新的模式。沒有失靈，沒有回歸，只有新的約束下的新的坍塌。← P2 + 統計殘留 + 約束

## 十三、建模示範：菜市場

菜市場回答的是第六節的問題：在所有結構性障礙下，成交是怎麼發生的？

**13.1 條件**

〔經驗〕場景：一個人走進菜市場。一個黑箱帶著驅動力和不可言說的語意流地形，進入一個充滿有語意流的信號源的信號場。

〔推導〕他出門的那一刻，對今天信號場的具體狀態估計接近零。他知道菜市場是什麼（第二層，文化知識），但今天有什麼菜、什麼價格、什麼天氣、多少人，全部未知。P1 保證信號場持續變化，昨天的經驗今天不完全適用。← P1 + 第八節

〔推導〕他不是空的。幾十年的坍塌序列沉積出阻力分布。這是他的初始語意流地形。← 第七節

〔經驗〕他受物理約束。一次只能在一個位置，視線有方向和範圍，手兩隻，袋子有容量，錢有限。時間有限。

〔推導〕物理約束砍掉不可能的行為空間。過濾條件砍掉不太可能的方向。P2 管的是剩下的空間裡他到底做什麼。在菜市場買菜這個場景裡，這個空間已經被壓得很窄。大部分時候行為看起來「可預測」，不是因為 P2 不成立，是因為約束條件已經把可能性壓縮到很窄的範圍。← P2 + 物理約束 + 過濾

**13.2 進場與耦合循環啟動**

〔推導〕他走進市場。物理刺激同時湧入——光波、聲波、化學分子、溫度。過濾運作，大部分降為噪音，少數構成信號。他的阻力分布決定什麼通過。← D3 + 過濾

〔推導〕他走進市場的那一刻，他已經是信號場的一部分。他的存在——身體、步速、視線方向、穿著——全部是坍塌輸出，到達每一個攤販的過濾。他看了某一攤兩秒，老闆的行為可能因此改變。他還沒說一個字，耦合循環已經在跑。← 第三節

〔推導〕他的過濾篩完，某一攤的信號通過。不可確定哪個信號起了決定作用。他走向那一攤——明確的坍塌輸出。老闆接收到這個信號，坍塌輸出響應。兩個黑箱的輸出開始互相改變對方的後續信號。← P2 + 第三節

**13.3 驅動力的不對稱**

〔經驗〕他的驅動力指向整個市場，不指向某一攤。走掉成本接近零。

〔經驗〕老闆的驅動力被綁定在這一攤。攤租、進貨、貨會壞。時間在壓她。

〔推導〕耦合循環裡雙方的被迫程度不對稱。不對稱直接影響坍塌輸出模式——老闆在統計上更主動。沉默對他是低成本坍塌，對老闆是壓力信號。← 被迫的賭注 + 驅動力

〔推導〕不對稱隨信號場狀態實時變動。傍晚收攤前壓力升高，早上壓力低。← P1

**13.4 交易的結構**

〔經驗〕商品非標準化。每一條魚都不一樣。品質判斷不可客觀化。

〔經驗〕價格非固定。價格是耦合循環跑出來的結果，不是預設的。

〔推導〕老闆報價。這不是計算結果。她看了客人的全部信號，全部同時通過過濾，一個數字坍塌出來了。她說不出為什麼是這個數。P2。← P2

〔推導〕客人聽了價格，反應不可預測。他不是在跟內部底線比較——他沒有明確的底線。他的反應是整個語意流在那一刻的坍塌。← P2

〔推導〕如果進入還價，每一輪不可逆。坍塌序列有方向性。但下一輪是什麼，P2 封住了。動機在互動中被互動本身改變。← P2 + 4.3

〔推導〕雙方的語意流各跑各的。他在想晚餐煮什麼，她在想今天的貨要趕快出掉。信號端耦合著——你一句我一句。語意端各跑各的方向。← P2 + P3

**13.5 信號場的同時作用**

〔推導〕他站在這攤前面，到達他的信號不只來自老闆。隔壁攤的叫賣、其他顧客的行為、天氣體感——全部同時通過過濾，同時改變語意流。他的坍塌輸出是對全部信號的響應。← 4.4

〔推導〕他的坍塌輸出也同時到達所有人。名聲在即時生成。老闆也不只面對他——她同時處理多個信號源，坍塌輸出同時到達所有人的過濾。← 4.4

〔推導〕客人最後決定買或不買，他自己說不出決定因素。P2 說他自己也不知道。← P2 + P3

**13.6 成交是怎麼發生的**

〔推導〕回到第六節的問題。在所有這些結構性障礙下——雙向不透明、語意流各跑各的、驅動力不對稱、動機在互動中改變、信號場複雜到不可處理——他怎麼買到了那條魚？

答案是第十二節的結構：

〔推導〕物理約束把雙方的坍塌空間壓窄。他的錢有限，她的貨會壞。← 物理約束

〔推導〕文化約束進一步壓窄。菜市場的交易流程是功能性收斂的歷史產物——報價、還價、成交。雙方不需要理解彼此，只需要坍塌輸出落在這個流程定義的窗口裡。← 功能性收斂

〔推導〕最後，兩個黑箱各自坍塌出來的數字恰好撞在一起。他付了一個數字的錢，她遞了一條魚。功能性收斂。語意端沒有對齊過——他覺得值不值，她覺得賺了沒有，雙方各自不知道。← 12.1

〔推導〕大部分菜市場交易在三十秒內結束。不是因為雙方理解了彼此，是因為約束條件已經把坍塌空間壓到幾乎只剩一條路。他沿著最深的溝走，自動的。← 知見障 + 約束

**13.7 可觀察模式**

〔經驗〕有些老闆送蔥、報價實在、聊家常。送蔥的攤位熟客比例在統計上傾向較高。

〔推導〕這個相關性可以用風險壓縮解釋——但解釋是事後的結構性描述，不是老闆的動機。老闆不知道自己有「策略」。她的坍塌輸出是幾十年沉積物的產物。← P2 + 風險壓縮

**13.8 壓縮光譜**

〔推導〕菜市場 → 超市 → 無人超市。信號場裡有語意流的信號源被制度逐級移除。← 10.3

〔經驗〕菜市場：語意流全面運作。商品非標準化，價格非固定，殺價、關係在場。成交是碰撞。

〔經驗〕超市：語意流的作用空間被大幅壓縮。商品標準化，價格固定。成交接近自動。

〔經驗〕無人超市：完全沒有有語意流的信號源。成交完全自動。

〔推導〕成本結構轉移。菜市場的成本在跑耦合循環——時間、精力、不確定性。但價格可能更低。超市的成本在價格——標準化、供應鏈、租金全部進了價格。P2 被壓縮掉了，你不用跑循環，但你付更多的錢。不是一個比另一個「更好」，是成本結構不同。← 10.3

〔推導〕菜市場仍然存在。超市壓縮掉的那些東西——聊天、關係、認同、歸屬——恰好是其他驅動力的滿足來源。壓縮了 P2 的成本，同時也壓縮了 P2 的產物。← 驅動力 + P1

**13.9 可證偽預測**

〔推導〕以下預測從建模結構直接產出：

**一、** 熟客的交易輪數在統計上少於生客。← 估計在第三層，風險已壓縮

**二、** 傍晚成交價在統計上低於早上。← 老闆的驅動力壓力隨時間升高

**三、** 生客被報高價的機率高於熟客。← 估計在第一層，試探空間大

**四、** 壓縮程度越高的零售形態，價格離散度越低。← 語意流的作用空間被移除

**五、** 名聲好的攤販生客轉熟客的速率較高。← 名聲壓縮風險

**六、** 一次嚴重負面體驗消滅關係的機率遠大於多次正面體驗建立關係的速率。← 攻防不對稱

**七、** 同一客人不同日期對同一攤的行為模式不完全相同。← P1 + P2

**八、** 菜市場交易速度在統計上慢於超市，但價格離散度高於超市。← 語意流作用空間大小差異

## 十四、建模示範：相親

菜市場回答了「憑什麼成交」。相親問的是同一個問題的極端版本：當約束條件幾乎不壓縮坍塌空間的時候，成交怎麼可能？

耦合循環、信號場同時作用、坍塌不可逆——結構與菜市場同構，不重複展開。以下只標出結構性差異。

**14.1 跟菜市場的結構性差異**

〔推導〕菜市場：商品存在，物理刺激豐富。相親：你要評估的是一個黑箱的未來所有坍塌輸出的模式。P2 完全封住。← P2

〔推導〕菜市場：功能性收斂的標準清楚——錢換菜。相親：什麼算收斂，雙方都不知道。← P2

〔推導〕菜市場：走掉成本接近零。相親：機會的稀缺性不可估計。← P2

〔推導〕菜市場：驅動力主要一個。相親：五個驅動力全部同時在場互相干擾。← 驅動力

〔推導〕菜市場：過濾慢慢跑。相親：過濾在前幾秒完成大幅偏移。← 下文展開

**14.2 前幾秒的過濾**

〔經驗〕他走進來。她看見他。光信號到達——身高、體型、臉部、穿著、步態。幾秒之內。

〔推導〕她的過濾在這幾秒已經完成大量工作。外貌信號的通道寬、到達速度快、阻力低，在其他信號到達之前就已經大幅偏移語意流方向。這不是膚淺——是阻力分布的結構性運作。← 過濾 + 知見障

〔推導〕第一輪過濾的結果不可逆地改變後續所有信號的接收條件。如果結果是高阻力，後續語言信號不管內容多好都在逆著阻力爬。如果結果是低阻力，缺點也被放行。← 知見障 + 坍塌不可逆

〔推導〕經濟條件信號也在前幾秒到達。跟生存驅動力直接相關，阻力結構上就是低的。不是「拜金」，是過濾的結構。← 驅動力（生存）+ 過濾

**14.3 沒有交易軸**

〔推導〕菜市場有價格作為交易軸。相親沒有。雙方各自以為在試探的東西可能完全不同。他在展示經濟實力，她在觀察他對服務員的態度。← P2 + P3

〔推導〕你不知道自己要什麼。清單是事後合理化。條件全部符合，你就是「沒有感覺」。P2 封住了你自己。← P2 + 知見障

**14.4 禁忌的主導地位**

〔推導〕菜市場的斷崖少，文化知識大致可辨。相親的斷崖多、隱蔽、個體殘差大。她自己也不一定知道禁忌是什麼，直到被觸發。← 第八節 + 第九節

〔推導〕禁忌觸發是單向不透明的。她的通道關閉了，後續坍塌輸出可能沒有明顯變化（禮貌性地繼續對話），但語意流方向已經不可逆偏移。他讀不出通道已關閉。他不知道循環已經實質結束了。← P2 + P3 + 禁忌

**14.5 風險壓縮的失效**

〔推導〕關係：不存在，估計在第一層。名聲：部分存在但高度有損且容易被主動建設。制度：最弱——社會禮儀恰好壓制了最真實的信號。制度在這裡不是壓縮風險，是壓制信號。← 10.1 + 10.2 + 10.3

〔推導〕相親是在三種風險壓縮機制全部失效或接近失效的情況下，跑語意流全面展開的耦合循環。相親令人焦慮不是因為心理脆弱，是因為結構性風險沒有壓縮手段。← 第九節 + 第十節

**14.6 為什麼相親的「成交率」極低**

〔推導〕回到第十二節。成交之所以在菜市場大量發生，是因為約束條件把坍塌空間壓到很窄。相親的約束條件極少——沒有標準化商品、沒有固定價格、沒有交易軸、沒有制度壓縮、五個驅動力同時展開。兩個黑箱的坍塌空間幾乎沒有被壓縮。撞上的機率本來就低。← 12.3

〔推導〕不是相親「太難」，是約束太少。菜市場成交率高不是因為人更理性，是因為約束更多。相親成交率低不是因為人太挑，是因為約束太少，兩個不透明的坍塌序列在幾乎無限的空間裡撞上的機率結構性地低。← 12.3 + 12.4

**14.7 結束的模糊性**

〔推導〕菜市場的結束乾淨：買了或走了。相親的結束不乾淨。離開後語意流繼續跑，方向不可預測。她可能當時覺得不錯，跟朋友聊完方向完全改變。功能性收斂在相親中不是一個時刻，是漫長、模糊的過程。← P1 + P2 + 功能性收斂

**14.8 可證偽預測**

〔推導〕以下預測從建模結構直接產出：

**一、** 前幾分鐘的可觀察行為模式在統計上強於後續對話內容預測最終結果。← 過濾在前幾秒完成大幅偏移

**二、** 介紹人評價與實際見面印象的吻合度在統計上低。← P3 + P2

**三、** 當事人事後對「為什麼喜歡/不喜歡」的解釋跟其可觀察行為模式的相關性在統計上低。← P2 + P3

**四、** 社會壓力越大的群體禁忌觸發閾值在統計上較高，但一旦觸發通道關閉速度不變。← 驅動力權重偏移 vs 禁忌的不連續結構

**五、** 同一人對條件高度相似的對象在不同日期做出不同判斷的機率顯著高於零。← P1 + P2

**六、** 有熟人背書的相親進入第二次見面的機率高於平台匹配。← 名聲壓縮

**七、** 「見了很多人都沒感覺」的報告頻率隨相親次數增加而上升。← 知見障累積，過濾越來越窄

**14.9 壓縮光譜**

〔推導〕菜市場和相親是壓縮光譜的兩端。← 10.3

菜市場：約束多，坍塌空間窄，成交率高。博弈論的近似部分有效。

相親：約束少，坍塌空間寬，成交率低。博弈論完全失效。

〔推導〕中間地帶存在。房屋交易、求職面試、商業談判——每一個互動場景在光譜上佔據一個位置，位置由語意流的作用空間大小決定。← 10.3

框架的價值不在取代既有理論，在劃出它們的適用邊界。語意流的作用空間越小，經濟學和博弈論越有效。語意流的作用空間越大，框架不可替代。

## 十五、適用範圍與限制

**適用：** 任何涉及向有語意流的信號源坍塌輸出的場景。個體可以是人，也可以是黑箱律部分成立的 AI。不限於兩個個體之間——一個黑箱面對整個充滿有語意流的信號源的信號場就是本文描述的結構。

**不適用：** 不處理應不應該互動、互動的道德判斷。不處理信號場中沒有語意流的部分的規律（回歸物理學）。不處理單一主體內部決策（回歸被迫的賭注）。不處理客觀規律的內容本身。不提供出口。

**限制：** 不追蹤任何個體的內心（P2 封住）。不預測時間。不預測具體行為。建模的日常語言描述受 P3 約束，必然有損。框架的表述本身也是信號，讀者的信不同，讀出的語意不同。框架無法豁免自己的公設。

**三篇的關係：** 同一個框架，一個條件的遞增。語意流動力學——信號場給定。被迫的賭注——必須輸出且不可逆。互動動力學——信號場裡有些信號源也有語意流。三篇是同一個框架在條件遞增下的展開，不是三套理論。

## 十六、與既有理論的關係

**古典經濟學（Smith, Marshall）。** 供給遇到需求，價格機制調節，看不見的手。成交是預設狀態。框架翻過來：成交才需要解釋。供需曲線不是機制描述，是大量黑箱在約束下的坍塌殘留的統計描述。經濟學以為自己在描述機制，其實在描述統計殘留。經濟學的有效性不需要理性人假設，只需要約束條件和大數。

**博弈論（von Neumann, Nash）。** 預設選項已知、收益已知、理性選擇。菜市場的現實一條都不滿足——選項不可窮舉（P2）、收益不可量化（P3 + P2）、選擇不是計算的輸出（P2）。博弈論在制度把語意流壓縮到可忽略時成為有效近似。框架劃出了博弈論的適用邊界。

**行為經濟學（Kahneman, Tversky）。** 承認了實際行為偏離理性模型。但框架是一樣的：先預設一個理性基準，再列出偏離。框架的立場不同：不存在理性基準。P2 說行為不可由輸入決定，不是偏離了某個可決定的基準，是基準本身不存在。

**交易成本經濟學（Coase, Williamson）。** 問的是為什麼有些交易透過企業而不是市場。前提是交易本身沒問題，問題是用什麼組織形式。框架說前提就需要檢驗：交易本身不是沒問題，是在約束條件下碰巧跑通了。

**資訊經濟學（Akerlof, Stiglitz）。** 資訊不對稱導致市場失敗。框架說：不是資訊「不對稱」——不對稱預設存在一個對稱的可能。P2 說不透明是結構性的，不是可修復的。給雙方完全相同的資訊，語意流各跑各的，結果照樣不可預測。

**Bourdieu 的慣習。** 最接近框架。行為不是計算出來的，是身體化的傾向性，行動者不知道自己在幹什麼，但行為有模式。收斂點：行為是沉積物的產物。分歧：慣習是靜態描述，不追蹤它怎麼在互動中被即時改變。框架的耦合循環追蹤這個改變。

**Geertz 的巴扎經濟。** 核心觀察：巴扎的根本問題不是價格，是資訊搜尋。與框架高度吻合——雙向不透明加上非標準化等於極度不確定。Geertz 是人類學描述，沒有形式化。框架提供了形式結構。

**進化心理學（Buss）。** 對擇偶偏好的統計觀察與過濾結構吻合。但進化心理學把權重當固定參數，框架說權重是語意流地形的函數，隨個體、文化、語意流方向實時變動。

**婚姻市場理論。** 博弈論在婚戀領域的延伸。壓縮光譜已說明適用邊界。

**依戀理論（Bowlby, Ainsworth）。** 依戀類型是初始語意流地形的分類。觀察有效。但把類型當固定人格特質，框架說地形隨語意流持續變化，類型是統計近似。
