核心信的判準 ≡ {認同構成, 死亡判準}

  從長時段歷史中觀察反覆出現的行為傾向，提取構成此文明區別於其他文明的認同結構

  蓄壓狀態：核心信全面運作，正反饋循環表面穩定
  兩條鋸線同時作用：容器老化（40a22ff8-9d90-4e1e-82f6-1fd80917c139.不穩定性內部來源）∧ 衣服漂移（40a22ff8-9d90-4e1e-82f6-1fd80917c139.不穩定性外部來源）
  動力機制反覆衝擊容器，每次消耗容器資源
  （從論文3.1節推出）

鋸斷 ↝ 斷裂：
  最後一次衝擊成功（因容器已被鋸至極薄）↝ 容器碎裂
  （從論文3.1節推出）

斷裂 ↝ 混戰：
  容器碎裂 → 動力機制全面釋放
  ∧ 再生產機制在基層持續運作
  ↝ 各方爭奪唯一位置，每個競爭者建小中央集權
  （從論文3.1節推出）

混戰 ↝ 英雄：
  從混戰中勝出者執行對齊功能（英雄）
  英雄合法性來自勝利（動力機制）
  （從論文3.1節推出）

英雄 ↝ 重建：
  英雄找到衣服，讓核心信在當下現實中存活
  ↝ 重建核心信要求的結構，再生產機制接入新信號容器
  ↝ 動力機制被壓回沉睡
  （從論文3.1節推出）

重建 ↝ 蓄壓：
  正反饋循環重啟，不穩定性重新開始累積
  ↝ 蓄壓狀態
  （從論文3.1節推出）

循環：蓄壓 → 鋸斷 → 斷裂 → 混戰 → 英雄 → 重建 → 蓄壓
標註：此為核心信存活下的結構性循環，無內建終止條件。退出條件 ≡ 核心信死亡（被替代信取代，或承載信的所有個體被物理消滅）。
