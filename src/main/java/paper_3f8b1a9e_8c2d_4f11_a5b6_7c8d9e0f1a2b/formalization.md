### 生物性

生物性 ≡ 個體是生物體，有持續運作的不可關閉驅動力
  ≡ {暴力, 好奇心, 貪婪}
  暴力：身體慾望無上限，取得排他物的最短路徑是拿了不給
  好奇心：生物硬件（探究反射），不可關閉；方向由主導結構分配，好奇心自身 ¬∃方向
  貪婪：差額導向，天然推向壟斷

  本篇操作性定義：暴力、好奇心、貪婪是生物性在本篇的操作性描述，方便後續推導使用
  （從 生物預設概念引申；生物預設 ≡ f81d4fae 上游的 607cd714.生物預設，定義為個體的三層物理結構）

### 物理條件

物理條件 ≡ {自然條件, 物質資源, 信號容器容量, 神聖性阻力場}
  自然條件：地形 ∧ 氣候 ∧ 礦產
  物質資源：能養活多少人的量級
  信號容器容量：能把協調模式傳遞給多少人（← 40a22ff8.信號容器）
  神聖性阻力場：哪些模板方向阻力高、低、無限大（← 40a22ff8.阻力）

### 可行域

可行域 ≡ 自然條件 ∧ 歷史條件共同定義的集合
  集合內容：什麼制度不可能存在（負向定義）
  可行域 ≠ 預測域：告訴你不可能，不告訴你可行域內長出什麼
  可行域由 物理條件 的自然條件成分 ∧ 歷史路徑共同確定
  歷史路徑為凝固的物理條件（從 2.5 節推導，見「制度的前史」段落）

### 成文層

成文層 ≡ 607cd714.模板的官方形式
  功能：{給模板一個可以被引用的語言, 讓集體不需要直視真實分配結構}
  特有能力：跨越陌生人 ∧ 在時間上傳遞給後代
  （從 607cd714.模板定義 + 40a22ff8.信號容器功能 推出）

### 不成文層

不成文層 ≡ 607cd714.模板的內化形式
  定義條件：成功到所有人都不知道自己在依循一個模板的狀態
  性質：自然資源——不可製造，從物理條件和日常協調裡長出來，只能發現，不能設計
  特有能力：真實協調 ∧ 覆蓋所有規則沒有寫到的情況
  存在條件：物理條件在則在，條件消失則消失；不需要傳遞機構

### 成文與不成文的距離

成文與不成文的距離 ≡ 成文層語言體系與不成文層語言體系的不可互譯程度

距離大小 ≠ 穩定性決定因素
  [論文明確聲明：美國距離小、中國距離大、印度距離無限大，三者都穩定，機制不同；距離大不是問題]

兩層的依賴關係（從 成文層定義 + 不成文層定義 推出）：
  不成文越強 → 越不需要成文（不成文自維持）
  不成文越弱 → 越依賴成文維持（依賴轉移）
  兩層互相需要對方才能持續存在

  環境衝擊 ↝ 可打掉成文層（可能）
  環境衝擊 ↝ 完全消除不成文層（極難——不可說的東西產生的文化差異很難完全消除）

### 制度

  制度的真實存在 ≡ 40a22ff8.功能性收斂（大量個體的輸出信號模式趨近）
  制度消失的判定：功能性收斂瓦解的那一刻，不管規章還在不在

### 認同

  性質：40a22ff8.功能性收斂在個體層的可觀察統計量，不是內在狀態
  ¬∃直接觀察（← 40a22ff8.P2 黑箱律）：只能看行為記錄的統計模式
  不成文層強弱讀取方式：
    認同高 → 不成文層強，安撫成本趨近於零
    認同下降 → 不成文層弱化，安撫成本上升
  認同的改變：從 P2 永遠不可解釋；在統計上與框架已有條件正相關（物理條件改變、成文/不成文距離擴大、安撫成本失效）
  （從 40a22ff8.功能性收斂 + 40a22ff8.P2 推出）

### 有效知識域

有效知識域 ≡ 主導結構定義的「什麼輸出算作知識」的集合
  好奇心方向由主導結構分配（← 生物性的好奇心成分）；主導結構同時定義有效知識域
  域外信號：不被拒絕，是根本不被識別為知識

有效知識域包含兩種已知結構（開放分類，不排除其他結構）：

加法結構 ≡ 有效知識域邊界固定、知識在域內累積的結構
  每一代加在上一代上面，邊界不改變

指數型結構 ≡ 知識生產改變域邊界的結構
  每個答案製造新問題，邊界持續往外擴張
  自我增強正反饋：知識生產知識（不是兩個變數相乘，是指數型，無上限）
  [指數型結構是相變條件，不是知識量問題]

### 終態

終態 ≡ 崩潰後多模板系統的結構性終點（開放分類，已知三個子類型）
  終態 = 轉型 ∨ 無政府 ∨ 滅亡

轉型 ≡ 可行域夠大 ∧ 候補模板存在 → 國家尺度制度重啟

無政府 ≡ 可行域夠大 ∧ 候補模板不存在 → 制度退縮到熟人社會尺度穩定下來
  性質：不是混亂，是規模退縮後的穩定
  熟人社會尺度的功能性收斂由 生物性（本篇概念） 直接驅動，不需要神聖性或成文層，永遠能夠存在
  無政府可以是永久終態，不是過渡狀態

滅亡 ≡ 可行域歸零

前提條件的邏輯覆蓋（從 6.1 三個必要條件推出，見「制度的重啟」段落）：
  可行域夠大 ∧ 候補模板存在 ⇒ 轉型
  可行域夠大 ∧ ¬候補模板存在 ⇒ 無政府
  ¬可行域夠大 ⇒ 滅亡
  （¬可行域夠大時，候補模板是否存在不影響終態，因為可行域歸零優先）

## 二、制度的前史

來源：論文第二節

本節推導以 生物性 和 40a22ff8.流變律–死亡律 為前提，建立制度的歷史必然性，並引入承重結構。

### 功能性收斂是定理（Section 2.2 推導）

前置條件：
  外部威脅對單一個體的威脅量級 ≫ 個體抵抗能力（論文給定）
  群體是個體生存的前提條件，在任何制度設計之前就已經是必要條件

推導（從 40a22ff8.流變律 + 黑箱律 + 損耗律 + 死亡律 + 群體存在 推出）：
  群體存在 → 大量個體的輸出信號模式必然趨近
  = 40a22ff8.功能性收斂（群體動力學的必然輸出，不需要任何人設計或強制）
  功能性收斂的最初形態就是制度
  ⇒ 制度不是被發明的，是群體存在的必然產物

### 多模板並行是起點（Section 2.3 推導）

已知最接近人類祖先的群體（黑猩猩）顯示：功能性收斂從一開始就是多模板並行
  已知類型：{性分配, 交易系統, 權力結構, 領土, 和解機制}
  ¬∃「原始單一模板」階段

對活在裡面的個體而言（從 40a22ff8.黑箱律 推出）：
  ¬∃「我在執行某某模板」的意識——就是這樣生活，制度對他們是空氣

### 承重結構

承重結構 ≡ 多模板並行系統中，各模板之間互相吸收對方三條成本（見 4.5 節）的結構性支撐關係
  每個模板的三條成本，有一部分由其他模板吸收
  互相支撐 ∧ 互相腐蝕（同一結構的兩面）
    支撐：家庭模板穩定，政治模板的安撫成本降低；宗教模板提供神聖性，政治模板的修補成本降低
    腐蝕：宗教機構膨脹和世俗權力爭同一個資源池；家庭模板弱化讓政治模板失去最基礎的不成文層支撐
  承重結構從多模板並行的那一刻就存在，貫穿運作和崩潰
  （從 多模板並行 + 三條成本定義 推出；三條成本完整定義見 4.5 節）

### 歷史條件 = 凝固的物理條件（Section 2.5 推導）

歷史遞回：現在的多模板結構 ← 之前的多模板結構在之前的物理條件下跑出來的結果
  可一路回溯到最早的群體

推導：
  歷史條件和自然條件對任何一個當下的群體性質完全相同：繼承的、不可選的、只能在裡面運作的給定條件
  ⇒ 可行域由 自然條件 ∧ 歷史條件 共同定義；兩者都是結構性給定，不是決策變數
  歷史是凝固的物理條件，跟山脈氣候一樣硬

### 知識累積相變（Section 2.6 推導）

兩個力同時運作：
  (+) 好奇心（← 生物性，不可關閉）：個體必然持續累積知識
  (-) P4 死亡律：個體消亡 → 語意流終止 → 知識耗散

在文明層級產生布林值：
  群體知識累積速度 > 死亡律耗散速度 ⊕ ¬（群體知識累積速度 > 死亡律耗散速度）

  不大於：制度複雜度每代接近清零，有硬上限
  大於：知識跨代複利，制度複雜度可跨代累積，無硬上限

人類跨過了這個門檻（經驗前提，論文 2.6 節明確標注：以文明知識跨代累積的歷史記錄接受，不從流變律–死亡律推出）。
相變不可逆：知識複利一旦開始，無法回到清零狀態

### 神聖性的動力學必要條件（Section 2.10 推導）

607cd714.神聖性 在動力學上產生效果的必要條件（缺一不可）：
  ① 607cd714.暴力壟斷者 存在（定義必要條件）
  ② 40a22ff8.信號容器 存在（缺信號容器 → 神聖性是一次性的，壟斷者死後效果歸零）

  條件①②滿足 ≠ 神聖性出現；只是出現了才能跑出動力學效果

動力學效果（從 607cd714.神聖性 + 40a22ff8.功能性收斂 推出）：
  憑空增加一個模板 ↝ 多模板系統的知識累積速度提升 ↝ 制度複雜度上升

  神聖性不保證文明在群際競爭裡存活——有神聖性的文明在歷史上大量消亡
  神聖性只是在可行域裡開了一些沒有它就不存在的制度形狀的可能性

### 軸心時代的結構性條件（Section 2.14 推導）

條件命題（從 文字出現 + 知識累積相變 推出）：
  若 ①文明獨立發展文字 ∧ ②讀書人作為獨立階層出現 ∧ ③舊模板正當性開始被質疑，
  三個條件同時成立，則百家爭鳴是必然的動力學輸出，不是可能

  缺任一條件：只是可能，不是必然

  借文字的文明：拿到現成概念系統，不需從零問，¬∃獨立思想家——符合條件命題的預測
  獨立發展文字的文明：每個抽象概念必須從具體經驗從零建起，強迫面對最根本的問題

校準：中國（儒墨道法）∧ 希臘（蘇格拉底/柏拉圖/亞里斯多德）∧ 印度（佛陀/耆那教/數論）
  在同一個歷史區間出現，是各文明獨立跨過文字門檻、三個條件同時成立後的同一個動力學過程

### 成文層收斂 / 神聖性發散（Section 2.17 推導）

選擇壓力對成文層有效（從 生物性的暴力成分 + 可行域 推出）：
  不學對方的軍事技術 → 死；不學對方的稅收系統 → 養不起軍隊
  → 行政形式 ∧ 商業框架 ∧ 法律技術隨交流快速收斂

神聖性沒有即時的戰場反饋：不信對方的神不會立刻死 → 神聖性不受選擇壓力收斂

結論：交流越深，成文層越趨同，神聖性系統繼續分叉
  → 生物性驅動收斂，神聖性驅動發散

### 地形重要性遞減，神聖性不可壓縮（Section 2.18 推導）

地形是成本（從 物理條件定義 推出）：技術單向降低跨越地形的代價 → 物理條件類的變異性來源被技術單向壓縮

神聖性阻擋的不是信號傳遞，是接收方的語意流（← 40a22ff8.阻力）：
  信號到了，但不被識別為有效知識或被識別為威脅
  這個阻力不是成本問題，技術壓縮不了

⇒ 文明之間的根本差異單向收窄到神聖性系統——神聖性是唯一不被壓縮的變數

## 三、知識爆炸後的動力學

來源：論文第三節

### 主幹因果鏈前置條件（Section 3 導言）

指數型結構有效知識域存在（從 Section 2.20 異端神聖性推出）：
  某個神聖性系統的方向讓「理解物理世界的規律」本身成為神聖行為
  → 有效知識域進入指數型結構
  為什麼這個方向在這裡出現：← 40a22ff8.P2 黑箱律，框架承認不可知，只描述輸出

歷史校準敘述（論文 Section 3 導言明確標注為歷史校準，框架形式推導在 3.1 節；以下為傳播路徑描述，非框架聲明）：
  指數型知識域啟動 ↝ 知識積累超過閾值 ↝ 和生產/軍事/經濟發生連結 ↝ 放大倍率爆炸
  第一個被炸的是基督教神聖性基礎設施本身（印刷術 ↝ 詮釋權散出 ↝ 教會正當性基礎瓦解）
  → 基督教撐起的政治制度正當性語言失效
  → 衝擊通過殖民和貿易輸出到全世界
  → 人類歷史第一次出現全球同步崩潰——不是各地獨立地三條成本超標，是單一來源通過交流網絡傳遍所有文明

### 永久崩潰狀態

永久崩潰狀態 ≡ 指數型知識域的環境變化率長期大於不成文層最大適應率時，制度穩定態結構性消失的狀態

條件命題：若 環境變化率(指數型知識域) 長期 > 最大適應率(不成文層)，則 ¬∃制度穩定態
  ¬∃穩定態 ≡ 新模板還沒站穩，下一波知識擴張已讓它的覆蓋能力再次不足
  性質：永久性——裂縫永遠在擴大
  論文聲明：此條件在當前歷史條件下成立；若未來出現某種機制讓不成文層的適應速度同步加速，條件不再成立，結論隨之改變

可證偽條件：∃機制讓不成文層適應速度達到指數型知識域的環境變化速度，且制度穩定態重新出現 ⊗ 永久崩潰狀態

外部強制函數的死局（從 永久崩潰狀態 + 607cd714.暴力壟斷者 推出）：
  不追趕 → 能力差距持續擴大 ↝ 可行域被壓縮 ↝ 制度失效（外部壓死）
  追趕 → 知識爆炸速度超過模板覆蓋能力 ↝ 制度從內部撐裂
  兩條路都走向失效，只是機制不同、速度不同
  不成文層損耗：追趕的不可回收代價（自然資源被打掉，條件消失就是消失，← 不成文層定義）

### 承重結構同時失效（Section 3.2 推導）

正常崩潰：最脆弱模板先斷，其他模板吸收負荷（承重結構有緩衝）
知識爆炸下（從 永久崩潰狀態 + 承重結構定義 推出）：
  同時打擊所有模板覆蓋能力，沒有哪個模板是穩定的
  → 承重結構無法運作（每一根柱子同時在彎）→ 緩衝消失
  → 這是近代史的結構：不是崩潰特別多，是正常崩潰的緩衝機制消失了

### 權力錨點移動（Section 3.3 推導）

農業時代：資源是固定總量 → 控制物理資源 = 控制一切（壟斷者提取邏輯）
知識爆炸之後（從 指數型結構 + 生物性的貪婪成分 推出）：
  資源產出 = 技術能力的函數（同樣土地，工業化農業產出遠大於傳統農業）
  → 誰控制放大倍率，誰就控制實際產出
  → 壟斷者提取能力 = 技術人才能力的函數
  → 壟斷者第一次在結構上需要技術人才多於技術人才需要他

### 民主政治的結構性條件（Section 3.4 推導）

民主政治的必要條件（從 3b1c4d8e.尋租空間 + 永久崩潰狀態 推出）：
  讓步成本 < 壓制成本
  農業時代：壓制成本 ≪ 讓步成本 → 民主是奢侈品
  知識爆炸之後：壓制技術人才的代價 = 放大倍率消失 → 讓步成本 < 壓制成本首次在結構上成立

  [讓步成本 < 壓制成本是必要條件，不是充分條件]

結構性死局（從 替代成本定義 + 3b1c4d8e.尋租空間 推出）：
  讓步 → 需拆解壟斷者賴以提取的控制結構 → 同時拆解提取能力
  → 讓步這個行為本身可能毀掉讓步所需的那個結構（不是信息不完整，是結構性不可解）

### 孤狼均衡

孤狼均衡 ≡ 低技術勞工移民第一代的結構性位置：生存為第一要務，個體分散，威脅不集中，對母國文化認同薄弱，對宿主文化無接入點
  兩頭都不屬於的動力學來源：母國安撫機制失敗（所以離開）∧ 宿主 607cd714.神聖性 對他們無約束力
  狀態特徵：弱勢 ∧ 分散 ∧ 威脅不集中（不穩定，但威脅分散）

### 雙重排除

雙重排除 ≡ 母國放棄（安撫機制失敗者）∧ 宿主接納不了（神聖性無約束力，處於分配結構最底層）的結構性位置
  安撫成本在兩端同時失效（← 安撫成本定義）

後果（從 雙重排除 + 安撫成本定義 + 40a22ff8.P2 推出）：
  不可量化的安撫需求 ↝ 信仰需求（壓力在當地長出來，不依賴從母國帶來什麼）
  第二代：在宿主國出生但宿主不成文層裡永遠是外人 → 怨恨型不成文層最容易長出來的人口

[移民衝突正反饋循環]（明確標記為循環）：
  移民引進 ↝ 人口結構風險輸入 + 不成文層衝突 ↝ 安撫成本爆炸 ↝ 管理成本爆炸
  ↝ 稅基需求上升 ↝ 需要更多移民維持稅基 ↝ 更多風險輸入與衝突
  退出條件：¬∃內建退出條件

移民死局（從 孤狼均衡 + 雙重排除 + 永久崩潰狀態 推出）：
  不接受移民 → 人口不夠 ↝ 稅基崩潰 ↝ 管理成本付不出去 ↝ 制度因缺人失效
  接受移民 → 人口結構風險輸入 + 不成文層衝突 + 同化機制消失 ↝ 制度從內部撐裂
  兩條路都走向失效（死局），只是機制不同，速度不同

同化機制的結構性消失（從 不成文層定義 + 永久崩潰狀態 推出）：
  宿主同化壓力來自宿主不成文層的強度（← 不成文層定義）
  宿主不成文層在知識爆炸 + 宗教退場 + 家庭模板失效的壓力下持續弱化
  → 同化壓力本來就在下降；網路讓物理孤立不可能；移入速度遠超吸收上限
  → 洩壓閥結構性消失

### 物理必然性約束（Section 3.8）

框架裡暴力的約束有三種：
  ① 更大的暴力從外部壓制
  ② 607cd714.神聖性 讓壟斷者自行停手
  ③ 物理必然性：使用暴力的物理結果保證自我毀滅（原子彈）
    不是更大的暴力——是使用暴力的算術結果不可逃脫
    不是神聖性——沒有人在原子彈面前停手是因為它神聖
  神聖性可以消失，壟斷者可以重新選擇動手；物理定律不會消失

## 四、制度的運作：落地、成本、穩定

來源：論文第四節

### 模板的結構性死結（Section 4.1 推導）

607cd714.暴力壟斷者 存在 → 3b1c4d8e.尋租空間 存在 → 壟斷者可在模板框架內合法抽取資源
  ¬∃內建上限（直到文明崩潰）

模板內制衡機構（元老院 ∧ 御史台 ∧ 議會）也在同一資源分配體系裡：
  壟斷者控制資源分配 ↝ 制衡機構存活依賴資源 ↝ 用資源收買就行了
  制衡機構本身也是得利者，制衡的動力本來就有限
  → 任何在模板內部設計出來的制衡機構，結構上都會被資源收編
  （從 3b1c4d8e.尋租空間 + 生物性的貪婪成分 推出）

### 替代成本

替代成本 ≡ 新模板落地所需的一次性成本，與新模板和現有不成文層之間的距離成正比

兩個成分（單位不相容，分開計算）：
  成分一（資源成本）：鎮壓成本 + 管理單位成本 + 宣傳成本
    可量化；原則上可以回收
  成分二（不成文層損耗）：被打掉的不成文層是自然資源，打掉就是打掉，不能用資源補回
    可觀察但不可量化；觀察指標：打掉之後需要多少代人才能長出新的不成文層，或永遠長不出來

成本的表現形式（從 生物性 + 認同定義 推出）：
  得利者能夠組織集體反抗 → 殺戮（落地快但代價極高）
  得利者無法組織集體反抗 → 摩擦（個體層面消化，週期可能幾代人）

新穩定態成立的判定：不成文層真正吸收了新模板的那個時刻（在那之前，成文和不成文的張力持續消耗資源）

### 模板的核心結構（Section 4.4 推導）

前置條件：
  任何制度上線都必須宣稱「這個分配是自然的/神聖的/必然的/公正的」
  ¬∃制度說「這是我們這批人的利益安排」還能存活（說了就沒有人配合，替代成本無限大）
  宣稱是落地的技術需求，跟統治者的品格無關（← 40a22ff8.P2 黑箱律）

推導（從 生物性的貪婪成分 + 成文層定義 推出）：
  貪婪持續在規則邊緣試探 ↝ 每次成功把實際分配再往上推一點
  成文層的公平宣稱不能跟著動（宣稱一旦固定，改了就失去正當性）
  ⇒ 成文與不成文的距離有單向累積的趨勢——這是所有制度的內建趨勢，不是偶發的腐敗問題

### 修補成本

修補成本 ≡ 生物性（暴力 + 貪婪 + 好奇心）持續衝擊制度邊界所需的持續對抗投入

驅動結構：
  貪婪在規則邊緣試探尋租
  暴力製造越界壓力
  好奇心產生新想法衝擊現有正當性

[修補複雜度爆炸循環]（明確標記為循環）：
  修補制度需要新制度 ↝ 新制度又被三個驅動力衝擊 ↝ 複雜度爆炸
  退出條件：¬∃內建退出條件

性質：持續性 ∧ 單向累積
  監督制衡（政治）、道德秩序（家庭）、誠信互信（商業）是同一個修補需求在不同模板上的表現，動力學結構完全一樣

操作性定義：制度上線時的行政成本為基準；之後每一輪超出基準的額外增量就是修補成本的累積量

### 安撫成本

安撫成本 ≡ 維持底層接受分配的持續成本

存在性：結構性必要條件——任何制度都必須有某種讓底層接受分配的機制，¬∃機制則崩潰
量級 ∝ 公平宣稱與實際分配之間的距離
形式：文明特定（種姓業報輪迴 ∧ 五倫雙向義務 ∧ 末世論 ∧ 薪資……）；框架只預測此成本存在，不預測其內容

兩個成分（單位不相容，分開計算）：
  成分一（可量化部分）：薪資 ∧ 退休金 ∧ 醫療 ∧ 福利支出等
    衡量工具：福利支出佔 GDP 比例
  成分二（不可量化部分）：政治權利 ∧ 宗教承諾 ∧ 民族榮譽感等
    反向信號衡量：認同統計下降 ∧ 抗議頻率上升 ∧ 移民率上升

性質：持續性 ∧ 單向累積

三條成本總覽（從 模板的核心結構 + 生物性 推出）：
  替代成本：一次性，和新舊模板距離成正比
  修補成本：持續，單向累積
  安撫成本：持續，單向累積
  三條成本同時在消耗可行域的資源上限；在承重結構裡核算，不是在每個模板上獨立超標

### 神聖性的效果與成本（Section 4.6 推導）

有神聖性：強制成本 → 0（語意流方向與約束一致，自願服從）；修補成本相對低
  代價：神聖性基礎設施成本（傳遞機構要吃飯，天然膨脹）∧ 神學複雜度（異端/分裂/教派衝突）

無神聖性：行政監控成本高；神聖性基礎設施成本低

兩條路都走向複雜度爆炸，只是爆炸的位置不同

### 穩定態

穩定態 ≡ 三條成本的總和在可行域資源上限之內，且成文與不成文的距離尚未跨越可見閾值的狀態

本質：倒計時，不是正面狀態（修補成本 ∧ 安撫成本單向累積，距離單向擴大，穩定只是崩潰尚未到來）
穩定 ≠ 統一機制；穩定的唯一條件：三條成本加總不超標
三條成本在承重結構裡核算

崩潰閾值形式化條件（從 穩定態定義 + 607cd714.暴力壟斷者 推出）：
  三條成本總和 > 壟斷者實際可抽取的資源量
  [「實際可抽取」≠「可行域內總資源」：取決於壟斷者對地方的實際控制深度]

可觀察指標：抽取比率逼近抽取能力上限的速率（稅率記錄、徵收實績與帳面差距、地方截留比例）

## 五、制度為什麼崩潰

來源：論文第五節

### 前置條件

崩潰的機制：模板與可行域之間的裂縫超過閾值
崩潰的觸發方向（兩條，從 穩定態定義 推出）：
  可行域縮小 ↝ 模板出界（正常崩潰方向）
  可行域擴張太快 ↝ 模板失去覆蓋能力（知識爆炸方向，方向相反，失效序列相同）

### 可想像性閾值

可想像性閾值 ≡ 「可以不一樣」從不可想像變得可以被想像的不可逆轉折點

特性：不可逆——一旦跨越，不可逆
說破不是崩潰原因：三條成本先殺死制度，說破確認它
  （說破之前，說模板是假的只是瘋子在說話；說破之後，只是說出了所有人已經半知道的事）

失效序列描述（不作為 export，作為推導描述）：
  成文與不成文的距離累積到閾值 ↝ 安撫成本機制失效 ↝ 執行機率下降 ↝ 模板變得可見
  ↝ 有人說出口 ↝ 替代框架有土壤進入 ↝ 可想像性閾值被跨越 ↝ 制度崩潰
  （從 穩定態定義 + 安撫成本定義 + 制度定義 推出）

承重結構的級聯崩潰（從 承重結構定義 推出）：
  最脆弱模板先達閾值 ↝ 原來它吸收的成本重新分配給其他模板 ↝ 其他模板倒計時加速
  外部觀察者看到的是最後一根柱子斷掉，但整個系統的負荷早就在悄悄重新分配了
  ¬∃預測哪個模板先斷（由各自承重結構和條件變化決定——框架提供診斷工具，不預測順序）

崩潰的兩個方向（從 穩定態定義 + 失效序列 推出）：
  從上往下：外部衝擊打掉成文層，壓力向下傳
  從下往上：不成文層先失效，成文層失去支撐

技術加速崩潰的機制（從 40a22ff8.信號容器 + 失效序列 推出）：
  技術不改變崩潰的方向和機制，只提高速率
  原來可以在地方分散處理的矛盾，變成全國同時爆發（印刷機 ∧ 網路是這個效果的不同量級）

## 六、制度為什麼能重啟

來源：論文第六節

### 前置條件

重啟的預設：預設不能重啟
  607cd714.神聖性 是自然資源，物理條件消失就消失
  明教/希臘神話/北歐神話有神聖性，死了——神聖性的存在不保證持續

### 重啟的三個必要條件

（三條件缺一不可，從 制度定義 + 終態定義 + 功能性收斂定理 推出）

條件一（物理條件）：可行域必須存在——硬底線，不存在則 → 滅亡
條件二（候補模板）：崩潰發生時地下必須有模板在等
  不需從零建（真空裡從零建模板，建不起來）
  候補模板越完整，替代成本越低（從 替代成本定義 推出）
條件三（基本人口）：功能性收斂需要群體
  人口低於某閾值 ↝ 群體動力學跑不起來 ↝ 制度從定義上不可能存在

607cd714.神聖性 降低重啟成本，但不是重啟必要條件：
  ¬神聖性 ∧ 候補模板存在 → 重啟可能，成本高
  決定重啟可不可能的是候補模板，不是神聖性

三個必要條件的邏輯關係 → 終態封閉分類（對應「一.終態」段落）：
  ∀條件均滿足 ⇒ 轉型
  條件一 ∧ 條件三滿足 ∧ ¬條件二 ⇒ 無政府
  ¬條件一 ⇒ 滅亡

### 現代重啟的時間結構（Section 6.3 推導）

前現代：時間是中性的（等待中條件自然恢復：人口反彈，候補模板在地下存活）
現代（從 永久崩潰狀態 推出）：時間是負值
  知識爆炸繼續打擊重啟條件：人口繼續下降，神聖性退場，候補模板繼續耗盡
  不是等夠了就能重啟，是等待讓重啟越來越不可能

競賽：重啟條件歸零速度 vs. 新模板從零長出速度

### 基督教的結構性例外（Section 6.6 推導）

多數神聖性系統：神聖性和具體社會模板捆綁 → 模板失效，神聖性跟著倒
基督教：神聖性錨定在一個歷史事件上（「這件事發生過」）
  錨點極小 → 神學/教會組織/道德框架/政治立場全部可以重新詮釋，只要核心敘事還在
  → 神聖性和制度模板解耦：模板失效，神聖性還在，可以在新的物理條件下長出新的模板版本

普世性（¬∃特定民族/語言/文化綁定）：讓壓力來自哪個方向，就從另一個方向找到新的可行域長出新版本

演化能力的結構性代價：
  錨點越小 → 從它長出來的模板越薄（¬∃對具體生活方式做強制性要求，因為細節在不同可行域裡互相矛盾）
  每一輪崩潰重啟之後，錨點保留，模板變薄
  長期動力學終態：存活但空洞化（神聖性錨點還在，但長不出任何有實質約束力的模板）

## 七、框架應用：家庭制度

來源：論文第七節

### 生物預設狀態

生物預設狀態（從 生物性 + 40a22ff8.死亡律 推出）：
  雄性親子確定性為零 → 投入特定幼崽是演化上的浪費
  母親和孩子的連結：生物硬件，不需要任何制度強制
  父親投入：制度發明（不是生物預設）

### 流浪漢均衡

流浪漢均衡 ≡ 在沒有說服機制的情況下，男性回到生物預設狀態、不投入特定孩子資源的穩定配置

均衡特徵：女性帶孩子（生物硬件），男性流浪（生物最優解）
性質：這不是制度，是預設狀態（沒有任何功能性收斂模板的情況下的生物性輸出）
（從 生物性 + 40a22ff8.黑箱律 推出）

可證偽條件：∃群體：¬∃任何制度說服機制 ∧ 男性持續大量投入特定孩子的資源 ∧ 這不能從神聖性或其他說服機制解釋 ⊗ 流浪漢均衡

### 母系社會的可行域（Section 7.2 推導，不作為 export）

母系社會的可行域極窄，必要物理條件同時成立：
  地形孤立（外部威脅低，男性暴力邊際收益為負）
  ∧ 女性控制的生產性資源是男性暴力拿不走的（特定農業形式 ∧ 漁業 ∧ 貿易網絡）
  ∧ 群體規模小（社會壓力有效，逃跑成本高）
  → 男性暴力的可行解空間被擠掉（不是道德，是物理條件下暴力沒有出路）

母系社會是少數：不是因為被父系社會打敗，是因為物理條件視窗太窄
（從 物理條件 + 可行域定義 + 生物性的暴力成分 推出）

### 父系社會的結構性解（Section 7.3 推導，不作為 export）

父系社會是解決男性大規模投入資源問題的制度發明，解決了流浪漢均衡在群際競爭下的存活問題：
  姓氏（信號）↝ 降低親子確定性不確定性
  貞操控制 + 婚姻儀式（執行機制）↝ 信號可信
  繼承規則 ↝ 男性資源綁定孩子跨代傳遞
  宗教 + 道德體系 ↝ 父親義務正當化 ↝ 進入不成文層
（從 流浪漢均衡 + 群際競爭壓力 + 承重結構 推出）

### 現代家庭崩潰（Section 7.5 推導）

物理條件改變：都市化 + 避孕技術 + 女性進入勞動市場
  ↝ 父系說服機制執行成本暴升 ∧ 信號功能弱化
  ↝ 說服機制失效 ↝ 男性回到流浪漢均衡
  ↝ 女性獨自承擔養育成本（資源支撐消失）
  ↝ 生育率崩潰

結構性結論（從 流浪漢均衡 + 替代成本 + 安撫成本 + 40a22ff8.P2 推出）：
  ¬∃替代說服機制（論文明確聲明：目前沒有任何理論給出替代說服機制）
  ¬∃成文層工具的解（補貼生育/推廣家庭價值觀 = 用成文層工具替代必須從物理條件長出來的不成文層）
  對應終態：可行域歸零 → 滅亡（框架所有崩潰序列裡唯一一個攻擊可行域生物基礎本身的機制）

### 複製貼上能力

複製貼上能力 ≡ 對外來模板的不成文層阻力場趨近於零、可以複製表面成文層同時保持底層不成文層的結構性能力

起源（從 物理條件 + 不成文層定義 推出）：

  對外來模板：40a22ff8.阻力場 趨近於零

能力邊界（從 有效知識域 + 加法結構 推出）：
  複製貼上的前提是有東西可以複製
  知識爆炸製造的問題（家庭模板失效、生育率崩潰）全世界沒有已知解 → 複製貼上在此完全失效

能力與弱點是同一件事：把複製練成了不成文層，反而失去從零生長新東西的能力

  戰後新憲法：路徑四（軍事介入）借神聖性外衣 → 不成文層阻力場相容性遠高於其他被殖民地區（← 複製貼上能力）
