## 約束層級

來源：論文第五節

ConstraintHierarchy ≡ 元價值觀層約束制度可能性空間，制度可能性空間約束制度形狀，制度形狀約束行為分布（Involution）
  約束意義：限定下游的可能性空間，不是因果導致
  → Java：record，field = {MetaValueLayer, InstitutionalLayer}

InstitutionalAction = Destroy ⊕ Occupy ⊕ Exploit（且僅此三者）
  Destroy：制度力量摧毀 TranscendenceMechanism（蘇聯肅清蒙古藏傳佛教、文革摧毀中國殘存信仰）
  Occupy：制度力量佔據超越性位置（明治國家神道、主體思想、中國夢）
  Exploit：制度力量利用 TranscendenceMechanism（國教化、收編）
  → Java：sealed interface

不可加推導 — CannotCreate ← TranscendenceMechanism 定義 + ModernizationCycle：
  ¬∃Create: InstitutionalPower → TranscendenceMechanism(direction ≠ ModernizationCycle)

  Step₁（從論文 3.4 推出）：InstitutionalPower ∈ ModernizationCycle 的運算範圍（法律可被遊說、預算可被削減、政策可被購買）
  Step₂（從 Step₁ 推出）：被造出的 Signal 源，權威來源 = 造它的 InstitutionalPower
  Step₃（從 Step₂ + TranscendenceMechanism 定義推出）：InstitutionalPower 是循環內貨幣，創造動作本身就是一條現成轉化路徑，循環不需費力尋找吸收辦法
  Step₄（從 TranscendenceMechanism 判定標準推出）：TranscendenceMechanism 要求世俗權力最頂端在它面前低頭，創造者不會向自己造的東西低頭，自己澆築的天花板壓不住自己
  結論：制度創造的候選機制必然倒下——方向坍縮為 = ModernizationCycle（權威就是世俗權威）⊕ 被吸收（創造路徑 = 吸收路徑）
  僅形式層

  精確限定：同步性不可能——只要創造者還活著，創造路徑就是活的吸收路徑
  歷史上存在「創造者消亡、造物存活」的案例（印度教婆羅門權威），但對任何現存政策制定者無可操作性

約束層級完整表述：
  MetaValueLayer 對下游約束是全時的——無論 TranscendenceMechanism 在場（菲律賓）∨ 缺席（中國空缺期、台灣）∨ 被佔據（韓國、北韓、再佔據期中國）
  InstitutionalLayer 對 MetaValueLayer 的作用是半開的——可減（Destroy ∨ Occupy ∨ Exploit），不可加（CannotCreate）
  不可加由定義保證，不依賴歸納
  僅形式層
